Description:
  Runs a labelled dataset against a provider, then writes the results and a calibration report.

Usage:
  minos calibrate [options]

Options:
  --dataset <file> (REQUIRED)  The labelled dataset: a JSONL file with one item per line.
  --config <file>              The config file, JSON with a Minos section. Environment variables such as Minos__Providers__<name>__Model override it. [default: minos.json]
  --provider <name>            The provider section of the config to use. Default: the section named by Minos:Active.
  --model <id>                 The model to call, in place of the section's Model. Default: the section's Model, then the provider's default model.
  --parallel <n>               How many items run at once. [default: 1]
  --prices <file>              A prices file, JSON, that prices the tokens of a provider that reports no cost. Default: none, so only reported costs count.
  --out <dir>                  The directory for results.jsonl, report.json and report.md, created when missing. Default: minos-out/<provider>-<UTC yyyyMMdd-HHmmss>, with the provider section being run.
  -?, -h, --help               Show help and usage information
