# Phase 1.1 Design — Repo scaffolding

**Date:** 2026-09-24
**Phase:** 1.1
**Surface:** Infra
**Stage:** phase (one phase, implementation-ready)

## Goal

A buildable, testable, packable solution skeleton for Jev.Net that follows the ZeroAlloc.Rest / AdoNet.Async repository standards, so every later phase lands on warnings-as-errors, central package management and public-API tracking from day one.

## Approach

Skeleton only — one library and one test project. The wire model, WireMock.Net harness, AOT smoke app, benchmarks and CI workflows are explicitly deferred to phases 1.2–1.7.

Build configuration merges the two reference repos. From ZeroAlloc.Rest: `global.json` pinning SDK 10.0.401 with `latestMinor` roll-forward, central package management via `Directory.Packages.props`, `NuGetAuditMode=direct`, RS0016/RS0017 promoted to errors, `IsPackable=false` for `*.Tests` / `*.Benchmarks`, README + icon packed into every package. From AdoNet.Async: `EnforceCodeStyleInBuild`, `AnalysisLevel=latest-recommended`, the full analyzer set (Meziantou, Roslynator, ErrorProne.NET Core + Structs, NetFabric.Hyperlinq, ZeroAlloc.Analyzers), `.editorconfig`, and `tests/Directory.Build.props` for test-only suppressions. Target is net10.0 only.

`src/Jev.Net` is declared `IsAotCompatible` and references `Microsoft.CodeAnalysis.PublicApiAnalyzers` with `PublicAPI.Shipped.txt` / `PublicAPI.Unshipped.txt`. A single placeholder public type, `JevDefaults` (base URL `https://api.typesafe.ai/`, env var name `TYPESAFE_API_KEY`, default model `jev-latest`), exercises the tracking files and gives the test project something real to assert. Package metadata: id `Jev.Net`, MIT, author Marcel Roozekrans, description stating it is an unofficial .NET client for TypeSafe AI's Jev.

`tests/Jev.Net.Tests` uses xUnit v2 with plain `Assert` (no FluentAssertions — commercial licence). Repository hygiene: `.gitattributes` forcing LF, `.gitignore` from the dotnet template, `.commitlintrc.yml` (scope-enum level 2), `renovate.json` extending the shared config, `LICENSE` (MIT), stub `README.md`, placeholder `assets/icon.png` + `assets/logo.svg`.

After `.commitlintrc.yml` lands, `init-conventions` is re-run so `CONVENTIONS.md` records `Scopes: enforced` with `Scope source: .commitlintrc.yml`. Phase 5.1 shrinks to API review/sealing since PublicAPI tracking starts here.

## Files / Modules Touched

- `global.json` — SDK pin
- `Directory.Build.props` — shared build, metadata, analyzers
- `Directory.Packages.props` — central package versions
- `tests/Directory.Build.props` — test suppressions
- `Jev.Net.slnx` — solution with `/src/` and `/tests/` folders
- `src/Jev.Net/Jev.Net.csproj`, `JevDefaults.cs`, `PublicAPI.Shipped.txt`, `PublicAPI.Unshipped.txt`
- `tests/Jev.Net.Tests/Jev.Net.Tests.csproj`, `JevDefaultsTests.cs`
- `.editorconfig`, `.gitattributes`, `.gitignore`, `.commitlintrc.yml`, `renovate.json`
- `LICENSE`, `README.md`, `assets/icon.png`, `assets/logo.svg`
- `docs/planning/CONVENTIONS.md` — Scopes re-derived after commitlint lands

## Tests

- Unit: `JevDefaultsTests` asserts base URL, env var name and default model.
- Build gate: `dotnet build -c Release` with zero warnings under TreatWarningsAsErrors and all analyzers.
- Pack gate: `dotnet pack -c Release` produces a `Jev.Net` nupkg containing README.md, icon.png and the MIT licence expression.
- Regression: n/a (no prior code).

## Open Questions

None — assertion library (plain xUnit), commit scopes and metadata decided during brainstorm.

## Risks

| Risk | Impact | Mitigation |
|---|---|---|
| Analyzer package versions lag or conflict on net10.0 / SDK 10.0.401 | Build fails under warnings-as-errors | Use the versions pinned in ZeroAlloc.Rest / AdoNet.Async (known-good on net10.0); suppress only with a documented reason |
| Placeholder `icon.png` missing breaks `dotnet pack` | Pack gate fails | Generate a small PNG placeholder in this phase |
| CRLF conversion on Windows produces noisy diffs | Churn in every commit | `.gitattributes` `* text=auto eol=lf` + renormalise existing files |
