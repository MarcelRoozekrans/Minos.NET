## Goal

A new, unpacked package `Minos.NET.Extensions.AI.Decisions` with two adapters: a Minos `IDecisionClient` over an upstream client, and an upstream `IDecisionClient` over a Minos client, tested with the Minos conformance checks, a round trip, and the escalation and fallback stages.

## Approach

**Package.** `src/Minos.NET.Extensions.AI.Decisions`, namespace `Minos.Extensions.AI.Decisions`, `IsPackable` false and `IsAotCompatible` true. It references `Minos.NET` and the built upstream assembly by the path in `artifacts/upstream/abstractions.path`, through a `Reference` item with `Private` false; the build fails with a clear message, naming `build-decisions.sh`, when the file is missing. The solution builds it only in a `Decisions` configuration and in the `upstream-decisions` CI job, so the default build and test never need the upstream clone. All public API carries the upstream experimental marker `MEAI001` and a README says the package follows an unreleased API.

**Minos over upstream.** `UpstreamDecisionClient : Minos.IDecisionClient` wraps an upstream client. It converts the request's `QuestionSetDefinition` to upstream questions (Noul to Binary; Choice to Choice with candidate ids from the option keys; Score to Score with the position keys `"0"`, `"1"` and so on as level ids), the state to a `JsonElement`, and the model to `DecisionOptions.ModelId`. An empty question set returns `Validation` with the message "The request has no questions." and no `QuestionFailure`, before sending, as `ChatDecisionClient` does and conformance check E1 expects. It returns `Unsupported` before sending, with one `QuestionFailure` per problem, only for what the mapping page lists as refused before sending: a kind outside the upstream `SupportedKinds` when that list is there (MIN201), images (MIN206), examples or exclusions on a criterion (MIN205), a blank question or option id (MIN207), a blank description (MIN208), a Noul with blank instructions and no description pair (MIN209), and a one-level Score (MIN210). The rule ids MIN205 to MIN210 are those in `docs/diagnostics.md`. Every other loss converts as the page says, for example JSON instructions sent as their JSON text, an undescribed option sent with its key as the description, and the retry attempt dropped. It checks that the upstream response's request has the state and questions it sent, and returns `InvalidResponse` when they differ. It converts the upstream answers back to `QuestionAnswer`s: the probability source from the `minos.probabilitySource` key when present, otherwise `Model` as an assumption, never derived from the declared precision; the confidence from `minos.confidence`, otherwise the probability of the chosen option or of the most probable level; a Score's chosen level from `minos.chosenLevel`, otherwise the most probable level, the lower one on a tie; and the expected level from `Score`, falling back to `ExpectedScore`. Exceptions become `DecisionError`: cancellation passes through and a call after disposal throws `ObjectDisposedException`, as the interface documents; `DecisionProtocolException` becomes `InvalidResponse` with its message; a transient `DecisionClientException` becomes `Server`, and any other exception becomes `Http`. Each keeps the message and no state, has a `null` status code, and keeps the caught exception in `DecisionError.Exception`.

**Upstream over Minos.** `MinosDecisionClient : Microsoft.Extensions.AI.IDecisionClient` wraps a Minos client. It builds a new `QuestionSetDefinition` from the upstream questions on each call, calls `EvaluateAsync`, and converts the answers, declaring `DecisionPrecision.TwoDecimalPlaces` on every answer because Minos providers report values rounded to two places. It writes the Minos values that have no upstream slot to `AdditionalProperties` under the `minos.*` keys the page defines: `minos.chosenLevel`, `minos.confidence` and `minos.probabilitySource` for answer values, and `minos.upstreamProvider`, `minos.path`, `minos.cost` and `minos.isCached` for response values. A number, `true`, `false` or `null` state, which Minos cannot hold, throws a non-transient `DecisionClientException` before the Minos client is called. A `DecisionError` throws `DecisionClientException`, which is sealed upstream so no Minos type derives from it, with the error's message and `IsTransient` from `DecisionRetryOptions.IsTransient`; for `InvalidResponse` it throws `DecisionProtocolException` instead. Either way the inner exception is a `MinosDecisionException` that carries the `DecisionError`. A Minos response whose usage cost is negative or not a finite number is refused like an answer upstream rejects: a `DecisionProtocolException` whose inner `MinosDecisionException` carries an `InvalidResponse` error. `minos.path` is written as a `JsonElement` with camelCase names, as the mapping page describes, so the response serializes without reflection. `GetService` returns the upstream metadata, `DecisionCapabilities` and the wrapped Minos client, so a caller can reach the pipeline stages. Extension methods `AsUpstreamDecisionClient()` and `AsMinosDecisionClient()` are the entry points; DI registration is left to the caller in this phase.

**Pipeline.** A test builds `UseFallback` and `UseEscalation` over `UpstreamDecisionClient` instances and checks the path, the answered-by names and the merged answers match the same stack over a fake Minos client.

## Tests

- Unit: each question kind and answer converts both ways, with a case per row the mapping marks as a loss, which is `Unsupported` only where the page refuses before sending; errors map as documented; cancellation and disposal pass through; no state appears in a message.
- Integration: the Minos conformance checks that apply run against both adapters over a fake upstream client; a round trip Minos to upstream to Minos returns the same answers; `UseFallback` and `UseEscalation` over the adapter match the same stack over a fake.
- Regression: the default solution build and test pass without the upstream clone; a test fails if the project becomes packable before Phase 11.3.

## Open Questions

- None blocking. My calls: the exception type is `MinosDecisionException`, the inner exception of the upstream exception Over Minos throws; DI helpers wait for a use case.

## Risks

| Risk | Impact | Mitigation |
|---|---|---|
| The upstream score model (`Score` and `ExpectedScore`) does not match Minos's levels | A lossy conversion | The mapping states the rule; the adapter declares `TwoDecimalPlaces`, is tested on it, and refuses before sending only what the page lists |
| A build reference to a path outside NuGet breaks `dotnet restore` for contributors | Local friction | The project is out of the default configuration and the error names the script |
| Upstream reshapes the API | Rework | The pin moves on purpose, and the mapping test names what broke |
