# Phase 11.2 Design — `Adapters`

**Date:** 2026-11-07
**Phase:** `11.2`
**Surface:** `Backend`
**Stage:** phase (one phase, implementation-ready)
**Status:** approved 2026-11-07

**Builds on:** Phase 11.1 — `tools/upstream/decisions-pin.json`, `tools/upstream/build-decisions.sh` writing `artifacts/upstream/abstractions.path`, and the mapping decisions in `docs/extensions-ai-decisions/mapping.md`.

## Goal

A new, unpacked package `Minos.NET.Extensions.AI.Decisions` with two adapters: a Minos `IDecisionClient` over an upstream client, and an upstream `IDecisionClient` over a Minos client, tested with the Minos conformance checks, a round trip, and the escalation and fallback stages.

## Approach

**Package.** `src/Minos.NET.Extensions.AI.Decisions`, namespace `Minos.Extensions.AI.Decisions`, `IsPackable` false and `IsAotCompatible` true. It references `Minos.NET` and the built upstream assembly by the path in `artifacts/upstream/abstractions.path`, through a `Reference` item with `Private` false; the build fails with a clear message, naming `build-decisions.sh`, when the file is missing. The solution builds it only in a `Decisions` configuration and in the `upstream-decisions` CI job, so the default build and test never need the upstream clone. All public API carries the upstream experimental marker `MEAI001` and a README says the package follows an unreleased API.

**Minos over upstream.** `UpstreamDecisionClient : Minos.IDecisionClient` wraps an upstream client. It converts the request's `QuestionSetDefinition` to upstream questions (Noul to Binary; Choice to Choice with candidate ids from the option keys; Score to Score with its levels), the state to a `JsonElement`, and the model to `DecisionOptions.ModelId`. It converts the upstream answers back to `QuestionAnswer`s and fills the probability source from the answer's precision. Exceptions become `DecisionError`: cancellation and disposal pass through as the interface documents, the protocol exception becomes `InvalidResponse`, anything else a `Transport` error that keeps the message and no state. A difference the mapping marks as a loss makes the adapter return `Unsupported` before sending, with a code, as the capability checks do.

**Upstream over Minos.** `MinosDecisionClient : Microsoft.Extensions.AI.IDecisionClient` wraps a Minos client. It builds a `QuestionSetDefinition` from the upstream questions, calls `EvaluateAsync`, and converts the answers; a `DecisionError` becomes a `MinosDecisionException` that carries it. `GetService` returns the upstream metadata, `DecisionCapabilities` and the wrapped Minos client, so a caller can reach the pipeline stages. Extension methods `AsUpstreamDecisionClient()` and `AsMinosDecisionClient()` are the entry points; DI registration is left to the caller in this phase.

**Pipeline.** A test builds `UseFallback` and `UseEscalation` over `UpstreamDecisionClient` instances and checks the path, the answered-by names and the merged answers match the same stack over a fake Minos client.

## Tests

- Unit: each question kind and answer converts both ways, with a case per row the mapping marks as a loss; errors map as documented; cancellation and disposal pass through; no state appears in a message.
- Integration: the Minos conformance checks that apply run against both adapters over a fake upstream client; a round trip Minos to upstream to Minos returns the same answers; `UseFallback` and `UseEscalation` over the adapter match the same stack over a fake.
- Regression: the default solution build and test pass without the upstream clone; a test fails if the project becomes packable before Phase 11.3.

## Open Questions

- None blocking. My calls: the exception type is `MinosDecisionException`; DI helpers wait for a use case.

## Risks

| Risk | Impact | Mitigation |
|---|---|---|
| The upstream score model (`Score` and `ExpectedScore`) does not match Minos's levels | A lossy conversion | The mapping states the rule; the adapter is tested on it and refuses what it cannot represent |
| A build reference to a path outside NuGet breaks `dotnet restore` for contributors | Local friction | The project is out of the default configuration and the error names the script |
| Upstream reshapes the API | Rework | The pin moves on purpose, and the mapping test names what broke |
