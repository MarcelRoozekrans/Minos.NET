# Phase 11.3 Design — `Publish when upstream ships`

**Date:** 2026-11-07
**Phase:** `11.3`
**Surface:** `Infra`
**Stage:** phase (one phase, implementation-ready)
**Status:** approved 2026-11-07
**Amended 2026-11-07:** where this design says to close or set the phase deferred, read: keep the phase pending with a Deferred line naming the issue (#352). The planning docs use only active, complete and pending.

**Builds on:** Phase 11.2 — the project `src/Minos.NET.Extensions.AI.Decisions` and its tests, with `IsPackable` false.

## Goal

Pack and release `Minos.NET.Extensions.AI.Decisions` as a beta against the first upstream Microsoft.Extensions.AI.Abstractions package that contains the decision types, or, when none exists, file the wait as an issue and close the phase as deferred.

## Approach

**The gate comes first.** Task 1 checks nuget.org for a stable or preview `Microsoft.Extensions.AI.Abstractions` whose public API contains `IDecisionClient` (the check is a script, `tools/upstream/find-decisions-package.sh`, that downloads candidate versions newer than 10.11.0 and looks for the type with `MetadataLoadContext`). If none does, the phase records the result: it files one issue titled for the wait, linking dotnet/extensions issue 7764 and PR 7795, sets the phase deferred in the roadmap with the issue number, and stops. The script stays, so the next check is one command.

**If a package exists.** The project swaps the pinned build reference for a `PackageReference` to that version, central in `Directory.Packages.props`; the mapping page and the tests are re-checked against the package, and any identifier that moved is fixed. The project becomes packable, with a beta version suffix through release-please's prerelease handling, a README, `PublicAPI.Shipped` and `Unshipped` files, `tools/release/inspect_packages.py` gets the new dependency, and `pack-validate` passes. The unpacked-until-upstream test from Phase 11.2 is replaced by one that pins the new rule. The release goes out as a minor release through release-please, with ApiCompat clean, and the docs page says how to install it.

## Files / Modules Touched

- `tools/upstream/find-decisions-package.sh` — new.
- In the published case: `src/Minos.NET.Extensions.AI.Decisions/*.csproj`, `Directory.Packages.props`, `tools/release/inspect_packages.py`, `release-please-config.json`, `docs/extensions-ai-decisions/`, `tests/Minos.NET.Extensions.AI.Decisions.Tests/`.

## Tests

- Unit: the script finds the type in a fixture assembly and reports none for one without it.
- Integration: in the published case, `pack-validate` passes and the package installs in the AOT smoke app; in the deferred case, the issue exists and the roadmap links it.

## Open Questions

- Whether a preview package counts as "ships". My call: yes for a beta, because the package is a beta; stable upstream is not required.

## Risks

| Risk | Impact | Mitigation |
|---|---|---|
| Upstream never ships Layer 1 | The phase stays deferred | The milestone closes with it deferred and tracked, and the script makes the recheck cheap |
| Upstream ships under another namespace or shape | The adapter needs rework | The package is re-mapped from the page first, and the change is a normal phase of its own |
