# Conformance Suite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `DecisionError.RequestId`, and a `Minos.NET.Conformance` suite that checks any decision endpoint's shapes, probabilities, errors, request ids and models, replayed in CI against TypeSafe, OpenRouter and OpenAI fixtures and recorded live on `main`.

**Architecture:**
- **The request id first, in the core:** an internal `RequestIdHeader` reads `x-request-id`, `x-typesafe-request-id`, then `request-id`. The shared `DecisionErrorMapper` reads it once for every HTTP error and passes it to the protocol's `MapError`, which sets the new public `DecisionError.RequestId`. Then event 1002 and the evaluation spans carry it.
- **Then the suite, as plain code in `src/Minos.NET.Conformance`,** which references only the core:
  - `ConformanceTarget`, `ModelRule`, `ConformanceProbe`, `CheckResult` and `ConformanceReport`;
  - `ConformanceFixture` and `ConformanceExchange`;
  - the `ConformanceChecks`, pure functions;
  - an `ExchangeCapture` handler and a `FixtureHandler`;
  - the `ConformanceRunner`, with live, record and replay modes.
- **Then the proof:**
  - `tests/Minos.NET.Conformance.Tests` unit-tests every check and replays three fixtures in the normal CI build;
  - `tests/Minos.NET.Live.Tests` records two of them on `main`;
  - a guide page documents it.

**Tech Stack:** .NET 10, C#, System.Text.Json with the source generator, `DelegatingHandler`, Microsoft.Extensions.Logging, ZeroAlloc.Telemetry's `[TraceTagFromResult]`, xUnit 2, ZeroAlloc.TestHelpers' `TextSnapshot`, PublicApiAnalyzers, MarkdownSnippets, Native AOT, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-11-phase-6.6-conformance-suite-design.md`. The spec is binding. This plan applies the "Amendments while planning" below; read them before Task 1.

## Global Constraints

- **Build:** `TreatWarningsAsErrors` is on, and the build must have 0 warnings. Never suppress a diagnostic: no `#pragma warning disable`, no `NoWarn`, no `[SuppressMessage]`, no `.editorconfig` severity change. Fix the cause. Existing `#pragma` lines in test helpers stay as they are.
- **Analyzers that bite in `src/`:**
  - Meziantou: `MA0004` wants `ConfigureAwait(false)` on every await; `MA0002` wants an explicit `StringComparer` on every string-keyed collection; `MA0006` wants `string.Equals` over `==` on strings, in tests too.
  - NetFabric.Hyperlinq: `HLQ012` wants `CollectionsMarshal.AsSpan` to iterate a `List<T>`; `HLQ004` wants `ref readonly` over a span.
  - ZeroAlloc.Analyzers: `ZA0501` forbids boxing a struct enumerator in a loop.

  The code in this plan already passes all of them; keep it that way when you change it.
- **Culture:** the machine's culture is not invariant. Every number written into a report, a log message or a check detail is formatted with `CultureInfo.InvariantCulture`, through `string.Create(CultureInfo.InvariantCulture, …)` or `FormattableString.Invariant`.
- **Public API:** every public change goes in its project's `PublicAPI.Unshipped.txt`. The core gains exactly two lines: `Minos.DecisionError.RequestId.get -> string?` and `Minos.DecisionError.RequestId.init -> void`. `Minos.NET.Conformance` is not shipped in this phase, so it has no PublicAPI files; Phase 8.3 adds them when it packs the tool.
- **No assembly may see two internal types with the same full name** (CS0436). `src/Shared/Rest/*.cs` compiles into both `Minos.NET.SystemOne` and `Minos.NET.OpenAI`. So:

  - neither package grants them `InternalsVisibleTo`;
  - `Minos.NET.Conformance` grants its internals to `Minos.NET.Conformance.Tests` only.

## Amendments while planning

Each one is the smallest correct resolution of a spec detail that could not be built as written. Every task follows them.

1. **E1 accepts `Validation` only.** The spec says "`Validation` or `InvalidRequest`", but there is no `InvalidRequest` kind. `ErrorBodies.KindOf` maps both 400 and 422 to `Validation`.
2. **Event 1002 is written by hand.**
   - **Why:** with `RequestId` it has seven fields. `[LoggerMessage]` emits `LoggerMessage.Define`, which takes at most six. For more, it emits a state struct whose `GetEnumerator` returns a reference type, and NetFabric.Hyperlinq's HLQ006 rejects that in generated code. This was checked by compiling a seven-field `[LoggerMessage]` against this repository's analyzers.
   - **What:** `DecisionLog.EvaluationFailed` keeps its id 1002, its name and its level, and logs through a hand-written `readonly struct` state whose enumerator is a struct. No diagnostic is suppressed.
   - **The template becomes:** `Minos {Operation} on {Model} failed with {ErrorKind}, status {StatusCode}, request id {RequestId}, in {DurationMs} ms: {ErrorMessage}`.
   - **Its readers follow:** `ObservabilityLoggingTests` reads the hand-written event's three constants, and `LogEventIdTests` adds its id.
3. **The request id travels as a `MapError` parameter.**
   - The internal `IDecisionProtocol.MapError` gains `string? requestId`, beside the `retryAfter` it already takes.
   - The shared `DecisionErrorMapper` reads the header once, through the core's `RequestIdHeader`. That is the one core path both adapters share.
   - The raw SystemOne evaluation, which also logs event 1002, tags its span too.
   - Model listing, its event 1005 and its span are unchanged.
4. **`ConformanceTarget` also takes a `ConformanceWire`,** `SystemOne` or `Decisions`. S2 must know whether a Noul is `noul` or `predicate`, and the answers must be read as an object or an array.
5. **`ConformanceTarget.ModelRule` is nullable.**
   - OpenAI's success fixtures come from the guide, whose example names no model, so the OpenAI target states no rule.
   - Without a rule, R2 is skipped, and R1 is skipped when the response names no model.
   - With a rule, a response without a model fails R1.
6. **The report groups the spec's `CheckResult(Id, Outcome, Detail)` by probe.** A `ProbeReport(Probe, Skipped, Checks)` holds each probe's results. E4 reads the whole run, so it is listed under `run`. A skip set is written `probe:check`, such as `noul:D2` or `run:E4`.
7. **A fixture exchange may say `skipped`, with a reason, instead of holding a response.** No real invalid-request body from OpenRouter or OpenAI exists yet, and the plan invents none. Such a probe is neither unknown nor missing: it is skipped with its reason, and its checks appear in the expected skip set. An unknown, repeated or missing probe id still fails the run, with an `InvalidDataException`, before any probe runs.
8. **No request-id value is invented.**
   - **Kept:** the real 401 bodies from the spec's header probe and the bodies earlier live runs captured.
   - **Left out:** their request-id headers, whose values were not kept. Each fixture's `note` says so.
   - **So:** E3 is skipped in every replay, as the spec allows when no header is present. The E3 unit tests cover a pass and a fail.
9. **The header allowlist adds `retry-after-ms`,** which Minos prefers over `Retry-After`, so E4 compares what Minos really read.
10. **The probes avoid what OpenAI cannot send:**
    - Noul `WhenTrue` and `WhenFalse`, which fail as MIN204;
    - criterion examples, which fail as MIN205.

    The `choice` probe has two options, billing and technical, so the guide's two-option example maps onto it without a made-up probability.
11. **A built fixture's exchange may omit `request`,** because replay answers by probe id. A recorded one always has it.
12. **The runner's API:**
    - `RunAsync(target, mode, fixturePath, cancellationToken)` takes the fixture's path. The spec calls it `fixtures`.
    - The `ConformanceRunner` constructor takes the network handler factory and the `TimeProvider`, so the tests can drive `Live` and `Record` offline.
13. **S3's "typed result" is `DecisionResponse.Answers`,** the neutral typed result: each answer's key, kind and chosen position. The suite references only the core, so it cannot use a generated type.
14. **No `[Covers]` is added for `RequestId`.** The AOT entry-point coverage excludes property accessors by design. A functional AOT smoke check proves `RequestId` and its `ToString` under Native AOT instead.

15. **Maintainer rulings on the open questions, 2026-10-11:**
   - Event 1002 is hand-written as in amendment 2, and HLQ006 firing on generated code is filed upstream at NetFabric.Hyperlinq.Analyzer in Task 2, Step 6b.
   - R2 for OpenRouter requires the `typesafe/` or `~typesafe/` prefix: the probes request a TypeSafe model, so an unprefixed model means OpenRouter routed elsewhere, which is a real finding.

```csharp
using Minos.Transport;

namespace Minos.Tests;

public sealed class RequestIdHeaderTests
{
    [Fact]
    public void Names_AreTriedInThisOrder()
        => Assert.Equal(["x-request-id", "x-typesafe-request-id", "request-id"], RequestIdHeader.Names);

    [Theory]
    [InlineData("x-request-id", "req_openai")]
    [InlineData("x-typesafe-request-id", "req_typesafe")]
    [InlineData("request-id", "req_plain")]
    [InlineData("X-TypeSafe-Request-Id", "req_typesafe")]
    public void EachHeader_IsRead_InAnyLetterCase(string name, string value)
        => Assert.Equal(value, RequestIdHeader.Read(Headers((name, value))));

    [Fact]
    public void XRequestId_WinsOverTheOthers_WhateverTheirOrder()
        => Assert.Equal("req_first", RequestIdHeader.Read(Headers(("request-id", "req_third"), ("x-typesafe-request-id", "req_second"), ("x-request-id", "req_first"))));

    [Fact]
    public void XTypeSafeRequestId_WinsOverRequestId()
        => Assert.Equal("req_second", RequestIdHeader.Read(Headers(("request-id", "req_third"), ("x-typesafe-request-id", "req_second"))));

    [Fact]
    public void ABlankValue_FallsThroughToTheNextName()
        => Assert.Equal("req_plain", RequestIdHeader.Read(Headers(("x-request-id", "  "), ("request-id", " req_plain "))));

    [Fact]
    public void OtherHeaders_AreNeverRead()
        => Assert.Null(RequestIdHeader.Read(Headers(("CF-RAY", "8c1f2a3b4c5d6e7f-AMS"), ("x-openrouter-id", "gen-1"), ("Retry-After", "3"))));

    [Fact]
    public void NoHeaders_GiveNull()
        => Assert.Null(RequestIdHeader.Read(new Dictionary<string, IReadOnlyList<string>>(StringComparer.Ordinal)));

    private static Dictionary<string, IReadOnlyList<string>> Headers(params (string Name, string Value)[] headers)
    {
        var map = new Dictionary<string, IReadOnlyList<string>>(StringComparer.Ordinal);
        foreach (var (name, value) in headers)
        {
            map[name] = [value];
        }

        return map;
    }
}
```

```csharp
namespace Minos.Transport;

/// <summary>
/// Reads the provider's request id from an error response's headers: <c>x-request-id</c>, as OpenAI sends it, then
/// <c>x-typesafe-request-id</c>, as TypeSafe sends it, then <c>request-id</c>. Cloudflare's <c>CF-RAY</c> names the CDN
/// hop, not the provider's request, and is never read; nor is a body field such as OpenRouter's <c>id</c>.
/// </summary>
internal static class RequestIdHeader
{
    /// <summary>Gets the header names, in the order they are tried.</summary>
    public static IReadOnlyList<string> Names { get; } = ["x-request-id", "x-typesafe-request-id", "request-id"];

    /// <summary>Returns the first value of the first header in <see cref="Names"/> that is present with a non-blank value.</summary>
    /// <param name="headers">The response headers, by name in any letter case.</param>
    /// <returns>The trimmed request id, or <see langword="null"/> when no such header carries a value.</returns>
    public static string? Read(IReadOnlyDictionary<string, IReadOnlyList<string>> headers)
    {
        ArgumentNullException.ThrowIfNull(headers);
        foreach (var name in Names)
        {
            foreach (var header in headers)
            {
                if (string.Equals(header.Key, name, StringComparison.OrdinalIgnoreCase)
                    && header.Value.Count > 0
                    && !string.IsNullOrWhiteSpace(header.Value[0]))
                {
                    return header.Value[0].Trim();
                }
            }
        }

        return null;
    }
}
```

```csharp
namespace Minos.Conformance;

/// <summary>How a target's reported model must relate to the requested one, for check R2. The report states <see cref="Description"/>.</summary>
public sealed class ModelRule
{
    private const string OpenRouterPrefix = "typesafe/";
    private const string OpenRouterVariantPrefix = "~typesafe/";

    private readonly Func<string, string, bool> _matches;

    /// <summary>Initializes a new instance of the <see cref="ModelRule"/> class.</summary>
    /// <param name="description">The rule in one sentence, for the report.</param>
    /// <param name="matches">Whether a reported model, the second argument, fits the requested one, the first.</param>
    public ModelRule(string description, Func<string, string, bool> matches)
    {
        ArgumentException.ThrowIfNullOrWhiteSpace(description);
        ArgumentNullException.ThrowIfNull(matches);

        Description = description;
        _matches = matches;
    }

    /// <summary>
    /// Gets TypeSafe's rule: the reported model is the requested one or, for an alias such as <c>jev-latest</c>, a
    /// versioned id of the same family, such as <c>jev-1.13.0</c>.
    /// </summary>
    public static ModelRule TypeSafe { get; } = new(
        "The reported model is the requested one or, for an alias such as jev-latest, a versioned id of the same family, such as jev-1.13.0.",
        SameOrVersioned);

    /// <summary>
    /// Gets OpenRouter's rule: TypeSafe's, with the reported model prefixed with <c>typesafe/</c> or <c>~typesafe/</c>,
    /// such as <c>~typesafe/jev-latest</c> or <c>typesafe/jev-1.13-20260917</c>.
    /// </summary>
    public static ModelRule OpenRouter { get; } = new(
        "The reported model is the requested one or a versioned id of its family, prefixed with typesafe/ or ~typesafe/, such as ~typesafe/jev-latest or typesafe/jev-1.13-20260917.",
        static (requested, reported) => WithoutPrefix(reported) is { } bare && SameOrVersioned(WithoutPrefix(requested) ?? requested, bare));

    /// <summary>Gets the rule in one sentence.</summary>
    public string Description { get; }

    /// <summary>Returns whether <paramref name="reported"/> fits <paramref name="requested"/> by this rule.</summary>
    /// <param name="requested">The model the probe asked for.</param>
    /// <param name="reported">The model the response named.</param>
    /// <returns><see langword="true"/> when it fits.</returns>
    public bool Matches(string requested, string reported)
    {
        ArgumentNullException.ThrowIfNull(requested);
        ArgumentNullException.ThrowIfNull(reported);
        return _matches(requested, reported);
    }

    /// <summary>
    /// Whether <paramref name="reported"/> is <paramref name="requested"/>, or <paramref name="requested"/> is an alias, whose
    /// last dash-separated part is letters only, and <paramref name="reported"/> continues its family with a digit.
    /// </summary>
    internal static bool SameOrVersioned(string requested, string reported)
    {
        if (string.Equals(requested, reported, StringComparison.Ordinal))
        {
            return true;
        }

        var dash = requested.LastIndexOf('-');
        if (dash <= 0 || dash == requested.Length - 1 || !IsLetters(requested.AsSpan(dash + 1)))
        {
            return false;
        }

        var family = requested.AsSpan(0, dash + 1);
        return reported.Length > family.Length
            && reported.AsSpan().StartsWith(family, StringComparison.Ordinal)
            && char.IsAsciiDigit(reported[family.Length]);
    }

    private static string? WithoutPrefix(string model)
        => model.StartsWith(OpenRouterVariantPrefix, StringComparison.Ordinal) ? model[OpenRouterVariantPrefix.Length..]
            : model.StartsWith(OpenRouterPrefix, StringComparison.Ordinal) ? model[OpenRouterPrefix.Length..]
            : null;

    private static bool IsLetters(ReadOnlySpan<char> text)
    {
        foreach (ref readonly var c in text)
        {
            if (!char.IsAsciiLetter(c))
            {
                return false;
            }
        }

        return true;
    }
```

```csharp
/// <summary>
/// One HTTP exchange of a probe: the request body, the response status, its media type, its allowlisted headers and its
/// body. In a fixture, an exchange may instead say why its probe is skipped.
/// </summary>
public sealed class ConformanceExchange
{
    /// <summary>Gets the probe's id.</summary>
    public required string Probe { get; init; }

    /// <summary>Gets the date this exchange was recorded, as <c>yyyy-MM-dd</c>, when it differs from the fixture's own; otherwise <see langword="null"/>.</summary>
    public string? Recorded { get; init; }

    /// <summary>Gets why the probe is skipped when the fixture has no exchange for it yet, or <see langword="null"/>.</summary>
    public string? Skipped { get; init; }

    /// <summary>Gets the request body, as JSON, or <see langword="null"/> when it was not kept.</summary>
    public JsonElement? Request { get; init; }

    /// <summary>Gets the response's HTTP status, or <see langword="null"/> for a skipped probe.</summary>
    public int? Status { get; init; }

    /// <summary>Gets the response's <c>Content-Type</c>, or <see langword="null"/> when it had none.</summary>
    public string? ContentType { get; init; }

    /// <summary>Gets the allowlisted response headers by lower-case name, or <see langword="null"/> when there were none.</summary>
    public IReadOnlyDictionary<string, string>? Headers { get; init; }

    /// <summary>Gets the response body: its JSON when <see cref="ContentType"/> is JSON and it parses, otherwise a JSON string holding its text.</summary>
    public JsonElement? Response { get; init; }

    /// <summary>Gets whether <see cref="Status"/> is 2xx.</summary>
    public bool IsSuccess => Status is >= 200 and < 300;

    /// <summary>Builds an exchange from what went over the wire.</summary>
    /// <param name="probe">The probe's id.</param>
    /// <param name="requestBody">The request body, or <see langword="null"/>.</param>
    /// <param name="status">The response status.</param>
    /// <param name="contentType">The response's <c>Content-Type</c>, or <see langword="null"/>.</param>
    /// <param name="headers">The allowlisted response headers, or <see langword="null"/>.</param>
    /// <param name="responseBody">The response body as text.</param>
    /// <returns>The exchange.</returns>
    public static ConformanceExchange FromHttp(
        string probe, string? requestBody, int status, string? contentType, IReadOnlyDictionary<string, string>? headers, string responseBody)
    {
        ArgumentException.ThrowIfNullOrWhiteSpace(probe);
        ArgumentNullException.ThrowIfNull(responseBody);

        return new ConformanceExchange
        {
            Probe = probe,
            Request = requestBody is not null && TryParse(requestBody, out var request) ? request : null,
            Status = status,
            ContentType = contentType,
            Headers = headers is { Count: > 0 } ? headers : null,
            Response = IsJson(contentType) && TryParse(responseBody, out var json)
                ? json
                : JsonSerializer.SerializeToElement(responseBody, ConformanceJsonContext.Default.String),
        };
    }

    /// <summary>Gets the first header of <paramref name="name"/>, in any letter case, or <see langword="null"/>.</summary>
    /// <param name="name">The header name.</param>
    /// <returns>Its value, or <see langword="null"/>.</returns>
    public string? Header(string name)
    {
        if (Headers is null)
        {
            return null;
        }

        foreach (var header in Headers)
        {
            if (string.Equals(header.Key, name, StringComparison.OrdinalIgnoreCase))
            {
                return header.Value;
            }
        }

        return null;
    }

    /// <summary>Gets the response body as the text that was sent.</summary>
    /// <returns>The body, or an empty string when there is none.</returns>
    public string ResponseText()
        => Response is not { } body ? string.Empty
            : !IsJson(ContentType) && body.ValueKind == JsonValueKind.String ? body.GetString() ?? string.Empty
            : body.GetRawText();

    /// <summary>Gets the response body as JSON, when it is JSON.</summary>
    /// <param name="body">The body.</param>
    /// <returns><see langword="true"/> when <see cref="ContentType"/> is JSON and the body is not kept as text.</returns>
    public bool TryGetJson(out JsonElement body)
    {
        if (Response is { } response && IsJson(ContentType))
        {
            body = response;
            return true;
        }

        body = default;
        return false;
    }

    /// <summary>Gets whether a <c>Content-Type</c> is JSON: <c>application/json</c> or a <c>+json</c> type, parameters aside.</summary>
    /// <param name="contentType">The header value, or <see langword="null"/>.</param>
    /// <returns><see langword="true"/> for JSON.</returns>
    internal static bool IsJson(string? contentType)
    {
        if (contentType is null)
        {
            return false;
        }

        var semicolon = contentType.IndexOf(';', StringComparison.Ordinal);
        var mediaType = (semicolon < 0 ? contentType : contentType[..semicolon]).Trim();
        return string.Equals(mediaType, "application/json", StringComparison.OrdinalIgnoreCase)
            || mediaType.EndsWith("+json", StringComparison.OrdinalIgnoreCase);
    }

    private static bool TryParse(string text, out JsonElement element)
    {
        try
        {
            using var document = JsonDocument.Parse(text);
            element = document.RootElement.Clone();
            return true;
        }
        catch (JsonException)
        {
            element = default;
            return false;
        }
    }
}
```

```csharp
/// <summary>A run's result: the target, the model, the mode, the fixture's source and date, and every check's result. Written as JSON and as markdown.</summary>

    /// <summary>Gets the target's wire format.</summary>

    [JsonIgnore]

    /// <summary>Gets the skipped checks, each as <c>probe:check</c>, in report order; E4 is <c>run:E4</c>.</summary>
    [JsonIgnore]
    public IReadOnlyList<string> SkippedChecks => Named(CheckOutcome.Skipped);

    /// <summary>Reads a report from its JSON.</summary>
    /// <param name="json">The JSON.</param>
    /// <returns>The report.</returns>
    /// <exception cref="InvalidDataException">The JSON is <c>null</c>.</exception>
    public static ConformanceReport FromJson(string json)
        => JsonSerializer.Deserialize(json, ConformanceJson.Readable.ConformanceReport)

    /// <returns>The JSON.</returns>
    public string ToJson() => JsonSerializer.Serialize(this, ConformanceJson.Readable.ConformanceReport) + "\n";

    /// <summary>Writes the report as markdown: a summary list and one table row per check.</summary>
    /// <returns>The markdown.</returns>
    public string ToMarkdown()
    {
        var text = new StringBuilder();
        text.Append("# Conformance: ").Append(Target).Append("\n\n");
        text.Append("- Mode: ").Append(Mode.ToString()).Append('\n');
        text.Append("- Wire: ").Append(Wire.ToString()).Append('\n');
        text.Append("- Model: `").Append(Model).Append("`\n");

            text.Append(", recorded ").Append(recorded);
        }

        text.Append('\n');
        text.Append(CultureInfo.InvariantCulture, $"- Result: {Passed} passed, {Failed} failed, {Skipped} skipped").Append("\n\n");

            foreach (var check in probe.Checks)
            {
                Row(text, probe.Probe, check);
            }
        }

        foreach (var check in RunChecks)

        }

            .Append(" | ").Append(check.Id)
            .Append(" | ").Append(OutcomeText(check.Outcome))
            .Append(" | ").Append(check.Detail.Replace("|", "\\|", StringComparison.Ordinal))
            .Append(" |\n");

        CheckOutcome.Pass => "pass",
        CheckOutcome.Fail => "fail",
        _ => "skipped",

        var count = 0;
        foreach (var probe in Probes)
        {
            foreach (var check in probe.Checks)
            {
                count += check.Outcome == outcome ? 1 : 0;
            }
        }

        foreach (var check in RunChecks)
        {
            count += check.Outcome == outcome ? 1 : 0;
        }

        return count;
    }

    private List<string> Named(CheckOutcome outcome)
    {
        var named = new List<string>();
        foreach (var probe in Probes)
        {
            foreach (var check in probe.Checks)
            {
                if (check.Outcome == outcome)
                {
                    named.Add(probe.Probe + ":" + check.Id);
                }
            }
        }

        foreach (var check in RunChecks)
        {
            if (check.Outcome == outcome)
            {
                named.Add(RunScope + ":" + check.Id);
            }
        }

        return named;
    }
```

```csharp
using System.Text.Json;

namespace Minos.Conformance.Tests;

/// <summary>Hand-made outcomes for the check tests: a wire body, and what Minos read, made separately so a test can make them disagree.</summary>
internal static class Outcomes
{
    public static ConformanceTarget SystemOneTarget { get; } = Target(ConformanceWire.SystemOne, "jev-latest", ModelRule.TypeSafe);

    public static ConformanceTarget DecisionsTarget { get; } = Target(ConformanceWire.Decisions, "gpt-6-luna", modelRule: null);

    public static ConformanceTarget Target(ConformanceWire wire, string model, ModelRule? modelRule)
        => new("test", wire, model, modelRule, _ => throw new InvalidOperationException("The check tests never create a client."));

    /// <summary>A probe that answered: one exchange with <paramref name="body"/>, and Minos's own reading.</summary>
    public static ProbeOutcome Answered(ConformanceProbe probe, string body, DecisionResponse? response, int status = 200, params (string Name, string Value)[] headers)
        => new(probe, [Exchange(probe, status, body, headers)], response, error: null);

    /// <summary>A probe that failed: one exchange with <paramref name="body"/>, and Minos's error.</summary>
    public static ProbeOutcome Failed(ConformanceProbe probe, int status, string body, DecisionError? error, params (string Name, string Value)[] headers)
        => new(probe, [Exchange(probe, status, body, headers)], response: null, error);

    public static ConformanceExchange Exchange(ConformanceProbe probe, int status, string body, params (string Name, string Value)[] headers)
        => ConformanceExchange.FromHttp(
            probe.Id,
            requestBody: null,
            status,
            "application/json",
            headers.Length == 0 ? null : headers.ToDictionary(h => h.Name, h => h.Value, StringComparer.Ordinal),
            body);

    public static DecisionError Error(DecisionErrorKind kind, int status, string body, string? requestId = null, TimeSpan? retryAfter = null)
    {
        using var document = JsonDocument.Parse(body);
        return new DecisionError(kind, "The API returned HTTP " + status + ".")
        {
            StatusCode = status,
            Detail = document.RootElement.Clone(),
            RequestId = requestId,
            RetryAfter = retryAfter,
        };
    }

    public static DecisionResponse Noul(double value, string? model = "jev-1.13.0")
        => new(ConformanceProbe.Noul.Definition, [QuestionAnswer.Noul(value)], model);

    public static DecisionResponse Choice(int chosen, double[] probabilities, string? model = "jev-1.13.0")
        => new(ConformanceProbe.Choice.Definition, [QuestionAnswer.Choice(chosen, 0.81, probabilities)], model);

    public static DecisionResponse Score(int level, double value, double[] probabilities, string? model = "jev-1.13.0")
        => new(ConformanceProbe.Score.Definition, [QuestionAnswer.Score(level, value, 0.92, probabilities)], model);

    public static DecisionResponse Mixed(double urgent, int department, double frustration)
        => new(
            ConformanceProbe.Mixed.Definition,
            [QuestionAnswer.Noul(urgent), QuestionAnswer.Choice(department, 0.81, [0.88, 0.12]), QuestionAnswer.Score(1, frustration, 0.92, [0.0, 0.95, 0.05])],
            "jev-1.13.0");

    public const string NoulBody = """{"model":"jev-1.13.0","answers":{"is_urgent":{"type":"noul","noul":0.95}},"usage":{"input_tokens":296,"output_tokens":20}}""";

    public const string ChoiceBody = """{"model":"jev-1.13.0","answers":{"department":{"type":"choice","choice":"billing","probabilities":{"billing":0.88,"technical":0.12},"confidence":0.81}}}""";

    public const string ScoreBody = """{"model":"jev-1.13.0","answers":{"frustration":{"type":"score","score":1.05,"probabilities":{"0":0.0,"1":0.95,"2":0.05},"confidence":0.92}}}""";

    // In alphabetical order, while the probe asks is_urgent, department, frustration.
    public const string MixedBody = """{"model":"jev-1.13.0","answers":{"department":{"type":"choice","choice":"billing","probabilities":{"billing":0.88,"technical":0.12},"confidence":0.81},"frustration":{"type":"score","score":1.05,"probabilities":{"0":0.0,"1":0.95,"2":0.05},"confidence":0.92},"is_urgent":{"type":"noul","noul":0.95}}}""";
```

```csharp
namespace Minos.Conformance;

/// <summary>What a probe did: the exchanges that went over the wire, in order, and what Minos returned.</summary>
public sealed class ProbeOutcome
{
    /// <summary>Initializes a new instance of the <see cref="ProbeOutcome"/> class.</summary>
    /// <param name="probe">The probe.</param>
    /// <param name="exchanges">The exchanges, in the order they were sent; more than one when the client retried.</param>
    /// <param name="response">Minos's response, or <see langword="null"/> when it returned an error.</param>
    /// <param name="error">Minos's error, or <see langword="null"/> when it returned a response.</param>
    public ProbeOutcome(ConformanceProbe probe, IReadOnlyList<ConformanceExchange> exchanges, DecisionResponse? response, DecisionError? error)
    {
        ArgumentNullException.ThrowIfNull(probe);
        ArgumentNullException.ThrowIfNull(exchanges);

        Probe = probe;
        Exchanges = exchanges;
        Response = response;
        Error = error;
    }

    /// <summary>Gets the probe.</summary>
    public ConformanceProbe Probe { get; }

    /// <summary>Gets the exchanges, in the order they were sent.</summary>
    public IReadOnlyList<ConformanceExchange> Exchanges { get; }

    /// <summary>Gets Minos's response, or <see langword="null"/>.</summary>
    public DecisionResponse? Response { get; }

    /// <summary>Gets Minos's error, or <see langword="null"/>.</summary>
    public DecisionError? Error { get; }

    /// <summary>Gets the last exchange, the one whose result Minos returned, or <see langword="null"/> when nothing was sent.</summary>
    public ConformanceExchange? Last => Exchanges.Count == 0 ? null : Exchanges[^1];
}
```

```csharp
using System.Runtime.InteropServices;
using System.Text.Json;

namespace Minos.Conformance;

/// <summary>One answer as the response sent it: the question key it names, its <c>type</c> and its JSON.</summary>
/// <param name="Key">The question key: the property name on System One, <c>name</c> on Decisions.</param>
/// <param name="Type">The <c>type</c>, or <see langword="null"/> when it is missing or not a string.</param>
/// <param name="Body">The answer's JSON.</param>
internal sealed record WireAnswer(string Key, string? Type, JsonElement Body)
{
    /// <summary>Gets a property, when the answer is an object and has it.</summary>
    public bool TryGet(string property, out JsonElement value)
    {
        if (Body.ValueKind == JsonValueKind.Object && Body.TryGetProperty(property, out value))
        {
            return true;
        }

        value = default;
        return false;
    }

    /// <summary>Gets a string property, or <see langword="null"/>.</summary>
    public string? Text(string property) => TryGet(property, out var value) && value.ValueKind == JsonValueKind.String ? value.GetString() : null;

    /// <summary>
    /// Reads the probabilities by option key: an object of numbers on System One, an array of <c>value</c>,
    /// <c>label</c> and <c>probability</c> on Decisions, keyed by the label when there is one. A value that is not a number
    /// is kept as <see langword="null"/>, so D1 can name it.
    /// </summary>
    /// <returns>The probabilities, or <see langword="null"/> when they are missing or not in the wire's shape.</returns>
    public List<(string Key, double? Value)>? Probabilities(ConformanceWire wire)
    {
        if (!TryGet("probabilities", out var probabilities))
        {
            return null;
        }

        var read = new List<(string Key, double? Value)>();
        if (wire == ConformanceWire.SystemOne)
        {
            if (probabilities.ValueKind != JsonValueKind.Object)
            {
                return null;
            }

            foreach (var property in probabilities.EnumerateObject())
            {
                read.Add((property.Name, Number(property.Value)));
            }

            return read;
        }

        if (probabilities.ValueKind != JsonValueKind.Array)
        {
            return null;
        }

        foreach (var entry in probabilities.EnumerateArray())
        {
            if (entry.ValueKind != JsonValueKind.Object)
            {
                return null;
            }

            var key = entry.TryGetProperty("label", out var label) && label.ValueKind == JsonValueKind.String ? label.GetString()
                : entry.TryGetProperty("value", out var value) && value.ValueKind is JsonValueKind.String ? value.GetString()
                : entry.TryGetProperty("value", out value) && value.ValueKind is JsonValueKind.Number ? value.GetRawText()
                : null;
            if (key is null)
            {
                return null;
            }

            read.Add((key, entry.TryGetProperty("probability", out var probability) ? Number(probability) : null));
        }

        return read;
    }

    /// <summary>Gets a number property that is finite, or <see langword="null"/>.</summary>
    public double? Number(string property) => TryGet(property, out var value) ? Number(value) : null;

    private static double? Number(JsonElement value)
        => value.ValueKind == JsonValueKind.Number && value.TryGetDouble(out var number) && double.IsFinite(number) ? number : null;
}

/// <summary>Reads a response body's answers in either wire format, without Minos, so the checks can compare the two.</summary>
internal static class WireAnswers
{
    /// <summary>The <c>type</c> a question kind has on a wire: Noul is <c>noul</c> on System One and <c>predicate</c> on Decisions.</summary>
    public static string TypeOf(QuestionKind kind, ConformanceWire wire) => kind switch
    {
        QuestionKind.Noul => wire == ConformanceWire.SystemOne ? "noul" : "predicate",
        QuestionKind.Choice => "choice",
        _ => "score",
    };

    /// <summary>The property holding a Noul's probability: <c>noul</c> on System One, <c>probability</c> on Decisions.</summary>
    public static string NoulProperty(ConformanceWire wire) => wire == ConformanceWire.SystemOne ? "noul" : "probability";

    /// <summary>Reads the last exchange's body as a JSON object.</summary>
    public static bool TryBody(ProbeOutcome outcome, out JsonElement body, out string problem)
    {
        body = default;
        if (outcome.Last is not { } last)
        {
            problem = "No request was sent" + (outcome.Error is { } error ? ": " + error.Kind.ToString() + ", " + error.Message : ".");
            return false;
        }

        if (!last.TryGetJson(out body) || body.ValueKind != JsonValueKind.Object)
        {
            problem = "The response body is not a JSON object.";
            return false;
        }

        problem = string.Empty;
        return true;
    }

    /// <summary>Reads the answers of the last exchange's body, in the order they were sent.</summary>
    public static bool TryRead(ProbeOutcome outcome, ConformanceWire wire, out List<WireAnswer> answers, out string problem)
    {
        answers = [];
        if (!TryBody(outcome, out var body, out problem))
        {
            return false;
        }

        if (!body.TryGetProperty("answers", out var list))
        {
            problem = "The response has no answers.";
            return false;
        }

        if (wire == ConformanceWire.SystemOne)
        {
            if (list.ValueKind != JsonValueKind.Object)
            {
                problem = "The answers are not a JSON object keyed by question.";
                return false;
            }

            foreach (var answer in list.EnumerateObject())
            {
                answers.Add(new WireAnswer(answer.Name, TypeText(answer.Value), answer.Value));
            }

            return true;
        }

        if (list.ValueKind != JsonValueKind.Array)
        {
            problem = "The answers are not a JSON array.";
            return false;
        }

        foreach (var answer in list.EnumerateArray())
        {
            var name = answer.ValueKind == JsonValueKind.Object && answer.TryGetProperty("name", out var key) && key.ValueKind == JsonValueKind.String
                ? key.GetString() ?? string.Empty
                : string.Empty;
            answers.Add(new WireAnswer(name, TypeText(answer), answer));
        }

        return true;
    }

    /// <summary>Finds the one answer for a key, or <see langword="null"/>.</summary>
    public static WireAnswer? Find(List<WireAnswer> answers, string key)
    {
        foreach (ref readonly var answer in CollectionsMarshal.AsSpan(answers))
        {
            if (string.Equals(answer.Key, key, StringComparison.Ordinal))
            {
                return answer;
            }
        }

        return null;
    }

    private static string? TypeText(JsonElement answer)
        => answer.ValueKind == JsonValueKind.Object && answer.TryGetProperty("type", out var type) && type.ValueKind == JsonValueKind.String
            ? type.GetString()
            : null;
}
```

```csharp
using System.Globalization;
using System.Runtime.InteropServices;
using System.Text.Json;

namespace Minos.Conformance;

/// <summary>
/// The checks: pure functions over one probe's exchanges and what Minos returned, except E4, which reads the whole run.
/// Each returns pass, fail or skipped; a check that cannot run is skipped, never passed.
/// </summary>
public static class ConformanceChecks
{
    /// <summary>How far a sum or an expected level may be from its target: 0.01.</summary>
    public const double Tolerance = 0.01;

    // Floating-point slack, so a sum that is 0.01 off on paper, such as 0.5 + 0.49, is still within the tolerance.
    private const double Rounding = 1e-9;

    private static readonly Check[] PerProbe =
    [
        new("S1", IsAnswer, static (outcome, target) => S1(outcome, target.Wire)),
        new("S2", IsAnswer, static (outcome, target) => S2(outcome, target.Wire)),
        new("S3", IsAnswer, static (outcome, _) => S3(outcome)),
        new("D1", IsAnswer, static (outcome, target) => D1(outcome, target.Wire)),
        new("D2", IsAnswer, static (outcome, target) => D2(outcome, target.Wire)),
        new("D3", IsAnswer, static (outcome, target) => D3(outcome, target.Wire)),
        new("D4", IsAnswer, static (outcome, target) => D4(outcome, target.Wire)),
        new("M1", static probe => string.Equals(probe.Id, ConformanceProbe.Mixed.Id, StringComparison.Ordinal), static (outcome, target) => M1(outcome, target.Wire)),
        new("E1", static probe => probe.Kind == ProbeKind.Invalid, static (outcome, _) => E1(outcome)),
        new("E2", static probe => probe.Kind == ProbeKind.BadKey, static (outcome, _) => E2(outcome)),
        new("E3", static probe => probe.Kind != ProbeKind.Answer, static (outcome, _) => E3(outcome)),
        new("R1", IsAnswer, R1),
        new("R2", IsAnswer, R2),
        new("R3", IsAnswer, static (outcome, _) => R3(outcome)),
    ];

    /// <summary>Gets every check id, in the order the report lists them; E4 reads the whole run.</summary>
    public static IReadOnlyList<string> Ids { get; } = ["S1", "S2", "S3", "D1", "D2", "D3", "D4", "M1", "E1", "E2", "E3", "E4", "R1", "R2", "R3"];

    /// <summary>Gets the request-id headers E3 and E4 read, in the order <see cref="DecisionError.RequestId"/> reads them.</summary>
    public static IReadOnlyList<string> RequestIdHeaders { get; } = ["x-request-id", "x-typesafe-request-id", "request-id"];

    /// <summary>Gets the ids of the checks that apply to a probe, in report order.</summary>
    /// <param name="probe">The probe.</param>
    /// <returns>The ids.</returns>
    public static IReadOnlyList<string> For(ConformanceProbe probe)
    {
        ArgumentNullException.ThrowIfNull(probe);
        var ids = new List<string>();
        foreach (var check in PerProbe)
        {
            if (check.AppliesTo(probe))
            {
                ids.Add(check.Id);
            }
        }

        return ids;
    }

    /// <summary>Runs every check that applies to the outcome's probe.</summary>
    /// <param name="outcome">What the probe did.</param>
    /// <param name="target">The target, for its wire format and model rule.</param>
    /// <returns>The results, in report order.</returns>
    public static IReadOnlyList<CheckResult> Run(ProbeOutcome outcome, ConformanceTarget target)
    {
        ArgumentNullException.ThrowIfNull(outcome);
        ArgumentNullException.ThrowIfNull(target);
        var results = new List<CheckResult>();
        foreach (var check in PerProbe)
        {
            if (check.AppliesTo(outcome.Probe))
            {
                results.Add(check.Run(outcome, target));
            }
        }

        return results;
    }

    /// <summary>Skips every check that applies to a probe that did not run.</summary>
    /// <param name="probe">The probe.</param>
    /// <param name="reason">Why it did not run.</param>
    /// <returns>The results, each skipped with <paramref name="reason"/>.</returns>
    public static IReadOnlyList<CheckResult> Skipped(ConformanceProbe probe, string reason)
    {
        var results = new List<CheckResult>();
        foreach (var id in For(probe))
        {
            results.Add(CheckResult.Skip(id, reason));
        }

        return results;
    }

    /// <summary>S1: the response is a JSON object with exactly one answer per question asked.</summary>
    /// <param name="outcome">What the probe did.</param>
    /// <param name="wire">The target's wire format.</param>
    /// <returns>The result.</returns>
    public static CheckResult S1(ProbeOutcome outcome, ConformanceWire wire)
    {
        ArgumentNullException.ThrowIfNull(outcome);
        if (outcome.Last is { IsSuccess: false } last)
        {
            return CheckResult.Failed("S1", "HTTP " + StatusText(last) + ": the response is an error, not answers.");
        }

        if (!WireAnswers.TryRead(outcome, wire, out var answers, out var problem))
        {
            return outcome.Last is null ? CheckResult.Skip("S1", problem) : CheckResult.Failed("S1", problem);
        }

        var questions = outcome.Probe.Definition.Questions;
        var seen = new HashSet<string>(StringComparer.Ordinal);
        var problems = new List<string>();
        foreach (ref readonly var answer in CollectionsMarshal.AsSpan(answers))
        {
            if (Question(outcome.Probe, answer.Key) is null)
            {
                problems.Add("an answer for '" + answer.Key + "', which was not asked");
            }
            else if (!seen.Add(answer.Key))
            {
                problems.Add("two answers for '" + answer.Key + "'");
            }
        }

        foreach (var question in questions)
        {
            if (!seen.Contains(question.Key))
            {
                problems.Add("no answer for '" + question.Key + "'");
            }
        }

        return problems.Count == 0
            ? CheckResult.Passed("S1", Invariant($"One answer for each question asked, {questions.Count} in all."))
            : CheckResult.Failed("S1", Sentence(problems));
    }

    /// <summary>S2: each answer's type matches its question: Noul is <c>noul</c> on System One and <c>predicate</c> on Decisions; Choice and Score are <c>choice</c> and <c>score</c> on both.</summary>
    /// <param name="outcome">What the probe did.</param>
    /// <param name="wire">The target's wire format.</param>
    /// <returns>The result.</returns>
    public static CheckResult S2(ProbeOutcome outcome, ConformanceWire wire)
    {
        ArgumentNullException.ThrowIfNull(outcome);
        if (!WireAnswers.TryRead(outcome, wire, out var answers, out var problem))
        {
            return CheckResult.Skip("S2", problem);
        }

        var problems = new List<string>();
        foreach (var question in outcome.Probe.Definition.Questions)
        {
            var expected = WireAnswers.TypeOf(question.Kind, wire);
            if (WireAnswers.Find(answers, question.Key) is { } answer && !string.Equals(answer.Type, expected, StringComparison.Ordinal))
            {
                problems.Add("'" + question.Key + "' is " + (answer.Type is null ? "untyped" : "'" + answer.Type + "'") + ", not '" + expected + "'");
            }
        }

        return problems.Count == 0
            ? CheckResult.Passed("S2", "Each answer has its question's type.")
            : CheckResult.Failed("S2", Sentence(problems));
    }

    /// <summary>S3: Minos reads the response without an error, and its result reads every key with its kind.</summary>
    /// <param name="outcome">What the probe did.</param>
    /// <returns>The result.</returns>
    public static CheckResult S3(ProbeOutcome outcome)
    {
        ArgumentNullException.ThrowIfNull(outcome);
        if (outcome.Error is { } error)
        {
            return CheckResult.Failed("S3", "Minos returned " + error.Kind.ToString() + ": " + error.Message);
        }

        if (outcome.Response is not { } response)
        {
            return CheckResult.Failed("S3", "Minos returned no response.");
        }

        var questions = outcome.Probe.Definition.Questions;
        var read = response.Answers;
        if (read.Count != questions.Count)
        {
            return CheckResult.Failed("S3", Invariant($"Minos read {read.Count} answers for {questions.Count} questions."));
        }

        var problems = new List<string>();
        for (var i = 0; i < questions.Count; i++)
        {
            var question = questions[i];
            var answer = read[i];
            if (!string.Equals(answer.Key, question.Key, StringComparison.Ordinal))
            {
                problems.Add(Invariant($"answer {i} is '{answer.Key}', not '{question.Key}'"));
            }
            else if (answer.Kind != question.Kind)
            {
                problems.Add("'" + question.Key + "' was read as a " + answer.Kind.ToString() + ", not a " + question.Kind.ToString());
            }
            else if (question.Kind != QuestionKind.Noul && (answer.ChosenIndex < 0 || answer.ChosenIndex >= question.Options.Count))
            {
                problems.Add(Invariant($"'{question.Key}' chose position {answer.ChosenIndex} of {question.Options.Count}"));
            }
        }

        return problems.Count == 0
            ? CheckResult.Passed("S3", Invariant($"Minos read every answer by key, {questions.Count} in all."))
            : CheckResult.Failed("S3", Sentence(problems));
    }

    /// <summary>D1: every probability is finite and in [0, 1].</summary>
    /// <param name="outcome">What the probe did.</param>
    /// <param name="wire">The target's wire format.</param>
    /// <returns>The result.</returns>
    public static CheckResult D1(ProbeOutcome outcome, ConformanceWire wire)
    {
        ArgumentNullException.ThrowIfNull(outcome);
        if (!WireAnswers.TryRead(outcome, wire, out var answers, out var problem))
        {
            return CheckResult.Skip("D1", problem);
        }

        var count = 0;
        var problems = new List<string>();
        foreach (var question in outcome.Probe.Definition.Questions)
        {
            if (WireAnswers.Find(answers, question.Key) is not { } answer)
            {
                continue;
            }

            if (question.Kind == QuestionKind.Noul)
            {
                count++;
                var value = answer.Number(WireAnswers.NoulProperty(wire));
                if (value is not { } probability)
                {
                    problems.Add("'" + question.Key + "' has no finite " + WireAnswers.NoulProperty(wire));
                }
                else if (probability is < 0 or > 1)
                {
                    problems.Add(Invariant($"'{question.Key}' is {probability}"));
                }

                continue;
            }

            if (answer.Probabilities(wire) is not { } probabilities)
            {
                problems.Add("'" + question.Key + "' has no probabilities");
                continue;
            }

            foreach (var (key, value) in probabilities)
            {
                count++;

    /// <param name="outcome">What the probe did.</param>
    /// <returns>The result.</returns>

    {
        ArgumentNullException.ThrowIfNull(outcome);
        if (outcome.Response is null)
        {
            return CheckResult.Skip("R3", "Minos returned an error; S3 reports it.");
        }

        if (!WireAnswers.TryBody(outcome, out var body, out var problem))
        {
            return CheckResult.Skip("R3", problem);
        }

        if (!body.TryGetProperty("usage", out var usage) || usage.ValueKind == JsonValueKind.Null)
        {
            return CheckResult.Skip("R3", "The response reports no usage.");
        }

        if (usage.ValueKind != JsonValueKind.Object)
        {
            return CheckResult.Failed("R3", "The usage is not a JSON object.");
        }

        var counts = new List<string>();
        var problems = new List<string>();
        foreach (var property in usage.EnumerateObject())
        {
            if (!property.Name.EndsWith("_tokens", StringComparison.Ordinal))
            {
                continue;
            }

            if (property.Value.ValueKind == JsonValueKind.Number && property.Value.TryGetInt64(out var tokens) && tokens >= 0)
            {
                counts.Add(Invariant($"{property.Name} {tokens}"));
            }
            else
            {
                problems.Add(property.Name + " is " + property.Value.GetRawText());
            }
        }

        if (problems.Count > 0)
        {
            return CheckResult.Failed("R3", Sentence(problems));
        }

        return counts.Count == 0
            ? CheckResult.Skip("R3", "The usage reports no token counts.")
            : CheckResult.Passed("R3", string.Join(", ", counts) + ".");
    }

    // retry-after-ms wins, as Minos reads it; a delta-seconds Retry-After gives an exact wait, an HTTP date only a present one.
    private static (bool Present, TimeSpan? Exact) RetryAfterOf(ConformanceExchange exchange)
    {
        if (exchange.Header("retry-after-ms") is { } milliseconds
            && double.TryParse(milliseconds.Trim(), NumberStyles.AllowDecimalPoint, CultureInfo.InvariantCulture, out var ms)
            && double.IsFinite(ms))
        {
            return (true, TimeSpan.FromMilliseconds(ms));
        }

        if (exchange.Header("retry-after") is not { } value)
        {
            return (false, null);
        }

        return ulong.TryParse(value.Trim(), NumberStyles.None, CultureInfo.InvariantCulture, out var seconds) && seconds <= int.MaxValue / 1000
            ? (true, TimeSpan.FromSeconds(seconds))
            : (true, null);
    }

    private static string NotSent(ProbeOutcome outcome)
        => "No request was sent" + (outcome.Error is { } error ? ": " + error.Kind.ToString() + ", " + error.Message : ".");

    private static string StatusText(ConformanceExchange exchange)
        => exchange.Status?.ToString(CultureInfo.InvariantCulture) ?? "without a status";

    private static string Chosen(QuestionDefinition question, QuestionAnswer answer)
        => answer.ChosenIndex >= 0 && answer.ChosenIndex < question.Options.Count ? question.Options[answer.ChosenIndex].Key : "nothing";

    private static bool Within(double actual, double expected) => Math.Abs(actual - expected) <= Tolerance + Rounding;

    private static bool SameNumber(double read, double? sent) => sent is { } value && Math.Abs(read - value) <= Rounding;

    private static string Shown(double? value) => value is { } number ? number.ToString(CultureInfo.InvariantCulture) : "nothing";

    private static string Invariant(FormattableString text) => FormattableString.Invariant(text);

    private static string Sentence(List<string> problems)
    {
        var text = string.Join("; ", problems);
        return string.Concat(text[..1].ToUpperInvariant(), text.AsSpan(1), ".");
    }
```

```csharp
using System.Net.Http.Headers;

namespace Minos.Conformance;

/// <summary>
/// Records each exchange of the probe in progress: the request body, the response status, its media type, its body and
/// an allowlist of headers, the request ids and the two retry-after forms. It never records <c>Authorization</c>,
/// <c>x-api-key</c> or any other header. For the bad-key probe it replaces the key with <see cref="InvalidKey"/>, so no
/// target needs a factory of its own for it.
/// </summary>
public sealed class ExchangeCapture : DelegatingHandler
{
    /// <summary>The key the bad-key probe sends.</summary>
    public const string InvalidKey = "minos-conformance-invalid-key";

    /// <summary>The request option that tells the fixture handler which probe a request belongs to.</summary>
    internal static readonly HttpRequestOptionsKey<string> ProbeOption = new("minos.conformance.probe");

    private readonly List<ConformanceExchange> _exchanges = [];
    private ConformanceProbe? _probe;

    /// <summary>Initializes a new instance of the <see cref="ExchangeCapture"/> class.</summary>
    /// <param name="innerHandler">The handler that sends the requests: the network, or a fixture.</param>
    public ExchangeCapture(HttpMessageHandler innerHandler)
        : base(innerHandler)
    {
    }

    /// <summary>Gets the response headers an exchange keeps, by lower-case name.</summary>
    public static IReadOnlyList<string> RecordedHeaders { get; } = ["x-request-id", "x-typesafe-request-id", "request-id", "retry-after", "retry-after-ms"];

    /// <summary>Starts recording a probe's exchanges.</summary>
    /// <param name="probe">The probe whose requests follow.</param>
    public void Begin(ConformanceProbe probe)
    {
        ArgumentNullException.ThrowIfNull(probe);
        _probe = probe;
        _exchanges.Clear();
    }

    /// <summary>Stops recording and returns the probe's exchanges, in the order they were sent.</summary>
    /// <returns>The exchanges.</returns>
    public IReadOnlyList<ConformanceExchange> End()
    {
        var exchanges = _exchanges.ToArray();
        _exchanges.Clear();
        _probe = null;
        return exchanges;
    }

    /// <inheritdoc />
    protected override async Task<HttpResponseMessage> SendAsync(HttpRequestMessage request, CancellationToken cancellationToken)
    {
        ArgumentNullException.ThrowIfNull(request);
        var probe = _probe ?? throw new InvalidOperationException("A request was sent outside a probe; call Begin first.");
        if (probe.Kind == ProbeKind.BadKey)
        {
            SwapKey(request);
        }

        request.Options.Set(ProbeOption, probe.Id);

        // Reading the content buffers it, so the bytes kept here are the bytes sent below.
        var requestBody = request.Content is null ? null : await request.Content.ReadAsStringAsync(cancellationToken).ConfigureAwait(false);
        var response = await base.SendAsync(request, cancellationToken).ConfigureAwait(false);
        var responseBody = await response.Content.ReadAsStringAsync(cancellationToken).ConfigureAwait(false);
        _exchanges.Add(ConformanceExchange.FromHttp(
            probe.Id, requestBody, (int)response.StatusCode, response.Content.Headers.ContentType?.ToString(), Allowlisted(response), responseBody));
        return response;
    }

    private static void SwapKey(HttpRequestMessage request)
    {
        if (request.Headers.Authorization is { } authorization)
        {
            request.Headers.Authorization = new AuthenticationHeaderValue(authorization.Scheme, InvalidKey);
        }

        if (request.Headers.Remove("x-api-key"))
        {
            request.Headers.TryAddWithoutValidation("x-api-key", InvalidKey);
        }
    }

    private static Dictionary<string, string>? Allowlisted(HttpResponseMessage response)
    {
        Dictionary<string, string>? kept = null;
        foreach (var name in RecordedHeaders)
        {
            if (response.Headers.TryGetValues(name, out var values) || response.Content.Headers.TryGetValues(name, out values))
            {
                (kept ??= new Dictionary<string, string>(StringComparer.Ordinal))[name] = string.Join(", ", values);
            }
        }

        return kept;
    }
}
```

```csharp
using System.Globalization;
using System.Runtime.InteropServices;

namespace Minos.Conformance;

/// <summary>Runs every probe and check against a target, live, recording or from a recording, and returns the report.</summary>
public sealed class ConformanceRunner
{
    private readonly Func<HttpMessageHandler> _network;
    private readonly TimeProvider _time;

    /// <summary>Initializes a new instance of the <see cref="ConformanceRunner"/> class that calls the network with a new <see cref="SocketsHttpHandler"/> per run.</summary>
    public ConformanceRunner()
        : this(static () => new SocketsHttpHandler(), TimeProvider.System)
    {
    }

    /// <summary>Initializes a new instance of the <see cref="ConformanceRunner"/> class.</summary>
    /// <param name="network">Creates the handler a live or recording run sends through; the run disposes it.</param>
    /// <param name="time">The clock that dates a recording.</param>
    public ConformanceRunner(Func<HttpMessageHandler> network, TimeProvider time)
    {
        ArgumentNullException.ThrowIfNull(network);
        ArgumentNullException.ThrowIfNull(time);

        _network = network;
        _time = time;
    }

    /// <summary>Runs every probe that applies to the target's capabilities, and every check that applies to each.</summary>
    /// <param name="target">The endpoint to check.</param>
    /// <param name="mode">Live, record or replay.</param>
    /// <param name="fixturePath">The fixture to replay, or to write when recording; ignored for a live run.</param>
    /// <param name="cancellationToken">Cancels the run.</param>
    /// <returns>The report.</returns>
    /// <exception cref="ArgumentException">A record or replay run has no <paramref name="fixturePath"/>.</exception>
    /// <exception cref="InvalidDataException">The replayed fixture is for another target, names a probe that does not exist or twice, or has no exchange for a probe that applies.</exception>
    public async Task<ConformanceReport> RunAsync(
        ConformanceTarget target, ConformanceMode mode, string? fixturePath = null, CancellationToken cancellationToken = default)
    {
        ArgumentNullException.ThrowIfNull(target);
        if (mode != ConformanceMode.Live)
        {
            ArgumentException.ThrowIfNullOrWhiteSpace(fixturePath);
        }

        var fixture = mode == ConformanceMode.Replay ? ConformanceFixture.Load(fixturePath!) : null;
        if (fixture is not null && !string.Equals(fixture.Target, target.Name, StringComparison.Ordinal))
        {
            throw new InvalidDataException("The fixture is for " + fixture.Target + ", not " + target.Name + ".");
        }

        using var capture = new ExchangeCapture(fixture is null ? _network() : new FixtureHandler(fixture));
        using var http = new HttpClient(capture, disposeHandler: false);
        using var client = target.CreateClient(http);
        var capabilities = client.GetService<DecisionCapabilities>();
        if (fixture is not null)
        {
            CheckCovers(fixture, capabilities);
        }

        var probes = new List<ProbeReport>();
        var outcomes = new List<ProbeOutcome>();
        var recorded = new List<ConformanceExchange>();
        foreach (var probe in ConformanceProbe.All)
        {
            if (NotApplicable(probe, capabilities) is { } reason)
            {
                probes.Add(new ProbeReport(probe.Id, reason, ConformanceChecks.Skipped(probe, reason)));
                continue;
            }

            if (fixture?.Find(probe.Id) is { Skipped: { } fixtureReason })
            {
                var skipped = "The fixture skips it: " + fixtureReason;
                probes.Add(new ProbeReport(probe.Id, skipped, ConformanceChecks.Skipped(probe, skipped)));
                continue;
            }

            capture.Begin(probe);
            var result = await client.EvaluateAsync(probe.Request with { Model = target.Model }, cancellationToken).ConfigureAwait(false);
            var exchanges = capture.End();
            var outcome = new ProbeOutcome(probe, exchanges, result.IsSuccess ? result.Value : null, result.IsFailure ? result.Error : null);
            outcomes.Add(outcome);
            probes.Add(new ProbeReport(probe.Id, null, ConformanceChecks.Run(outcome, target)));
            if (mode == ConformanceMode.Record)
            {
                recorded.Add(exchanges.Count > 0
                    ? exchanges[^1]
                    : new ConformanceExchange { Probe = probe.Id, Skipped = "No request was sent: " + result.Error.Kind.ToString() + ", " + result.Error.Message });
            }
        }

        if (mode == ConformanceMode.Record)
        {
            new ConformanceFixture
            {
                Target = target.Name,
                Source = ConformanceFixture.RecordedSource,
                Model = FirstModel(outcomes) ?? target.Model,
                Recorded = _time.GetUtcNow().ToString("yyyy-MM-dd", CultureInfo.InvariantCulture),
                Exchanges = recorded,
            }.Save(fixturePath!);
        }

        return new ConformanceReport
        {
            Target = target.Name,
            Wire = target.Wire,
            Model = target.Model,
            ModelRule = target.ModelRule?.Description,
            Mode = mode,
            FixtureSource = fixture?.Source,
            FixtureRecorded = fixture?.Recorded,
            Probes = probes,
            RunChecks = [ConformanceChecks.E4(outcomes)],
        };
    }

    /// <summary>Why a probe does not apply to these capabilities, or <see langword="null"/> when it does.</summary>
    internal static string? NotApplicable(ConformanceProbe probe, DecisionCapabilities? capabilities)
    {
        if (capabilities is null)
        {
            return null;
        }

        var questions = probe.Definition.Questions;
        if (capabilities.MaxQuestions is { } maxQuestions && questions.Count > maxQuestions)
        {
            return string.Create(CultureInfo.InvariantCulture, $"The target takes at most {maxQuestions} questions.");
        }

        foreach (var question in questions)
        {
            var kind = question.Kind switch
            {
                QuestionKind.Noul => QuestionKinds.Noul,
                QuestionKind.Choice => QuestionKinds.Choice,
                _ => QuestionKinds.Score,
            };
            if (capabilities.QuestionKinds is { } kinds && (kinds & kind) == QuestionKinds.None)
            {
                return "The target does not accept " + question.Kind.ToString() + " questions.";
            }

            if (question.Kind == QuestionKind.Choice && capabilities.MaxChoiceOptions is { } maxOptions && question.Options.Count > maxOptions)
            {
                return string.Create(CultureInfo.InvariantCulture, $"The target takes at most {maxOptions} options per Choice.");
            }
        }

        return null;
    }

    // Replay answers by probe id, never by body: an id the suite does not know, a repeated one, or a missing one fails the
    // run instead of being skipped.
    private static void CheckCovers(ConformanceFixture fixture, DecisionCapabilities? capabilities)
    {
        var known = new HashSet<string>(StringComparer.Ordinal);
        foreach (var probe in ConformanceProbe.All)
        {
            known.Add(probe.Id);
        }

        var seen = new HashSet<string>(StringComparer.Ordinal);
        var unknown = new List<string>();
        var repeated = new List<string>();
        foreach (var exchange in fixture.Exchanges)
        {
            if (!known.Contains(exchange.Probe))
            {
                unknown.Add(exchange.Probe);
            }
            else if (!seen.Add(exchange.Probe))
            {
                repeated.Add(exchange.Probe);
            }
        }

        var missing = new List<string>();
        foreach (var probe in ConformanceProbe.All)
        {
            if (NotApplicable(probe, capabilities) is null
                && (fixture.Find(probe.Id) is not { } exchange || (exchange.Skipped is null && exchange.Status is null)))
            {
                missing.Add(probe.Id);
            }
        }

        if (unknown.Count > 0)
        {
            throw new InvalidDataException("The fixture names probes the suite does not have: " + string.Join(", ", unknown) + ".");
        }

        if (repeated.Count > 0)
        {
            throw new InvalidDataException("The fixture names these probes more than once: " + string.Join(", ", repeated) + ".");
        }

        if (missing.Count > 0)
        {
            throw new InvalidDataException("The fixture has no exchange for these probes: " + string.Join(", ", missing) + ".");
        }
    }

    private static string? FirstModel(List<ProbeOutcome> outcomes)
    {
        foreach (ref readonly var outcome in CollectionsMarshal.AsSpan(outcomes))
        {
            if (outcome.Response?.Model is { Length: > 0 } model)
            {
                return model;
            }
        }

        return null;
    }
}
```

```csharp
    {
        var target = new ConformanceTarget(
            "my-server",
            ConformanceWire.SystemOne,
```

```markdown
# Conformance

Minos reaches several providers, and each one should answer the same request the same way. The conformance suite,
`Minos.NET.Conformance`, checks that. It sends a fixed set of probes to an endpoint through an `IDecisionClient`, reads
each answer twice, once as the wire sent it and once as Minos read it, and runs its checks on both. It works against any
endpoint a Minos client can reach, a server of your own included.

The suite runs on every CI build, against the TypeSafe, OpenRouter and OpenAI fixtures described below. It is not
published to NuGet yet; a later release ships it as a `dotnet` tool.

## The probes

Each probe is one request with a stable id. The probes ask only what every provider can express, so none sets a Noul's
`WhenTrue` or a criterion's examples, which OpenAI cannot send.

| Probe | What it sends | What it expects |
| --- | --- | --- |
| `noul` | One Noul question, `is_urgent`. | Answers. |
| `choice` | One Choice question, `department`, with two options. | Answers. |
| `score` | One Score question, `frustration`, with three levels. | Answers. |
| `mixed` | The three in one set, keyed `is_urgent`, `department` and `frustration`, which is not alphabetical. | Answers. |
| `keyed` | A set built with `QuestionSetBuilder`: a Choice with the options `pro-plan` and `team-plan`, and a Score. | Answers. |
| `invalid` | A request with no questions. | A 400 or a 422. |
| `bad-key` | The `noul` request with an invalid key. | A 401 or a 403. |

A probe that the client's [capabilities](client-and-errors.md#capabilities) rule out, such as `choice` on a Noul-only
server, is skipped with the reason, and so are its checks.

## The checks

Each check passes, fails or is skipped. A check that cannot run is skipped, never passed. A sum or an expected level may
be off by 0.01.

| Check | What it checks | Skipped when |
| --- | --- | --- |
| `S1` | The response is a JSON object with exactly one answer per question asked. | No request was sent. |
| `S2` | Each answer's `type` fits its question: a Noul is `noul` on System One and `predicate` on OpenAI; a Choice and a Score are `choice` and `score` on both. | The response has no answers to read. |
| `S3` | Minos reads the response without an error, and its result reads every key with its kind. | Never. |
| `D1` | Every probability is a finite number from 0 to 1. | The response has no answers to read. |
| `D2` | A Choice's or a Score's probabilities sum to 1 and cover exactly the options or levels sent. | The probe asks no Choice or Score. |
| `D3` | A Score's `score` is the sum of each level times its probability. | The probe asks no Score. |
| `D4` | A reported confidence is from 0 to 1. | No answer reports one, as for a Noul. |
| `M1` | The `mixed` answers are matched by key, so a provider or a parser that relies on their order fails. | Minos returned an error. |
| `E1` | `invalid` gets a 400 or a 422 with a JSON body, which Minos maps to `Validation` with a message. | No request was sent. |
| `E2` | `bad-key` gets a 401 or a 403, which Minos maps to `Unauthorized` and does not retry. | No request was sent. |
| `E3` | An error response's request-id header equals `DecisionError.RequestId`. | The response carries none, as OpenRouter's 401 does. |
| `E4` | A 429 met during the run has its `Retry-After` in `DecisionError.RetryAfter` and its request id read. | No 429 was met. One cannot be provoked, so the suite keeps no made-up 429. |
| `R1` | A successful response names a model, and `DecisionResponse.Model` is the same. | The response names none and the target promises none. |
| `R2` | The reported model fits the requested one by the target's rule. | The target states no rule. |
| `R3` | The usage, when there is one, has whole, non-negative token counts. | The response reports no usage. |

The report states the model rule `R2` applied. TypeSafe answers an alias such as `jev-latest` with a versioned id of the
same family, such as `jev-1.13.0`. OpenRouter answers with a prefixed form, such as `~typesafe/jev-latest` or
`typesafe/jev-1.13-20260917`. `E3` and `E4` read the request-id headers in the order the client does;
[Request ids](client-and-errors.md#request-ids) lists which provider sends which.

## Running it against your endpoint

A `ConformanceTarget` names the endpoint, its wire format, the model to ask, the rule its reported model follows, and a
factory that builds the client over the runner's `HttpClient`. `ConformanceRunner.RunAsync` runs every probe in one of
three modes:

- `Live` sends real requests and saves nothing.
- `Record` sends real requests and saves the exchange of each probe, errors included, to a fixture file.
- `Replay` answers each probe from a fixture file by its id. A fixture that names a probe the suite does not have, names
  one twice, or lacks one fails the run rather than skipping the probe.

<!-- snippet: Conformance_Record -->
<!-- endSnippet -->

A recording sends one request per probe, seven in all, and each one is billed. The fixture keeps the request body, the
status, the response body, its media type and only these headers: `x-request-id`, `x-typesafe-request-id`,
`request-id`, `retry-after` and `retry-after-ms`. It never keeps your key or any other header. For `bad-key` the runner
swaps your key for an invalid one itself, so a target needs no second factory for it.

The report comes as JSON, from `ToJson`, and as markdown, from `ToMarkdown`. It names the target, the model and its rule,
the mode, the fixture's source and date, and has one row per check.

## The fixtures

Each fixture says where its exchanges came from:

| Source | Meaning |
| --- | --- |
| `recorded` | Recorded from the live endpoint by a `Record` run. The fixture must name the model and the date. |
| `tests` | Built from the response fixtures of the client's own unit tests, until the first recording replaces it. |
| `guide` | Built from the provider's documentation. |

An exchange recorded apart from the rest carries its own date, and a fixture may skip a probe, with the reason, when no
exchange for it exists yet. In CI the suite must fail no check on any fixture, and each fixture must skip exactly the
checks its test expects, so a check that starts to skip fails the build.

The Live smoke workflow records TypeSafe's and OpenRouter's fixtures on `main` and uploads them as an artifact; they
reach the repository through a pull request. Until the first recording they are built from the unit tests' fixtures,
with error bodies that earlier live runs captured.

### Why OpenAI's success fixtures come from the guide

There is no OpenAI key to record with yet. OpenAI's success fixtures are built from the example in its
[Decisions guide](https://developers.openai.com/api/docs/guides/decisions), as the adapter's own tests are, and are
labelled `guide`. That example names no model and no usage, so `R1`, `R2` and `R3` skip for OpenAI. The `bad-key`
exchange is real, because a 401 needs no key. [Issue #OPENAI_FIXTURES_ISSUE](https://github.com/MarcelRoozekrans/Minos.NET/issues/OPENAI_FIXTURES_ISSUE)
tracks recording the rest once a key exists.
```
