# OpenAI Decisions Adapter and Image State Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add image state to the core, make capabilities provider-neutral, and ship a `Minos.NET.OpenAI` package that sends question sets to OpenAI's `POST /v1/decisions`. Document every provider difference, and live-test images and Clef through OpenRouter.

**Architecture:**
- **Core first:** `DecisionImage` and `DecisionRequest.Images`, then the neutral `DecisionCapabilities` and `QuestionKinds` with the shared pre-send check, including MIN206.
- **The protocol-neutral transport moves into the core as internals:** `IDecisionProtocol`, `StateWriter`, `RequestStates`, `DecisionTransport` and `RetryAfterHeader`. The only ZeroAlloc.Rest-bound pieces, the error mapper and the raw serializer, become shared source linked into both protocol packages.
- **SystemOne learns images:** with images, `state` is written as a content-part array.
- **Then the new package:** first its protocol, the request writer, the answer reader, errors and the MIN204/MIN205 checks; then its client, options and DI.
- **Then the proofs:** packaging, the AOT smoke and surface, live tests through OpenRouter, and the docs with the provider differences table.

**Tech Stack:** .NET 10, C#, ZeroAlloc.Rest 3.3.1 with `{**path}` routes, ZeroAlloc.Results, System.Text.Json `Utf8JsonWriter` and `Utf8JsonReader`, Microsoft.Extensions.DependencyInjection, Http and Options with the configuration binding generator, xUnit, WireMock.Net, PublicApiAnalyzers, MarkdownSnippets, Native AOT, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-11-phase-6.5-openai-decisions-adapter-design.md`. Read its "Amendments while planning" section first: this plan applies it.

## Rulings made while planning

These are recorded in the spec's "Amendments while planning". Every task follows them.

1. **Capabilities are neutral, in the core.** The maintainer decided this on 2026-10-11. They were still unreleased, since 0.9.0 is PR #153 and still open.
   - `SystemOneCapabilities` becomes `Minos.DecisionCapabilities`, and `SystemOneQuestionKinds` becomes `Minos.QuestionKinds`.
   - Both clients take a `DecisionCapabilities` in their options and answer `GetService<DecisionCapabilities>()`.
   - The check for MIN201–MIN203 and MIN206 lives once, in the core's internal `CapabilitySet`. There is no `OpenAICapabilities`.
2. **The protocol-neutral transport moves into the core as internals,** in namespace `Minos.Transport`, beside `RawJson`.
   - **The types:** `IDecisionProtocol`, `StateWriter`, `RequestStates`, `RetryAfterHeader` and `DecisionTransport`.
   - **`DecisionTransport`** sends through an internal delegate, `RawSend`, rather than `IDecisionApi`. Each package's ZeroAlloc.Rest interface stays in the package, because ZeroAlloc.Rest generates the client in the declaring assembly.
   - **The two Rest-bound adapters, `DecisionErrorMapper` and `DecisionRawSerializer`,** move to `src/Shared/Rest/` in namespace `Minos.Transport.Rest`, linked into both packages. They are the only shared source; see the CS0436 constraint.
   - **The core does not reference ZeroAlloc.Rest.**
3. **`DecisionRequest.Images` is an `init` property,** not a constructor overload as the spec says. `with`, which the retry stage uses, then copies it. The setter copies the list to an array and rejects `null`. The default is an empty array and allocates nothing.
4. **OpenAI's `input` is a string whenever there are no images,** for JSON state too: the raw JSON text. With images, `input` is the one-message array. The spec's table also sent JSON state as a message array; a string is equivalent and simpler.
5. **`QuestionSetDefinition` gets two protocol-cache slots.** Slot 0 is SystemOne's `questions` object; slot 1 is OpenAI's `questions` array.
6. **The OpenAI checks MIN204 and MIN205 run through the protocol:** `IDecisionProtocol.CollectUnsupported`. `DecisionTransport` merges them with the capability failures into one `Unsupported` error. Capability failures come first, then protocol failures, each in question order.
7. **OpenAI unit tests go in a new `tests/Minos.NET.OpenAI.Tests`,** which gets `InternalsVisibleTo` from core and OpenAI. The WireMock tests go in `tests/Minos.NET.Integration.Tests`, through the public API only.
8. **`Refused` errors carry `StatusCode = 200`,** as `InvalidResponse` from a 200 body does. Their message is `"The model refused to answer: <key>[, <key>…]."`.

- [x] **Step 3: Implement `DecisionImage`** in `src/Minos.NET/DecisionImage.cs`:

```csharp
using System.Buffers;
using System.Buffers.Text;
using System.Text;
using System.Text.Json;

namespace Minos;

/// <summary>
/// An image a decision is about, sent with the state where the provider supports images: inline bytes and their media
/// type. Providers accept PNG, JPEG, WebP and GIF, as base64 data URLs; remote URLs and file ids are not supported.
/// </summary>
public readonly struct DecisionImage : IEquatable<DecisionImage>
{
    private static readonly string[] SupportedTypes = ["image/png", "image/jpeg", "image/webp", "image/gif"];

    private readonly byte[]? _data;

    private DecisionImage(string mediaType, byte[] data)
    {
        MediaType = mediaType;
        _data = data;
    }

    /// <summary>Gets the media type, such as <c>image/png</c>.</summary>
    public string MediaType { get; }

    /// <summary>Gets the image bytes.</summary>
    public ReadOnlyMemory<byte> Data => _data;

    internal bool IsInitialized => _data is not null;

    // "data:" + type + ";base64," + the base64 text.
    internal int DataUrlLength => 5 + MediaType.Length + 8 + Base64.GetMaxEncodedToUtf8Length(_data!.Length);

    /// <summary>Creates an image from its bytes. The bytes are copied.</summary>
    /// <param name="data">The image bytes.</param>
    /// <param name="mediaType"><c>image/png</c>, <c>image/jpeg</c>, <c>image/webp</c> or <c>image/gif</c>.</param>
    /// <returns>The image.</returns>
    /// <exception cref="ArgumentNullException"><paramref name="mediaType"/> is <see langword="null"/>.</exception>
    /// <exception cref="ArgumentException"><paramref name="data"/> is empty, or <paramref name="mediaType"/> is not supported.</exception>
    public static DecisionImage FromBytes(ReadOnlyMemory<byte> data, string mediaType)
    {
        ArgumentNullException.ThrowIfNull(mediaType);
        var type = Supported(mediaType) ?? throw new ArgumentException(
            "The media type must be image/png, image/jpeg, image/webp or image/gif.", nameof(mediaType));
        if (data.IsEmpty)
        {
            throw new ArgumentException("The image has no data.", nameof(data));
        }

        return new DecisionImage(type, data.ToArray());
    }

    /// <summary>Creates an image from a <c>data:&lt;type&gt;;base64,&lt;data&gt;</c> URL.</summary>
    /// <param name="dataUrl">The data URL.</param>
    /// <returns>The image.</returns>
    /// <exception cref="ArgumentNullException"><paramref name="dataUrl"/> is <see langword="null"/>.</exception>
    /// <exception cref="ArgumentException">
    /// <paramref name="dataUrl"/> is not a base64 data URL of a supported type, or its data is empty or not base64.
    /// </exception>
    public static DecisionImage FromDataUrl(string dataUrl)
    {
        ArgumentNullException.ThrowIfNull(dataUrl);
        const string Prefix = "data:";
        const string Marker = ";base64,";
        var markerAt = dataUrl.IndexOf(Marker, StringComparison.Ordinal);
        if (!dataUrl.StartsWith(Prefix, StringComparison.Ordinal) || markerAt < 0)
        {
            throw new ArgumentException("The value must be a data:<type>;base64,<data> URL.", nameof(dataUrl));
        }

        var type = Supported(dataUrl[Prefix.Length..markerAt]) ?? throw new ArgumentException(
            "The media type must be image/png, image/jpeg, image/webp or image/gif.", nameof(dataUrl));
        byte[] data;
        try
        {
            data = Convert.FromBase64String(dataUrl[(markerAt + Marker.Length)..]);
        }
        catch (FormatException exception)
        {
            throw new ArgumentException("The data URL's data is not base64.", nameof(dataUrl), exception);
        }

        if (data.Length == 0)
        {
            throw new ArgumentException("The image has no data.", nameof(dataUrl));
        }

        return new DecisionImage(type, data);
    }

    /// <summary>Writes the image as a data URL, one JSON string value, base64-encoding into a pooled buffer.</summary>
    internal void WriteDataUrl(Utf8JsonWriter writer)
    {
        var length = DataUrlLength;
        var rented = ArrayPool<byte>.Shared.Rent(length);
        try
        {
            var url = rented.AsSpan();
            var written = Encoding.ASCII.GetBytes("data:", url);
            written += Encoding.ASCII.GetBytes(MediaType, url[written..]);
            written += Encoding.ASCII.GetBytes(";base64,", url[written..]);
            Base64.EncodeToUtf8(_data, url[written..], out _, out var encoded);
            writer.WriteStringValue(url[..(written + encoded)]);
        }
        finally
        {
            ArrayPool<byte>.Shared.Return(rented);
        }
    }

    /// <inheritdoc />
    public bool Equals(DecisionImage other)
        => string.Equals(MediaType, other.MediaType, StringComparison.Ordinal) && Data.Span.SequenceEqual(other.Data.Span);

    /// <inheritdoc />
    public override bool Equals(object? obj) => obj is DecisionImage other && Equals(other);

    /// <inheritdoc />
    public override int GetHashCode() => HashCode.Combine(MediaType, _data?.Length ?? 0);

    /// <summary>Compares two images for equality.</summary>
    /// <param name="left">The first image.</param>
    /// <param name="right">The second image.</param>
    /// <returns><see langword="true"/> when both have the same type and bytes.</returns>
    public static bool operator ==(DecisionImage left, DecisionImage right) => left.Equals(right);

    /// <summary>Compares two images for inequality.</summary>
    /// <param name="left">The first image.</param>
    /// <param name="right">The second image.</param>
    /// <returns><see langword="true"/> when they differ.</returns>
    public static bool operator !=(DecisionImage left, DecisionImage right) => !left.Equals(right);

    private static string? Supported(string mediaType)
    {
        foreach (var type in SupportedTypes)
        {
            if (string.Equals(type, mediaType, StringComparison.Ordinal))
            {
                return type;
            }
        }

        return null;
    }
}
```

Base64 output is ASCII, so the JSON writer escapes nothing: `+` and `/` are not escaped by `Utf8JsonWriter`'s default encoder. A test in Step 1 pins the exact output.

```csharp
    // A solid red 128x128 PNG, built so the test needs no binary fixture.
    internal static byte[] RedPng()
    {
        const int Size = 128;
        var raw = new byte[Size * ((Size * 3) + 1)];
        for (var row = 0; row < Size; row++)
        {
            var start = row * ((Size * 3) + 1);
            for (var x = 0; x < Size; x++)
            {
                raw[start + 1 + (x * 3)] = 0xE0;
                raw[start + 2 + (x * 3)] = 0x10;
                raw[start + 3 + (x * 3)] = 0x10;
            }
        }

        using var png = new MemoryStream();
        png.Write([0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A]);
        WriteChunk(png, "IHDR", [0, 0, 0, Size, 0, 0, 0, Size, 8, 2, 0, 0, 0]);
        using (var compressed = new MemoryStream())
        {
            using (var zlib = new System.IO.Compression.ZLibStream(compressed, System.IO.Compression.CompressionLevel.Optimal, leaveOpen: true))
            {
                zlib.Write(raw);
            }

            WriteChunk(png, "IDAT", compressed.ToArray());
        }

        WriteChunk(png, "IEND", []);
        return png.ToArray();
    }

    private static void WriteChunk(Stream png, string type, byte[] data)
    {
        Span<byte> length = stackalloc byte[4];
        System.Buffers.Binary.BinaryPrimitives.WriteInt32BigEndian(length, data.Length);
        png.Write(length);
        var typeBytes = System.Text.Encoding.ASCII.GetBytes(type);
        png.Write(typeBytes);
        png.Write(data);
        var crc = new System.IO.Hashing.Crc32();
        crc.Append(typeBytes);
        crc.Append(data);
        Span<byte> crcBytes = stackalloc byte[4];
        System.Buffers.Binary.BinaryPrimitives.WriteUInt32BigEndian(crcBytes, crc.GetCurrentHashAsUInt32());
        png.Write(crcBytes);
    }
```
