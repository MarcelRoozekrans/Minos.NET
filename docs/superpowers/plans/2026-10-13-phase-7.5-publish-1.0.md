# Phase 7.5: Publish 1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the repository able to publish 1.0.0 of its six packages to nuget.org through Trusted Publishing, rehearsed on every push, and update the docs for a published 1.0.

**Architecture:** `ci.yml` gains two jobs:
- `pack-validate` runs on every push. It packs, inspects the packages and rehearses the push against a local feed.
- `publish-nuget` runs only on a dispatch with `publish_to_nuget=true` on a `v*` tag. It pushes the packages after every check passes.

`release-please.yml` dispatches that run when a release is created. A Python script inspects the packages, and a docs test pins the workflow wiring. Tasks 1 to 6 are code; Task 7 is the controller's verification and state work.

**Tech Stack:** GitHub Actions, .NET 10 SDK, `dotnet pack`/`dotnet nuget push`, `NuGet/login@v1`, Python 3 standard library, xUnit.

**Spec:** `docs/superpowers/specs/2026-10-13-phase-7.5-publish-1.0-design.md`

## Global Constraints

- **The six packages:** `Minos.NET`, `Minos.NET.SystemOne`, `Minos.NET.OpenAI`, `Minos.NET.DependencyInjection`, `Minos.NET.Caching` and `Minos.NET.RateLimiting`. Nothing else is packed for release.
- **Every release build and pack passes `-p:MinosRelease=true`.** Without it, `Directory.Build.props` versions the build `<manifest version>-local`, and that version is compiled into the DLLs.
- **The version** is the `"."` entry of `.release-please-manifest.json`.
- **The publish refuses** any version below 1.0.0 and any prerelease.
- **The push to nuget.org** sends only `*.nupkg`, with `--skip-duplicate`. A `.snupkg` beside its `.nupkg` is delivered with it.
- **Trusted Publishing:** the key comes from `NuGet/login@v1` with `user: ${{ vars.NUGET_USER }}`. No API key is stored in the repository.
- **The build** treats warnings as errors. Never suppress a warning; fix its cause.
- **Docs code blocks** come from `tests/Minos.NET.Docs.Tests` through mdsnippets: edit the `.cs` source, then run `dotnet mdsnippets`.
- **Build and test** from PowerShell, with `dotnet build Minos.NET.slnx -c Release` and `dotnet test Minos.NET.slnx -c Release --no-build`.
- **Commits** are conventional, with a scope from `.commitlintrc.yml`: core, generator, di, systemone, openai, ratelimiting, caching, conformance, tests, benchmarks, samples, docs, ci, deps, roadmap, state, sync, milestone, main. No commit body has nested parentheses. Every commit ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, and none contains a `claude.ai/code/session_` link.

**Why:** `dotnet pack` and `dotnet build` start MSBuild worker nodes, and possibly the compiler server. These inherit the child's redirected stdout and stderr.
```csharp
using System.Diagnostics;

namespace Minos.PackTests;

/// <summary>
/// Runs <c>dotnet</c> with its output captured, safely. A build started by the child must not leave MSBuild worker nodes
/// or the compiler server holding the redirected pipes, or reading them never ends (#145). So node reuse and the shared
/// compiler are off for the child, both streams are read at the same time so neither pipe can fill and block the other,
/// and the wait has a time limit that fails with the output so far.
/// </summary>
internal static class DotnetProcess
{
    public static (int ExitCode, string Output, string Error) Run(string workingDirectory, TimeSpan timeout, IEnumerable<string> arguments)
    {
        var startInfo = new ProcessStartInfo("dotnet")
        {
            RedirectStandardOutput = true,
            RedirectStandardError = true,
            UseShellExecute = false,
            WorkingDirectory = workingDirectory,
        };
        startInfo.Environment["MSBUILDDISABLENODEREUSE"] = "1";
        startInfo.Environment["DOTNET_CLI_USE_MSBUILD_SERVER"] = "0";
        foreach (var argument in arguments)
        {
            startInfo.ArgumentList.Add(argument);
        }

        using var process = Process.Start(startInfo) ?? throw new InvalidOperationException("Failed to start 'dotnet'.");
        var output = process.StandardOutput.ReadToEndAsync();
        var error = process.StandardError.ReadToEndAsync();
        if (!process.WaitForExit(timeout))
        {
            process.Kill(entireProcessTree: true);
            throw new TimeoutException(
                $"'dotnet {string.Join(' ', startInfo.ArgumentList)}' did not finish within {timeout}.");
        }

        return (process.ExitCode, output.GetAwaiter().GetResult(), error.GetAwaiter().GetResult());
    }
}
```

At each call site:
- Build the argument list as now, adding `-nodeReuse:false` and `-p:UseSharedCompilation=false` for `dotnet pack` and `dotnet msbuild`.
- Call `DotnetProcess.Run` with a 5-minute timeout for pack and the 2-minute timeout `VersionSchemeTests` already uses.
- Keep each site's error message: exit code, stdout and stderr.

Match the namespace the project uses; read `PackedProject.cs` for it. If an analyzer flags `GetAwaiter().GetResult()` in this synchronous helper, use the form the analyzer accepts. The helpers are synchronous by design, and `xUnit`'s analyzers may prefer `Task.Result` here; do not suppress.

```python
def informational(version: str) -> bytes:

    text = version.encode("utf-8")
    return b"\x01\x00" + bytes([len(text)]) + text + b"\x00\x00"

        for dependency in inspect_packages.PACKAGES[package_id]
        if dependency != drop_dependency)
```

`tools/release/inspect_packages.py`:

```python
"""Checks the packages a release is about to push to nuget.org, before anything is pushed.

Usage: python3 tools/release/inspect_packages.py <directory> <version>

A NuGet version can be unlisted but never deleted, so ci.yml runs this in pack-validate on every push and again in
publish-nuget just before the push. It fails when the directory does not hold exactly the six packages at the release
version, each with its .snupkg symbol package; when a package's DLL was built without -p:MinosRelease=true, which
Directory.Build.props versions <release>-local and which is compiled into the DLL; or when a package depends on another
Minos package at a different version. Standard library only.
"""
import pathlib
import re
import sys
import zipfile

# Each package and the Minos packages it must depend on, from the ProjectReferences in its csproj.
PACKAGES: dict[str, tuple[str, ...]] = {
    "Minos.NET": (),
    "Minos.NET.DependencyInjection": ("Minos.NET",),
    "Minos.NET.SystemOne": ("Minos.NET", "Minos.NET.DependencyInjection"),
    "Minos.NET.OpenAI": ("Minos.NET", "Minos.NET.DependencyInjection"),
    "Minos.NET.Caching": ("Minos.NET",),
    "Minos.NET.RateLimiting": ("Minos.NET",),
}


def _informational_version_found(dll: bytes, version: str) -> bool:
    # AssemblyInformationalVersion is stored as a length-prefixed UTF-8 string followed by 00 00: the release version,
    # optionally followed by +<commit>. The four-part FileVersion, 1.0.0.0, never matches, because a '.' follows the
    # version there. The byte before the string must be its length, which rejects a longer version that merely ends in
    # this one, such as 11.0.0 for 1.0.0.
    pattern = re.escape(version.encode("utf-8")) + rb"(?:\+[0-9A-Za-z.]+)?(?=\x00\x00)"
    return any(
        match.start() > 0 and dll[match.start() - 1] == len(match.group())
        for match in re.finditer(pattern, dll)
    )


def _package_problems(directory: pathlib.Path, package: str, version: str) -> list[str]:
    errors: list[str] = []
    path = directory / f"{package}.{version}.nupkg"
    dll_name = f"lib/net10.0/{package}.dll"
    try:
        with zipfile.ZipFile(path) as archive:
            nuspec = archive.read(f"{package}.nuspec").decode("utf-8")
            dll = archive.read(dll_name) if dll_name in archive.namelist() else None
    except zipfile.BadZipFile as exc:
        return [f"{package}: {path.name} is not a valid package: {exc}"]
    except KeyError:
        return [f"{package}: {path.name} has no {package}.nuspec"]

    declared = re.search(r"<version>([^<]+)</version>", nuspec)
    if declared is None or declared.group(1) != version:
        errors.append(f"{package}: nuspec version is {declared.group(1) if declared else 'missing'}, expected {version}")

    if dll is None:
        errors.append(f"{package}: {dll_name} is missing")
    elif not _informational_version_found(dll, version):
        errors.append(f"{package}: {package}.dll has no informational version {version}; was it built with -p:MinosRelease=true?")

    if not (directory / f"{package}.{version}.snupkg").is_file():
        errors.append(f"{package}: {package}.{version}.snupkg is missing")

    accepted = {version, f"[{version}, )", f"[{version},)"}
    found: dict[str, list[str]] = {}
    for tag in re.findall(r"<dependency\b[^>]*>", nuspec):
        identity = re.search(r'\bid="([^"]+)"', tag)
        if identity is None or not identity.group(1).startswith("Minos.NET"):
            continue
        dependency_version = re.search(r'\bversion="([^"]+)"', tag)
        found.setdefault(identity.group(1), []).append(dependency_version.group(1) if dependency_version else "(no version)")
    for dependency in PACKAGES[package]:
        if dependency not in found:
            errors.append(f"{package} does not depend on {dependency}, expected {version}")
    for dependency, versions in found.items():
        for dependency_version in versions:
            if dependency_version not in accepted:
                errors.append(f"{package} depends on {dependency} {dependency_version}, expected {version}")
    return errors


def problems(directory: pathlib.Path, version: str) -> list[str]:
    found = sorted(path.name for path in directory.glob("*.nupkg"))
    expected = sorted(f"{package}.{version}.nupkg" for package in PACKAGES)
    if found != expected:
        missing = sorted(set(expected) - set(found))
        extra = sorted(set(found) - set(expected))
        return [f"expected exactly the six release packages in {directory}; missing {missing}, unexpected {extra}"]

    errors: list[str] = []
    for package in PACKAGES:
        errors.extend(_package_problems(directory, package, version))
    return errors


def main(argv: list[str]) -> int:
    if len(argv) != 2:
        print("usage: inspect_packages.py <directory> <version>", file=sys.stderr)
        return 2
    directory, version = pathlib.Path(argv[0]), argv[1]
    errors = problems(directory, version)
    for error in errors:
        print(f"ERROR: {error}")
    if errors:
        return 1
    print(f"OK: {', '.join(f'{package} {version}' for package in PACKAGES)} are ready to push")
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```

```yaml
  # Publishes a release to nuget.org. release-please.yml dispatches this workflow on the release tag with
  # publish_to_nuget=true when it creates a release; a maintainer can dispatch it the same way to finish a push that
  # died partway, since --skip-duplicate makes a re-run safe. It runs after every other job on that exact commit, and it
  # refuses a 0.x version, a prerelease, and a tag that is not the manifest's version. The key comes from nuget.org's
  # Trusted Publishing; no key is stored. A .snupkg beside its .nupkg is delivered with the same push. RELEASING.md has
  # the procedure; WorkflowWiringTests pins the commands.
  publish-nuget:
    if: github.event_name == 'workflow_dispatch' && inputs.publish_to_nuget && startsWith(github.ref, 'refs/tags/v')
    needs: [build, aot-smoke, aot-surface, pack-validate]
    runs-on: ubuntu-latest
    timeout-minutes: 30
    permissions:
      contents: write
      id-token: write
    steps:
      - uses: actions/checkout@v7
        with:
          fetch-depth: 0

      - name: Setup .NET
        uses: actions/setup-dotnet@v6
        with:
          global-json-file: global.json
          dotnet-version: '10.0.x'

      - name: Refuse anything but a stable 1.0 or later release from its own tag
        shell: bash
        run: |
          version=$(jq -r '."." // empty' .release-please-manifest.json)
          if ! [[ "$version" =~ ^[0-9]+\.[0-9]+\.[0-9]+$ ]]; then
            echo "::error::Refusing to publish '$version': it is not a stable version."
            exit 1
          fi
          if [[ "$version" == 0.* ]]; then
            echo "::error::Refusing to publish $version: 0.x versions are not published to nuget.org."
            exit 1
          fi
          if [ "$GITHUB_REF_NAME" != "v$version" ]; then
            echo "::error::Refusing to publish: the tag is $GITHUB_REF_NAME but the manifest says $version."
            exit 1
          fi
          echo "PACKAGE_VERSION=$version" >> "$GITHUB_ENV"

      - name: Pack the release build
        run: dotnet pack Minos.NET.slnx -c Release -p:MinosRelease=true -o artifacts/packages

      - name: Inspect the packages
        run: python3 tools/release/inspect_packages.py artifacts/packages "$PACKAGE_VERSION"

      - name: Mint a short-lived nuget.org key
        uses: NuGet/login@v1
        id: nuget-login
        with:
          user: ${{ vars.NUGET_USER }}

      - name: Push to nuget.org
        shell: bash
        env:
          NUGET_API_KEY: ${{ steps.nuget-login.outputs.NUGET_API_KEY }}
        run: |
          if [ -z "$NUGET_API_KEY" ]; then
            echo "::error::NuGet/login minted no key. Check the NUGET_USER repository variable and the Trusted Publishing policy on nuget.org; see RELEASING.md."
            exit 1
          fi
          dotnet nuget push "artifacts/packages/*.nupkg" --source https://api.nuget.org/v3/index.json --api-key "$NUGET_API_KEY" --skip-duplicate

      - name: Attach the packages to the GitHub release
        env:
          GH_TOKEN: ${{ github.token }}
        run: gh release upload "$GITHUB_REF_NAME" artifacts/packages/*.nupkg artifacts/packages/*.snupkg --clobber
```

```markdown
# Releasing Minos.NET

Releases are cut by release-please and published to nuget.org by `ci.yml`. Nothing is published by hand.

## How a release happens

1. Conventional commits on `main` make release-please keep a release PR open, named `chore(main): release X.Y.Z`.
2. Merging that PR tags `vX.Y.Z` and creates the GitHub release.
3. `release-please.yml` then dispatches `ci.yml` on the tag with `publish_to_nuget=true`.
4. On that run, every job runs on the tagged commit. `publish-nuget` starts only after `build`, `aot-smoke`, `aot-surface` and `pack-validate` pass.
5. `publish-nuget` refuses a 0.x version, a prerelease, or a tag that is not the manifest's version. It then packs with `-p:MinosRelease=true`, inspects the packages, pushes the six `.nupkg` files to nuget.org, and attaches them and their `.snupkg` files to the GitHub release.

Every push and pull request also runs `pack-validate`. It packs the same way, inspects the packages, and rehearses the push against a local feed.

## Before the first release: two settings on nuget.org and GitHub

- **Trusted Publishing:** on nuget.org, add a Trusted Publishing policy for the repository `MarcelRoozekrans/Minos.NET` and the workflow file `ci.yml`.
- **`NUGET_USER`:** in the GitHub repository, add a variable named `NUGET_USER` holding the nuget.org user name that owns the policy.

Without both, `publish-nuget` fails at its login or push step and nothing reaches nuget.org.

## Re-running a publish

A push that died partway can be finished by dispatching the same run again on the tag:

    gh workflow run ci.yml --ref vX.Y.Z -f publish_to_nuget=true

`--skip-duplicate` skips the packages that already arrived. Dispatching on `main` publishes nothing, because the job runs only on a `v*` tag.

## The version

The version is the `"."` entry of `.release-please-manifest.json`. A build without `-p:MinosRelease=true` is versioned `X.Y.Z-local`, and that version is compiled into the DLLs. So every release pack builds with the switch, and the inspection rejects a DLL that does not carry the release version.
```
