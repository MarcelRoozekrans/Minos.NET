# /v1/systemone Adapter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Split the `/v1/systemone` protocol out of the core into a new `Minos.NET.SystemOne` package. Add presets for TypeSafe, OpenRouter, Cloudflare Workers AI, vLLM Semantic Router and custom servers, capability flags checked before sending, optional auth, and `AddSystemOneClient` registrations over a provider-neutral DI package.

**Architecture:**
- **Verify first:** the controller spikes a local server in CI and records Cloudflare's real response before any code depends on either.
- **Core preparation:** the internals that both packages need, the retry-settings rules, the disposed-error factory and the log and telemetry members, are moved to their final side of the boundary inside core, with no behaviour change.
- **One atomic move:** the SystemOne files `git mv` into the new project, with their renames, and every consumer follows in the same commit.
- **DI is reshaped:** the DI package becomes neutral, and `AddSystemOneClient` arrives with `SystemOneClientServiceBuilder`.
- **Then the new behaviour:** presets with optional auth, capabilities with the pre-send check, and Cloudflare's envelope.
- **Then the proofs:** fixtures, the live test, the local-server job and the docs.

**Tech Stack:** .NET 10, C#, ZeroAlloc.Rest 3.3.1 with `{**path}` routes, ZeroAlloc.Telemetry `[Instrument]` proxies, ZeroAlloc.Results, Microsoft.Extensions.DependencyInjection, Http and Options, the configuration binding generator, System.Text.Json `Utf8JsonReader`, xUnit, WireMock.Net, PublicApiAnalyzers, MarkdownSnippets, Native AOT, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-11-phase-6.4-systemone-adapter-design.md`. Read its "Amendments while planning" section before any task.

**Reference reports, in the repository:**
- `docs/plans/2026-10-11-phase-6.4-split-inventory.md`: the file-by-file classification, every cross-boundary internal, and every consumer to update. Tasks 3–5 cite its sections as "inventory §N".
- `docs/plans/2026-10-11-phase-6.4-provider-research.md`: the vendor facts behind the presets.

## Global Constraints

- **Build:** `TreatWarningsAsErrors` is on, and the build must have 0 warnings. Never suppress a diagnostic: no `#pragma warning disable`, no `NoWarn`, no `[SuppressMessage]`. Fix the cause. Existing `#pragma` lines in test helpers stay as they are.
- **Nothing goes public to bridge packages.** Internals cross only through `InternalsVisibleTo`. A public member is added only where the spec or this plan names it.
- **No duplicate internal type names across assemblies.** With `InternalsVisibleTo`, a type in `Minos.NET.SystemOne` with the same full name as one in core is error CS0436. Every internal in the new package lives in a `Minos.SystemOne` or `Minos.SystemOne.*` namespace. Do not link `DiagnosticIds.cs`, `DecisionLimits.cs` or `SnakeCase.cs` into the new project.
- **Wire behaviour unchanged for TypeSafe and OpenRouter:** every request body, every typed answer, and every `DecisionError` kind, message, `StatusCode`, `RetryAfter` and `Detail` stays identical to `main`. The wire fixtures in `tests/Minos.NET.Tests/WireFixtures/` keep passing unchanged.
- **Observability changes allowed:** only those in the spec's amendments. The raw-call logs and the model-list logs name the provider by its telemetry name, such as `typesafe`, where they used the enum name. The new presets get their own provider names. Every other span name, tag, metric, event id, level, message and logger category stays identical. The category stays `Minos.DecisionClient`.
- **Allocation budgets:** the budgets in `samples/Minos.NET.AotSmoke/AllocationChecks.cs` are never raised. They are measured only in the published AOT smoke exe; `dotnet test` does not run them. If a gate breaches, cut the allocations. If that is impossible, stop and report the measurements to the controller; do not change the budget.
- **Public API:** every public change is recorded in the `PublicAPI.Unshipped.txt` of its project. A removal of a shipped member is a `*REMOVED*` line. A new project starts with a `PublicAPI.Shipped.txt` holding only `#nullable enable`.
- **Naming:**
  - Public types in `Minos.NET.SystemOne` carry the `SystemOne` prefix: `SystemOneClient`, `SystemOneClientOptions`, `SystemOneProvider`, `SystemOneCapabilities`, `SystemOneQuestionKinds`, `SystemOneDefaults` and `SystemOneClientServiceBuilder`.
  - The raw wire types keep their names: `SystemOneRequest`, `SystemOneResponse`, `ModelList`, `ModelCard`, `Question`, `NoulQuestion`, `ChoiceQuestion`, `ScoreQuestion`, `NoulCriteria`, `Answer`, `NoulAnswer`, `ChoiceAnswer` and `ScoreAnswer`.
  - Public namespace `Minos.SystemOne`. DI extensions in `Microsoft.Extensions.DependencyInjection`.
- **XML docs:** every public member has a `<summary>`, plus `<param>`, `<returns>` and `<exception>` where they apply, in the style of the surrounding files. A `cref` to a type in another package needs that package's namespace.
- **Docs snippets:** every C# block in `docs/` comes from a `#region` in `tests/Minos.NET.Docs.Tests`. After a docs change, run `dotnet mdsnippets` and expect no diff. Top-level `docs/*.md` files are site pages; reports go in `docs/plans/`.
- **Commits:**
  - Conventional, with scopes from `.commitlintrc.yml`: core, generator, di, tests, benchmarks, samples, docs, ci, deps, roadmap, state, sync, milestone, main, and, from Task 4, systemone.
  - No nested parentheses in commit bodies.
  - End every message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  - Never add a `claude.ai/code/session` link.
- **Native AOT:** run AOT publishes from PowerShell, with `$env:PATH = "C:\Program Files (x86)\Microsoft Visual Studio\Installer;$env:PATH"`. A failed link leaves a stale exe that still runs, so check the publish output for errors before trusting a run.
- **Test commands:**
  - Build and test: `dotnet build Minos.NET.slnx -c Release`, then `dotnet test Minos.NET.slnx -c Release --no-build`. The live tests skip without a key.
  - Set `MSBUILDDISABLENODEREUSE=1` before running the pack tests, which otherwise hang (#145).
- **Pushing:** only the controller pushes, with the `gh auth git-credential` helper and a time-out, and only after asking the maintainer the first time.

## Rulings made while planning

These are recorded in the spec's amendments. Every task follows them.

1. **Tests stay in `Minos.NET.Tests`.** It references `Minos.NET.SystemOne`, and both libraries grant it `InternalsVisibleTo`. Moving 51 files buys nothing. `Minos.NET.DependencyInjection.Tests` keeps the neutral DI tests and gains the `AddSystemOneClient` tests, so it references the new package too.
2. **The DI builder is a subclass.** `DecisionClientServiceBuilder` becomes a non-sealed public class with an internal constructor, and loses `HttpClient`. `SystemOneClientServiceBuilder : DecisionClientServiceBuilder` adds `HttpClient`. This was the maintainer's decision on 2026-10-11.
3. **Capability failures use rule ids MIN201–MIN203** in `QuestionFailure.Rule`: MIN201 for an unsupported kind, MIN202 for too many questions, MIN203 for too many Choice options. The MIN2xx block is reserved for provider-capability rules, and Phase 6.5's analyzer reuses these ids.
4. **`DecisionError` gains an internal constructor** that takes `(DecisionErrorKind kind, string message, IReadOnlyList<QuestionFailure> failures)`. A public one is not needed until a third-party protocol package exists.
5. **`SystemOneClientOptions.Model` becomes `string?`, default `null`.** A null model resolves to the preset's default, `jev-latest` for TypeSafe and OpenRouter. The other presets have no default, so their options fail validation without a model.
6. **Cloudflare's address is split between the base address and the path.** The base address is `https://api.cloudflare.com/client/v4/accounts/{AccountId}/ai/run/@cf/cloudflare/`, and the request path is the model name, one segment. The `@` sits in the base address and is never escaped. A Cloudflare model must match `^[A-Za-z0-9._-]+$`. The options check the default model, and the transport checks a request's model, returning `Validation` without sending.
7. **The raw `EvaluateAsync(SystemOneRequest)` uses `{**path}`,** as `SendAsync` does, so Cloudflare and `Custom.Path` reach it. `ListModelsAsync` keeps `v1/models` and runs only where `ModelListing` is true.
8. **No new allocation gate.** The capability check must keep every existing typed and built-set gate at its current measurement. That is the 0 B proof on success. The `Unsupported` path gets a functional smoke check, not a budget.
9. **`IDecisionProtocol`, `RequestStates` and `StateWriter` move with `Protocols/`.** Phase 6.5 decides whether they come back to core. `QuestionSetDefinition`'s single protocol-cache slot is left for 6.5 too.
10. **The ollajev spike and the Cloudflare recording are controller tasks.** Task 2 needs the maintainer to run one command with their own token, so the token never enters the session.

on:
  push:
    branches: [phase/6.4-systemone-adapter]
    paths: [.github/workflows/spike-local-systemone.yml]
permissions:
  contents: read
jobs:
  spike:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/setup-python@v6
        with:
          python-version: '3.12'

          ollajev serve --help || true
          ollajev --version || true

        env:
          OLLAJEV_DEVICE: cpu
        run: |
          nohup ollajev serve > serve.log 2>&1 &
          for i in $(seq 1 120); do curl -sf http://127.0.0.1:8000/v1/models && break; sleep 5; done
          cat serve.log
      - name: Ask all three kinds
        run: |
          curl -s -w '\n%{http_code}\n' http://127.0.0.1:8000/v1/systemone -H 'Content-Type: application/json' -d '{"model":"MODEL","state":"The customer asks for a refund on a broken kettle.","questions":{"refund":{"type":"noul","instructions":"Does the customer ask for a refund?"},"topic":{"type":"choice","instructions":"What is the topic?","criteria":{"billing":"Payments and refunds","shipping":"Delivery","other":"Anything else"}},"urgency":{"type":"score","instructions":"How urgent is it?","criteria":["Not urgent","Somewhat urgent","Very urgent"]}}}'
          free -m
          cat serve.log
