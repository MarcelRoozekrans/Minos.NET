## Docusaurus heading ids

A link anchor `page.md#x` must match a heading's id. Docusaurus uses the github-slugger rules, and `LinkTests` implements the same rule:
1. Lower-case the heading text.
2. Remove every character that is not a letter, a digit, a space, a hyphen or an underscore.
3. Replace each space with `-`.
4. When the same slug repeats within a page, add `-1`, `-2` and so on.

A heading with an explicit `{#custom-id}` uses that id instead. Inline code backticks are removed before slugging. For example, ``## `JevError` kinds`` becomes `jeverror-kinds`.

- [ ] **Step 1: Write the page enumerator** in `PublishedPages.cs`:

```csharp
namespace ZeroAlloc.Jev.Docs.Tests;

/// <summary>The pages the docs site publishes: every <c>docs/**/*.md</c> except the planning folders and README files.</summary>
internal static class PublishedPages
{
    private static readonly string[] Unpublished = ["planning", "plans", "superpowers"];

    public static string Root { get; } = FindRoot();

    public static IReadOnlyList<string> All { get; } = Find();

    /// <summary>Reads the <c>---</c>-fenced front matter at the top of a page as flat <c>key: value</c> pairs.</summary>
    public static IReadOnlyDictionary<string, string> FrontMatter(string relativePath)
    {
        var lines = File.ReadAllLines(Path.Combine(Root, relativePath));
        var result = new Dictionary<string, string>(StringComparer.Ordinal);
        if (lines.Length == 0 || !string.Equals(lines[0], "---", StringComparison.Ordinal))
        {
            return result;
        }

        for (var i = 1; i < lines.Length && !string.Equals(lines[i], "---", StringComparison.Ordinal); i++)
        {
            var colon = lines[i].IndexOf(':', StringComparison.Ordinal);
            if (colon > 0)
            {
                result[lines[i][..colon].Trim()] = lines[i][(colon + 1)..].Trim();
            }
        }

        return result;
    }

    private static List<string> Find()
    {
        var docs = Path.Combine(Root, "docs");
        var pages = new List<string>();
        foreach (var path in Directory.EnumerateFiles(docs, "*.md", SearchOption.AllDirectories))
        {
            var relative = Path.GetRelativePath(docs, path).Replace('\\', '/');
            var top = relative.Split('/')[0];
            if (Array.Exists(Unpublished, u => string.Equals(u, top, StringComparison.Ordinal))
                || string.Equals(Path.GetFileName(path), "README.md", StringComparison.Ordinal))
            {
                continue;
            }

            pages.Add("docs/" + relative);
        }

        pages.Sort(StringComparer.Ordinal);
        return pages;
    }

    private static string FindRoot()
    {
        for (var dir = new DirectoryInfo(AppContext.BaseDirectory); dir is not null; dir = dir.Parent)
        {
            if (File.Exists(Path.Combine(dir.FullName, "ZeroAlloc.Jev.slnx")))
            {
                return dir.FullName;
            }
        }

        throw new InvalidOperationException("Could not find the repository root.");
    }
}
```

### Tasks 2 to 6: Page tasks, common rules

Each page task does the following:

1. **Write the page.** Use the front matter given in the task. The `id` is the file name, and the `sidebar_position` is given. Adapt the source section of `README.md` named in the task, and fill gaps from the code. Read the relevant `src/` types, so that every statement matches the code.
2. **Give the code a home.** Put every C# block in `tests/ZeroAlloc.Jev.Docs.Tests/<PageName>.cs` as a named `#region`. Prefix region names with the page, for example `GettingStarted_FirstEvaluation`.
3. **Test the main example.** Add `<PageName>Tests.cs` running the page's main example against canned answers through `CannedJev`. Assert the outcome the page states. Mutation-check one assertion.
4. **Close the page.** End it with `## Next`, linking the next page or pages.
5. **Regenerate and test.** Run `dotnet mdsnippets` twice, then `dotnet test tests/ZeroAlloc.Jev.Docs.Tests -c Release`. The front-matter and link tests must pass.
6. **Report mismatches.** Any place where the README contradicts the code goes in your report, with the code's behaviour used on the page.
7. **Commit.** Use `docs(docs): add the <page> guide page`, or `pages` when the task adds more than one, with a short body and the trailer.

A page explains how to use Jev and why. It is not a dump of every API member, so link the XML docs or the related page for detail. Keep each page to one topic. When a topic belongs on another page, link there rather than repeating it.
