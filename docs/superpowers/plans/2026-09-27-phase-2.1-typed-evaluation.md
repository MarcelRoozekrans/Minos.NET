# Phase 2.1 Typed Evaluation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** `IJevClient.EvaluateAsync<T>` evaluates a `[JevQuestions]` set in one call and returns `Result<T, JevError>`.
- `JevClient` takes a raw UTF-8 path: no reflection, no `SystemOneResponse`, and fewer allocations than the untyped call.
- Any other implementation falls back to a correct default interface method.

**Architecture:**
- **Default interface methods on `IJevClient`.** Four typed overloads, whose defaults round-trip through the existing `EvaluateAsync(SystemOneRequest)`. `JevClient` overrides all four with a zero-allocation path.
- **Raw endpoint.** The fast path uses `IJevApi.EvaluateRawAsync`, which has a method-level `[Serializer(typeof(JevRawSerializer))]` and a `RawJson` body and response. So the same generated retry proxy, error mapper and `X-TypeSafe-Retry-Count` header apply.
- **Generator.** It emits `IJevQuestionSet<TSelf, TState>` when `[JevQuestions(State = typeof(...))]` is set, and reports JEV107 for an invalid `State` type.
- **`ProbabilityMap<T>`.** It gains content equality (#12) and an error path that doesn't box (#13).

**Tech Stack:** .NET 10, ZeroAlloc.Rest 2.2.0, ZeroAlloc.Resilience 3.3.0, ZeroAlloc.Results 1.2.3, System.Text.Json (`Utf8JsonWriter`, `Utf8JsonReader`, `ArrayPool<byte>`), Roslyn 5.0.0 for the generator.

**Spec:** `docs/superpowers/specs/2026-09-27-phase-2.1-typed-evaluation-design.md`

**Interfaces:**

- Produces:
  - `internal sealed class RawJson : IDisposable`. It owns a rented `byte[]` and a `Length`, exposes `ReadOnlySpan<byte> Span`, and returns the buffer on `Dispose`.

- [x] **Step 1: Failing tests,** through `StubHandler` like the other `JevClientTests`.
  - For each overload, the request body the handler receives is JSON-equal to the default path's request body for the same input: questions, state and model. The model is `JevClientOptions.Model`.
  - The response is parsed to `T`. Extra top-level fields and `answers` in any position are fine.
  - A response with no `answers` gives `InvalidResponse`.
  - An answer of the wrong type gives `InvalidResponse` with an `Exception`.
  - A 503 followed by a 200 retries, and the retry-count header runs absent, then `1`.
  - A 401 gives `Unauthorized`.
  - Caller cancellation throws `OperationCanceledException`.
  - Pooled buffers are returned. Wrap `ArrayPool<byte>` behind an internal `static ArrayPool<byte> Pool` seam that tests can swap for a counting pool, or check with the smallest design available and report which you used.
- [x] **Step 2: `RawJson` and `JevRawSerializer`.**
  - `DeserializeAsync<T>`:
    - throws `NotSupportedException` unless `typeof(T) == typeof(RawJson)`;
    - reads the stream into a rented buffer, growing by rent-copy-return until it reaches the end;
    - returns a `RawJson` that owns the buffer.
  - `SerializeAsync<T>` requires a `RawJson` value and writes its span to the stream.
  - Both methods carry `[RequiresUnreferencedCode]` and `[RequiresDynamicCode]` with a justification stating that only `RawJson` is supported and no reflection is used. This is required for the interface match, per the spike facts.
  - `ContentType` is `"application/json"`.
- [x] **Step 3: `IJevApi.EvaluateRawAsync`.**
