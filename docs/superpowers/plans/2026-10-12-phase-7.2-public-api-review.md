# Phase 7.2: Public API Review Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Review the public API of all six packages once before 1.0, apply the approved findings, guard the mechanical rules with tests, label the OpenAI adapter as unverified, and leave `PublicAPI.Shipped.txt` describing 1.0.0.

**Architecture:** Task 1 is a read-only audit that writes a findings document. Execution then **stops for the maintainer**, who rules on every breaking (B) finding. Tasks 2–4 apply the pre-seeded findings, whose content is already decided. Tasks 5–8 apply the approved audit findings package by package. Task 9 adds the four guard tests after the surface has settled. Task 10 finalises the Shipped files, and Task 11 does the tracker work and the full verification.

**Tech Stack:** .NET 10, C#, xUnit, Roslyn (`Microsoft.CodeAnalysis`) in `tests/Minos.NET.AotSmoke.Tests`, the PublicAPI analyzers (RS0016/RS0017), mdsnippets.

**Spec:** `docs/superpowers/specs/2026-10-12-phase-7.2-public-api-review-design.md`

## Global Constraints

- The six packages are `Minos.NET`, `Minos.NET.SystemOne`, `Minos.NET.OpenAI`, `Minos.NET.DependencyInjection`, `Minos.NET.Caching` and `Minos.NET.RateLimiting`. The analyzers, code fixes, generator and conformance projects are not in scope.
- **The maintainer approves every breaking change.** No B finding is applied before the maintainer has approved, rejected or amended it in the findings document. N findings are applied without a separate approval: XML doc fixes, nullability annotations that only tighten, internal tidy-ups, and additive members the findings document lists.
- **The surface keeps what is documented.** A public member stays public when a docs page, a sample or a documented scenario uses it.
- New features are out of scope. A finding whose real fix is a feature is documented, and filed for 1.x.
- api-compat setup (Phase 7.5), live runs (Phase 7.3), and benchmark and AOT re-verification (Phase 7.4) are out of scope.
- The build treats warnings as errors, with the Meziantou, Roslynator, ZeroAlloc and PublicAPI analyzers. **Never suppress a warning** with `#pragma`, `[SuppressMessage]`, `.editorconfig` or `NoWarn`; fix its cause.
- Every public API change updates the package's `PublicAPI.Unshipped.txt`. Removing or changing a line that is in `PublicAPI.Shipped.txt` adds a `*REMOVED*<old line>` to `PublicAPI.Unshipped.txt` until Task 10.
- A new public method or constructor needs a `[Covers("<exact PublicAPI line>")]` call in `samples/Minos.NET.AotSmoke`, or `EntryPointCoverageTests` fails. A new public generic type or generic method needs an instantiation in `samples/Minos.NET.AotSurface`, or `SurfaceGenericsTests` fails.
- Docs code blocks come from `tests/Minos.NET.Docs.Tests` through mdsnippets. Edit the `.cs` source, then run `dotnet mdsnippets` from the repository root; never hand-edit a snippet in a `.md` file.
- Allocation budgets do not change. If an approved finding changes a hot path, re-measure its gate; its budget may only go down.
- Build and test from PowerShell with `$env:MSBUILDDISABLENODEREUSE = "1"`. The full commands are `dotnet build Minos.NET.slnx -c Release` and `dotnet test Minos.NET.slnx -c Release --no-build`.
- Commits are conventional, with a scope from `.commitlintrc.yml`: core, generator, di, systemone, openai, ratelimiting, caching, conformance, tests, benchmarks, samples, docs, ci, deps, roadmap, state, sync, milestone, main. A breaking change uses `!` after the scope and a `BREAKING CHANGE:` footer. **No nested parentheses** anywhere in a commit body. Every commit ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, and no commit or PR body contains a `claude.ai/code/session_` link.

### Task 1: The audit and the findings document

This task changes no code. The controller runs it directly: it dispatches the reviewers, merges their output and commits the document. **After this task, execution stops until the maintainer has ruled on every B finding.** That stop is the spec's Stage 2, not a stall.

Every reviewer's prompt contains:
1. Its scope and id prefix, from the table.
2. The files to read: the package's `PublicAPI.Shipped.txt` and `PublicAPI.Unshipped.txt`, its source, `docs/*.md`, `samples/` except `Minos.NET.AotSmoke` and `Minos.NET.AotSurface`, and the root `README.md`.
3. The checklist, copied verbatim from the spec's "The checklist" table, all eleven rows.
4. The spec's "Decisions" section, copied verbatim, so it knows the keep-what-is-documented rule.
5. The output contract: one entry per finding, in this shape:

```markdown
### CORE-07: <one-line summary>

- **Flag:** B | N
- **Lines:** `<the PublicAPI line or lines>`
- **Problem:** <what is wrong, and why it matters to a 1.0 user>
- **Proposal:** <the exact change: new signature, new name, new doc text, or "make internal">
- **Checklist area:** <one of the eleven areas>
```

6. The rules for the flag: **B** when any existing caller's source or binary breaks, or when behaviour a caller can observe changes. **N** otherwise.
7. The instruction to report only verified findings, each checked against the source, and to drop cosmetic nits.
8. The instruction to change no file other than its own audit file, and to dispatch no subagents.

The stages-di reviewer also gets the pre-seeded ids CACHE-01 to CACHE-07 and RL-01 from the spec's Section 2, so it does not report them again.

- [ ] **Step 1: Write the tests**

```csharp
using System.Text.RegularExpressions;
using Microsoft.CodeAnalysis;

namespace Minos.AotSmoke.Tests;

/// <summary>
/// The mechanical rules the six packages' public surface keeps for 1.0, checked over the package assemblies the AOT smoke
/// app references. Each test names every member that breaks its rule.
/// </summary>
public sealed partial class SurfaceRuleTests
{
    private const string ServiceCollection = "Microsoft.Extensions.DependencyInjection.IServiceCollection";
    private const string ServiceCollectionNamespace = "Microsoft.Extensions.DependencyInjection";

    // Each package's assembly and the namespace its extension classes live in.
    private static readonly (string Assembly, string RootNamespace)[] Packages =
    [
        ("Minos.NET", "Minos"),
        ("Minos.NET.SystemOne", "Minos.SystemOne"),
        ("Minos.NET.OpenAI", "Minos.OpenAI"),
        ("Minos.NET.DependencyInjection", "Minos"),
        ("Minos.NET.Caching", "Minos.Caching"),
        ("Minos.NET.RateLimiting", "Minos.RateLimiting"),
    ];

    // Public classes designed for inheritance that are not abstract.
    private static readonly Dictionary<string, string> Unsealed = new(StringComparer.Ordinal)
    {
        ["Minos.DecisionClientBuilder"] = "DecisionClientServiceBuilder in Minos.NET.DependencyInjection derives from it.",
        ["Minos.DecisionClientServiceBuilder"] = "SystemOneClientServiceBuilder and OpenAIDecisionClientServiceBuilder derive from it.",
    };

    // Public types no docs page or sample names.
    private static readonly Dictionary<string, string> Undocumented = new(StringComparer.Ordinal);

    // The folders under docs/ that are not published pages.
    private static readonly string[] UnpublishedDocs = ["design", "planning", "plans", "superpowers"];

    // The samples that exist to reach the whole surface, so naming a type there documents nothing.
    private static readonly string[] SurfaceHosts = ["Minos.NET.AotSmoke", "Minos.NET.AotSurface"];

    [Fact]
    public void The_packages_have_public_types_to_check()
        // Guards the tests below against passing vacuously, for example if the assemblies stopped being found.
        => Assert.True(PublicTypes().Count() > 50);

    [Fact]
    public void Every_public_class_is_sealed_abstract_static_or_designed_for_inheritance()
    {
        var offenders = PublicTypes()
            .Where(type => type.TypeKind == TypeKind.Class && !type.IsSealed && !type.IsAbstract && !type.IsStatic)
            .Select(Name)
            .Where(name => !Unsealed.ContainsKey(name))
            .ToList();

        Assert.True(offenders.Count == 0, "These public classes are neither sealed nor abstract; seal them or add them to Unsealed with a reason:\n" + string.Join('\n', offenders));
        Assert.All(Unsealed.Keys, name => Assert.Contains(name, PublicTypes().Select(Name)));
    }

    [Fact]
    public void Every_public_method_returning_a_task_ends_in_Async()
    {
        var offenders = PublicTypes()
            .SelectMany(type => type.GetMembers().OfType<IMethodSymbol>())
            .Where(method => method.MethodKind == MethodKind.Ordinary
                && method.DeclaredAccessibility is Accessibility.Public or Accessibility.Protected or Accessibility.ProtectedOrInternal
                && IsTask(method.ReturnType)
                && !method.Name.EndsWith("Async", StringComparison.Ordinal))
            .Select(method => method.ToDisplayString())
            .ToList();

        Assert.True(offenders.Count == 0, "These public methods return a Task or ValueTask but do not end in Async:\n" + string.Join('\n', offenders));
    }

    [Fact]
    public void Every_public_type_is_named_in_the_docs_or_a_sample()
    {
        var text = DocumentationText();
        var offenders = PublicTypes()
            .Where(type => !Undocumented.ContainsKey(Name(type)) && !Mentions(text, type.Name))
            .Select(Name)
            .ToList();

        Assert.True(offenders.Count == 0, "No published docs page or sample names these public types; document them, make them internal, or add them to Undocumented with a reason:\n" + string.Join('\n', offenders));
    }

    [Fact]
    public void Every_public_extension_class_is_in_the_namespace_its_users_import()
    {
        var offenders = new List<string>();
        foreach (var (assembly, rootNamespace) in Packages)
        {
            foreach (var type in PublicTypes(assembly).Where(type => type.IsStatic && type.MightContainExtensionMethods))
            {
                var extendsServices = type.GetMembers().OfType<IMethodSymbol>()
                    .Any(method => method.IsExtensionMethod && string.Equals(method.Parameters[0].Type.ToDisplayString(), ServiceCollection, StringComparison.Ordinal));
                var expected = extendsServices ? ServiceCollectionNamespace : rootNamespace;
                var actual = type.ContainingNamespace.ToDisplayString();
                if (!string.Equals(actual, expected, StringComparison.Ordinal))
                {
                    offenders.Add($"{Name(type)} is in {actual}, expected {expected}");
                }
            }
        }

        Assert.True(offenders.Count == 0, "These extension classes are not where their users look for them:\n" + string.Join('\n', offenders));
    }

    private static IEnumerable<INamedTypeSymbol> PublicTypes() => Packages.SelectMany(package => PublicTypes(package.Assembly));

    private static IEnumerable<INamedTypeSymbol> PublicTypes(string assemblyName)
    {
        var compilation = SampleCompilation.Smoke.Compilation;
        var assembly = compilation.References
            .Select(compilation.GetAssemblyOrModuleSymbol)
            .OfType<IAssemblySymbol>()
            .First(candidate => string.Equals(candidate.Name, assemblyName, StringComparison.Ordinal));
        return Types(assembly.GlobalNamespace);
    }

    private static IEnumerable<INamedTypeSymbol> Types(INamespaceSymbol ns)
        => ns.GetNamespaceMembers().SelectMany(Types).Concat(ns.GetTypeMembers().SelectMany(Types));

    private static IEnumerable<INamedTypeSymbol> Types(INamedTypeSymbol type)
        => type.DeclaredAccessibility != Accessibility.Public ? [] : type.GetTypeMembers().SelectMany(Types).Prepend(type);

    private static string Name(INamedTypeSymbol type) => type.ToDisplayString(SymbolDisplayFormat.CSharpErrorMessageFormat.WithGenericsOptions(SymbolDisplayGenericsOptions.None));

    private static bool IsTask(ITypeSymbol type)
        => type.ContainingNamespace?.ToDisplayString() == "System.Threading.Tasks"
            && type.Name is "Task" or "ValueTask";

    private static string DocumentationText()
    {
        var docs = Path.Combine(Repository.Root, "docs");
        var pages = Directory.EnumerateFiles(docs, "*.md", SearchOption.AllDirectories)
            .Where(page => !UnpublishedDocs.Contains(Path.GetRelativePath(docs, page).Split(Path.DirectorySeparatorChar, Path.AltDirectorySeparatorChar)[0], StringComparer.Ordinal));
        var samples = Path.Combine(Repository.Root, "samples");
        var sources = Directory.EnumerateFiles(samples, "*.cs", SearchOption.AllDirectories)
            .Where(source =>
            {
                var relative = Path.GetRelativePath(samples, source).Split(Path.DirectorySeparatorChar, Path.AltDirectorySeparatorChar);
                return !SurfaceHosts.Contains(relative[0], StringComparer.Ordinal) && !relative.Contains("obj", StringComparer.Ordinal) && !relative.Contains("bin", StringComparer.Ordinal);
            });
        return string.Join('\n', pages.Concat(sources).Select(File.ReadAllText));
    }

    private static bool Mentions(string text, string typeName) => Regex.IsMatch(text, $@"\b{Regex.Escape(typeName)}\b", RegexOptions.CultureInvariant, TimeSpan.FromSeconds(5));
}
```

`IsTask` uses `==` on a `string?`; if Meziantou or Roslynator flags it, use `string.Equals(..., StringComparison.Ordinal)`. If an analyzer flags `Regex.IsMatch` with a pattern built at run time, keep the timeout and fix whatever it asks for; do not suppress it. Drop the `partial` modifier if no `[GeneratedRegex]` ends up in the class.

- **Extension namespace:** a missed finding, handled as for sealing.
