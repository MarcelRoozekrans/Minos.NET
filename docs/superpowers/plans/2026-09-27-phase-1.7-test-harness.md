# Phase 1.7 Test Harness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `JevClient` is proven over real sockets against WireMock.Net in CI, and against the live TypeSafe and OpenRouter APIs on demand, and the four unit-test gaps in #17 are closed.

**Architecture:** There are two new test projects:
- `tests/ZeroAlloc.Jev.Integration.Tests` runs WireMock.Net 2.18.0 and runs in the CI `build` job.
- `tests/ZeroAlloc.Jev.Live.Tests` holds `[LiveFact]` tests that skip when their provider's key is missing. A manual `live-smoke.yml` workflow runs it with secrets from a `live-api` environment.

The existing unit projects gain the #17 tests.

**Tech Stack:** .NET 10, xUnit v2.9.3, WireMock.Net 2.18.0, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-27-phase-1.7-test-harness-design.md`

## Global Constraints

- **Branch.** Work on branch `phase/1.7-test-harness`, which is already checked out. Commit there. Do **not** push, open pull requests or touch GitHub settings.
- **Billing danger.** `OPENROUTER_API_KEY` is set on this machine, so running the live project makes **billed** calls.
  - Never run `dotnet test` on the whole solution, and never run `tests/ZeroAlloc.Jev.Live.Tests` with the key visible.
  - Run the unit and integration projects by path.
  - To check the live project, build it, then run it with both keys removed from the process environment. In bash: `env -u OPENROUTER_API_KEY -u TYPESAFE_API_KEY dotnet test tests/ZeroAlloc.Jev.Live.Tests -c Release`. Every test must report skipped.
  - Only the controller makes a live run.
- **Secrets.** Never print, log or commit an API key. Test output may show response headers and bodies but never the request's `Authorization` value.
- **Build rules.** `TreatWarningsAsErrors` stays on, with the repo's analyzers. Fix analyzer findings in code. Suppress only a demonstrable false positive, narrowly, with a comment and a tracking issue number. The HLQ005 false positive on xUnit `Assert.Single` is tracked as #38; reuse the existing pragma pattern for it.
- **Timing tests.** Assert lower bounds only. Take request counts from WireMock's log, never from timing. Use small time-outs and backoffs.
- **Fixtures and environment.**
  - Link the existing fixtures from `tests/ZeroAlloc.Jev.Tests/Fixtures`; don't copy them.
  - Integration tests set every `JevClientOptions` value they depend on (`ApiKey`, `BaseAddress`, `MaxRetries`, `InitialBackoff`, `Timeout`) so the environment cannot leak in.
- **No backslash-u in source.** Write no backslash-u escape sequences in C# or JSON test data. Where a non-ASCII or control character is needed, build it with `(char)0x00E9` or similar, or with `char.ConvertFromUtf32`.
- **Commits.**
  - Use conventional types and scopes from `.commitlintrc.yml`: `tests` for test projects, `ci` for workflows, `docs`, `deps` for package versions.
  - End with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and nothing else: no `Claude-Session:` line and no claude.ai links.
  - No nested parentheses in commit bodies.
- **Helper names.** Test code in this plan names existing helpers and APIs from memory. Where the real API differs, follow the existing code and test files, keep the test's intent, and report each adaptation.
- **Baseline.** 229 tests in `tests/ZeroAlloc.Jev.Tests` and 55 in `tests/ZeroAlloc.Jev.Generator.Tests`, with 0 warnings. `dotnet build ZeroAlloc.Jev.slnx -c Release` must stay at 0 warnings after every task.

```csharp
namespace ZeroAlloc.Jev.Live.Tests;

/// <summary>A fact that runs only when the provider's API key is set; the calls are real and may be billed.</summary>
[AttributeUsage(AttributeTargets.Method)]
public sealed class LiveFactAttribute : FactAttribute
{
    public LiveFactAttribute(JevProvider provider)
    {
        Provider = provider;
        var variable = provider == JevProvider.OpenRouter
            ? JevDefaults.OpenRouterApiKeyEnvironmentVariable
            : JevDefaults.ApiKeyEnvironmentVariable;
        if (string.IsNullOrWhiteSpace(Environment.GetEnvironmentVariable(variable)))
        {
            Skip = "Set " + variable + " to run this live test; it calls the real API.";
        }
    }

    public JevProvider Provider { get; }
}
```

### Task 5: Manual live-smoke workflow

**Files:**
- Create: `.github/workflows/live-smoke.yml`

- [ ] **Step 1: Workflow.**

```yaml
name: Live smoke

# Calls the real TypeSafe and OpenRouter APIs, which bills a few small evaluations per run.
# Manual only: never on pull requests or pushes, so forks can never reach the keys.
on:
  workflow_dispatch:

permissions:
  contents: read

jobs:
  live:
    runs-on: ubuntu-latest
    timeout-minutes: 10
    environment: live-api
    steps:
      - uses: actions/checkout@v7

      - name: Setup .NET
        uses: actions/setup-dotnet@v6
        with:
          global-json-file: global.json
          dotnet-version: '10.0.x'

      - name: Live tests
        env:
          TYPESAFE_API_KEY: ${{ secrets.TYPESAFE_API_KEY }}
          OPENROUTER_API_KEY: ${{ secrets.OPENROUTER_API_KEY }}
          JEV_LIVE_MODEL: ${{ vars.JEV_LIVE_MODEL }}
          JEV_LIVE_OPENROUTER_MODEL: ${{ vars.JEV_LIVE_OPENROUTER_MODEL }}
        run: dotnet test tests/ZeroAlloc.Jev.Live.Tests -c Release --logger "console;verbosity=detailed"
```
