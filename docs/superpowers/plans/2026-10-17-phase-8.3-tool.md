# Phase 8.3 The minos Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `Minos.NET.Tool`, a dotnet tool `minos` with `calibrate`, `report` and `conformance`, and publish it with `Minos.NET.Evaluation` as 1.2.0. A run that a client stops keeps its paid results (#228).

**Architecture:**
- **Library:** `DatasetRunException` and partial-run support go in the library, `Minos.NET.Evaluation`.
- **Tool:** an internal `MinosCli.RunAsync(args, stdout, stderr, networkFactory, token)` holds all the logic, with System.CommandLine 2.0.13 parsing. `Program.Main` only calls it. Tests drive it in-process with a fake `HttpMessageHandler`.
- **Packaging:** the existing gates are extended from 6 to 8 packages.

**Tech Stack:** .NET 10, C#, System.CommandLine 2.0.13, Microsoft.Extensions.Configuration (JSON plus environment), xUnit, ZeroAlloc.TestHelpers snapshots, Python 3 for `inspect_packages.py`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-17-phase-8.3-tool-design.md`. Read "Decisions", "`DatasetRunException` (#228)" and "Settled after the builder check".

## Global Constraints

- **Packages:**
  - `Minos.NET.Tool` has `PackAsTool`, `ToolCommandName` `minos`, targets `net10.0`, and is not AOT.
  - The tool has no public API: everything is `internal`, with `InternalsVisibleTo Minos.NET.Tool.Tests`.
  - `Minos.NET.Evaluation` becomes packable. `Minos.NET.Conformance` stays non-packable and is bundled in the tool.
- **Commands:**
  - `minos calibrate --dataset <file> [--config <file>] [--provider <name>] [--model <id>] [--parallel <n>] [--prices <file>] [--out <dir>]`
  - `minos report --results <file> --dataset <file> [--prices <file>] [--out <dir>]`
  - `minos conformance [--config <file>] [--provider <name>] [--model <id>] [--out <dir>]`
- **Defaults:**
  - `--config`: `minos.json` in the current directory.
  - `--provider`: `Minos:Active`.
  - `--parallel`: 1.
  - `--out`: `minos-out/<provider>-<UTC yyyyMMdd-HHmmss>/`. For `report`, the provider comes from the results header.
- **Files written:**
  - `calibrate`: `results.jsonl`, `report.json` and `report.md`. On a `DatasetRunException` it writes `results.partial.jsonl` plus the reports built from it.
  - `report`: `report.json` and `report.md`.
  - `conformance`: `conformance.json` and `conformance.md`.
- **Configuration:**
  - The `Minos` section of a chain: the `--config` JSON file, then unprefixed environment variables, for example `Minos__Providers__OpenRouter__Model`.
  - Each provider section binds to `SystemOneDecisionClientOptions`, and `--model` overrides `Model`.
  - The binding uses the source-generated configuration binder, as `Minos.NET.SystemOne` does; no reflection binding.
- **Prices file:** `{"prices":[{"model":"…","inputPerMillion":0.042,"outputPerMillion":0,"date":"2026-10-17","source":"…"}]}`.
- **Conformance target:**
  - The wire is `SystemOne`.
  - The model is `--model`, then the section's `Model`, then `SystemOneDefaults.Model`.
  - The `ModelRule` is `ModelRule.TypeSafe` for TypeSafe and `ModelRule.OpenRouter` for OpenRouter; any other provider has no rule.
  - Its `createClient` is `http => { SystemOneDecisionClient.ConfigureHttpClient(http, options); return new SystemOneDecisionClient(http, options); }`.
  - It runs in `ConformanceMode.Live`.
- **Exit codes:**
  - 0: success, where a skipped check counts as a pass.
  - 1: a run-time failure: a `DatasetRunException`, a failed check, a network or unexpected exception, or an output directory that cannot be written.
  - 2: input, usage or configuration problems.
  - 130: cancelled.

  Failures print one line on stderr. Dataset and results problems are printed one per line, as `line N: message`.
- **#228 contract:**
  - `public sealed class DatasetRunException : Exception`, with `EvaluationResults PartialResults`. The original exception is its `InnerException`.
  - The partial results hold the finished items in dataset order, their header has `Partial = true`, and `ItemCount` is the number of finished items.
  - `RunHeader.Partial` is saved as `"partial": true` and is absent when false.
  - With a partial header, `CalibrationReport.Create` matches by id: the items must be a subset of the dataset in dataset order.
  - The report gains `bool Partial` and `int DatasetItemCount`. The Markdown shows "Partial run: N of M items", and the JSON has `header.partial` and `datasetItemCount`.
- **Package validation:** off for `Minos.NET.Evaluation` and `Minos.NET.Tool`, which have no 1.0.1. A comment says to set the baseline after their first release.
- **READMEs:** each new package packs its own README in place of the root one.
- **Dependencies:** add `System.CommandLine` 2.0.13 to `Directory.Packages.props`. Only the tool references it.
- **Commits:**
  - `feat:` with no scope for library and tool code;
  - `test(tests):`, `docs(docs):` and `ci(ci):` elsewhere;
  - no nested parentheses in bodies;
  - every message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - always use `export MSBUILDDISABLENODEREUSE=1`.

## Review Focus

1. **A dataset path that does not exist, a directory, or a file that is not readable** exits 2 with a clear one-line message, not a stack trace. Pinned in Task 2.
2. **`--parallel 0` or a non-number:** System.CommandLine's validation exits 2 with its error before any request. Pinned in Task 2.
3. **`--out` pointing at an existing directory that holds a previous run:** files are overwritten atomically, through `EvaluationResults.Save`'s temp-and-move, and are never mixed. The command reports what it wrote. Pinned in Task 2.
4. **Ctrl+C during `calibrate`:** exit 130, and nothing partial is written in place of `results.jsonl`. Cancellation is not a `DatasetRunException`. Pinned in Task 3 with a cancelled token.
5. **A `minos.json` whose `Minos:Active` names a missing section, or that has no `Minos` section at all:** exit 2, with a message naming the providers that are present. Pinned in Task 2.
