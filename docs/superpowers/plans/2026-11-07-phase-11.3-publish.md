# Publish When Upstream Ships Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Check for an upstream package with the decision types, then either publish `Minos.NET.Extensions.AI.Decisions` as a beta or file the wait and defer the phase, for Phase 11.3.

**Architecture:** A script checks nuget.org for the type. Task 1 decides the path; Tasks 2 to 5 run only when a package exists, and Task 6 only when none does.

**Tech Stack:** bash, `System.Reflection.MetadataLoadContext`, release-please, `tools/release/inspect_packages.py`.

**Spec:** `docs/superpowers/specs/2026-11-07-phase-11.3-publish-design.md`

**Builds on:** Phase 11.2 — the project `src/Minos.NET.Extensions.AI.Decisions`, its tests in `tests/Minos.NET.Extensions.AI.Decisions.Tests`, and its `IsPackable` false rule.

## Global Constraints

- Tasks 2 to 5 are marked `park`: if Task 1 finds an upstream package, the unattended run stops there and the maintainer does the publish attended. Task 6 runs when none is found.

- Nothing is published unless the script finds a real upstream package with `IDecisionClient`. Never reference a locally built assembly in a packed project.
- A new package dependency is added to `tools/release/inspect_packages.py` or `pack-validate` fails.
- The release goes through release-please as a minor release, with ApiCompat clean. Merge is the maintainer's call.
- Commit messages are `feat: <subject>`, `ci: <subject>` or `chore: <subject>`, no Claude trailer, no nested parentheses in the body. Run `MSBUILDDISABLENODEREUSE=1` before `dotnet` commands.

Tasks 2-5 not run: the gate exited 1 on 2026-11-07; they stay unticked on purpose until `find-decisions-package.sh` exits 0 (#352).
