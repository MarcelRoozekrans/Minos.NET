# Phase 7.1: Caching and Rate-Limiting Stages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two pipeline stages, `UseHybridCache` in a new `Minos.NET.Caching` package and `UseRateLimiting` in a new `Minos.NET.RateLimiting` package, documented, tested, packed and covered by the AOT checks, so Phase 7.2's API review and the 1.0 freeze include them.

**Architecture:** Both stages derive from core's `DelegatingDecisionClient` and are added with a `DecisionClientBuilder` extension. Core gains only what the cache needs from its internals: a public `DecisionResponse.IsCached`, an internal cache-key builder, a `minos.cache.hit` span and metric tag, and a `{Cached}` field on log event 1001. The caching package reaches those internals through InternalsVisibleTo, as `Minos.NET.SystemOne` and `Minos.NET.OpenAI` do. The rate-limiting package uses public API only.

**Tech Stack:** .NET 10, C#, `Microsoft.Extensions.Caching.Hybrid` 10.0.0, `System.Threading.RateLimiting` 10.0.0, xUnit 2.9, ZeroAlloc.Telemetry 1.11.0 (generated span and metric proxy), ZeroAlloc.TestHelpers 1.5.1 (`AllocationGate`), MarkdownSnippets.

**Spec:** `docs/superpowers/specs/2026-10-12-phase-7.1-pipeline-stages-design.md`

```csharp
    /// <summary>
    /// Writes this content to a cache key: a tag for text, a caller's UTF-8 state or structured JSON, then its bytes.
    /// Equal contents in different forms, such as text and the same text as a UTF-8 JSON string, get different keys;
    /// that costs a cache miss, never a wrong answer.
    /// </summary>
    /// <param name="writer">The key being written.</param>
    internal void WriteCacheKey(ref DecisionCacheKey.Writer writer)
    {
        switch (_value)
        {
            case string text:
                writer.Tag((byte)'T');
                writer.Text(text);
                break;
            case byte[] utf8:
                writer.Tag((byte)'U');
                writer.Bytes(utf8);
                break;
            default:
                if (_json.ValueKind == JsonValueKind.Undefined)
                {
                    writer.Tag(0);
                }
                else
                {
                    writer.Tag((byte)'J');
                    writer.Bytes(JsonMarshal.GetRawUtf8Value(_json));
                }

                break;
        }
    }
```

Add `using System.Runtime.InteropServices;` if the file does not have it; `JsonMarshal` lives there.

```csharp
using System.Buffers;
using System.Buffers.Binary;
using System.Buffers.Text;
using System.Security.Cryptography;
using System.Text;

namespace Minos;

/// <summary>
/// The cache key of a request, for <c>Minos.NET.Caching</c>: a SHA-256 digest over the definition, the state, the images,
/// the model, and the client's provider and endpoint. The retry attempt is left out, so a retried call finds the entry
/// its first attempt stored.
/// </summary>
/// <remarks>
/// Every variable-length field is written with its length first, so two different requests never write the same bytes.
/// The definition's part is a digest of its own, computed once per definition instance and kept in its protocol-data
/// slot. Each image is hashed on its own, so the buffer never holds image bytes.
/// </remarks>
internal static class DecisionCacheKey
{
    // Bumped when the layout below changes, so keys written by an older layout are never read as current ones.
    private const byte Layout = 1;

    private const int DefinitionSlot = 2;

    private const int DigestLength = 32;

    // The digest's unpadded Base64Url length.
    private const int EncodedLength = 43;

    public static string Create(DecisionRequest request, string provider, string? endpoint, string prefix)
    {
        var definition = request.Definition.GetOrAddProtocolData(DefinitionSlot, static d => DefinitionDigest(d));
        Span<byte> digest = stackalloc byte[DigestLength];
        Span<byte> imageDigest = stackalloc byte[DigestLength];
        var writer = new Writer(256);
        try
        {
            writer.Tag(Layout);
            writer.Bytes(definition);
            request.State.WriteCacheKey(ref writer);
            writer.Text(request.Model);
            writer.Text(provider);
            writer.Text(endpoint);
            var images = request.Images;
            writer.Int(images.Count);
            for (var i = 0; i < images.Count; i++)
            {
                writer.Text(images[i].MediaType);
                SHA256.HashData(images[i].Data.Span, imageDigest);
                writer.Bytes(imageDigest);
            }

            writer.Hash(digest);
        }
        finally
        {
            writer.Dispose();
        }

        return string.Create(prefix.Length + EncodedLength, (prefix, Digest: digest.ToArray()), static (chars, state) =>
        {
            state.prefix.AsSpan().CopyTo(chars);
            Base64Url.EncodeToChars(state.Digest, chars[state.prefix.Length..]);
        });
    }

    private static byte[] DefinitionDigest(QuestionSetDefinition definition)
    {
        var writer = new Writer(1024);
        try
        {
            var questions = definition.QuestionArray;
            writer.Int(questions.Length);
            foreach (var question in questions)
            {
                writer.Text(question.Key);
                writer.Int((int)question.Kind);
                question.Instructions.WriteCacheKey(ref writer);
                Optional(ref writer, question.WhenTrue);
                Optional(ref writer, question.WhenFalse);
                var options = question.OptionArray;
                writer.Int(options.Length);
                foreach (var option in options)
                {
                    writer.Text(option.Key);
                    Criterion(ref writer, option.Criterion);
                }
            }

            var digest = new byte[DigestLength];
            writer.Hash(digest);
            return digest;
        }
        finally
        {
            writer.Dispose();
        }
    }

    private static void Optional(ref Writer writer, DecisionContent? content)
    {
        if (content is { } value)
        {
            writer.Tag(1);
            value.WriteCacheKey(ref writer);
        }
        else
        {
            writer.Tag(0);
        }
    }

    private static void Criterion(ref Writer writer, Criterion? criterion)
    {
        if (criterion is null)
        {
            writer.Tag(0);
            return;
        }

        writer.Tag(1);
        writer.Text(criterion.Description);
        Optional(ref writer, criterion.JsonContent);
        Texts(ref writer, criterion.ExampleEntries);
        Texts(ref writer, criterion.NotForEntries);
    }

    private static void Texts(ref Writer writer, ReadOnlySpan<string?> texts)
    {
        writer.Int(texts.Length);
        foreach (var text in texts)
        {
            writer.Text(text);
        }
    }

    /// <summary>A growable byte buffer rented from the shared pool; dispose it to return the buffer.</summary>
    internal struct Writer
    {
        private byte[] _buffer;
        private int _length;

        public Writer(int capacity) => _buffer = ArrayPool<byte>.Shared.Rent(capacity);

        public void Tag(byte value)
        {
            Ensure(1);
            _buffer[_length++] = value;
        }

        public void Int(int value)
        {
            Ensure(sizeof(int));
            BinaryPrimitives.WriteInt32LittleEndian(_buffer.AsSpan(_length), value);
            _length += sizeof(int);
        }

        public void Bytes(ReadOnlySpan<byte> value)
        {
            Int(value.Length);
            Ensure(value.Length);
            value.CopyTo(_buffer.AsSpan(_length));
            _length += value.Length;
        }

        // A null text is written as length -1, so it differs from an empty one.
        public void Text(string? value)
        {
            if (value is null)
            {
                Int(-1);
                return;
            }

            var count = Encoding.UTF8.GetByteCount(value);
            Int(count);
            Ensure(count);
            _length += Encoding.UTF8.GetBytes(value, _buffer.AsSpan(_length));
        }

        public readonly void Hash(Span<byte> destination) => SHA256.HashData(_buffer.AsSpan(0, _length), destination);

        public void Dispose()
        {
            ArrayPool<byte>.Shared.Return(_buffer);
            _buffer = [];
        }

        private void Ensure(int count)
        {
            if (_length + count <= _buffer.Length)
            {
                return;
            }

            var larger = ArrayPool<byte>.Shared.Rent(Math.Max(_buffer.Length * 2, _length + count));
            _buffer.AsSpan(0, _length).CopyTo(larger);
            ArrayPool<byte>.Shared.Return(_buffer);
            _buffer = larger;
        }
    }
}
```

```csharp
using System.Threading.RateLimiting;
using ZeroAlloc.Results;

namespace Minos.RateLimiting;

/// <summary>A stage that takes one permit from a <see cref="RateLimiter"/> for each call, before the call is sent.</summary>
/// <remarks>
/// <para>
/// A call waits for its permit as the limiter is configured, and holds it until the call completes, so a
/// <see cref="ConcurrencyLimiter"/> counts calls in flight. A call the limiter rejects returns a
/// <see cref="DecisionErrorKind.RateLimited"/> error without reaching the provider: its <see cref="DecisionError.StatusCode"/>
/// is <see langword="null"/>, which tells it apart from a server's 429, and its <see cref="DecisionError.RetryAfter"/> is
/// the limiter's <see cref="MetadataName.RetryAfter"/>, when the limiter reports one.
/// </para>
/// <para>
/// Cancelling a call while it waits for its permit throws <see cref="OperationCanceledException"/>. The limiter belongs to
/// the caller, who may share it across clients; disposing the stage disposes the inner client, never the limiter.
/// </para>
/// </remarks>
public sealed class RateLimitingDecisionClient : DelegatingDecisionClient
{
    /// <summary>The message of the error a rejected call returns.</summary>
    public const string RejectedMessage = "The client's rate limiter rejected the call before it was sent.";

    private readonly RateLimiter _limiter;

    /// <summary>Initializes a new instance of the <see cref="RateLimitingDecisionClient"/> class.</summary>
    /// <param name="innerClient">The client to limit.</param>
    /// <param name="limiter">The limiter each call takes a permit from. The caller owns it.</param>
    /// <exception cref="ArgumentNullException"><paramref name="innerClient"/> or <paramref name="limiter"/> is <see langword="null"/>.</exception>
    public RateLimitingDecisionClient(IDecisionClient innerClient, RateLimiter limiter)
        : base(innerClient)
    {
        ArgumentNullException.ThrowIfNull(limiter);
        _limiter = limiter;
    }

    /// <inheritdoc />
    public override ValueTask<Result<DecisionResponse, DecisionError>> EvaluateAsync(DecisionRequest request, CancellationToken cancellationToken = default)
    {
        ArgumentNullException.ThrowIfNull(request);
        var acquiring = _limiter.AcquireAsync(1, cancellationToken);
        return acquiring.IsCompletedSuccessfully
            ? Proceed(acquiring.Result, request, cancellationToken)
            : AcquireThenProceedAsync(acquiring, request, cancellationToken);
    }

    private async ValueTask<Result<DecisionResponse, DecisionError>> AcquireThenProceedAsync(
        ValueTask<RateLimitLease> acquiring, DecisionRequest request, CancellationToken cancellationToken)
    {
        var lease = await acquiring.ConfigureAwait(false);
        return await Proceed(lease, request, cancellationToken).ConfigureAwait(false);
    }

    // Sends the call under the lease, and disposes the lease when the call completes; a rejected lease sends nothing.
    private ValueTask<Result<DecisionResponse, DecisionError>> Proceed(RateLimitLease lease, DecisionRequest request, CancellationToken cancellationToken)
    {
        if (!lease.IsAcquired)
        {
            var error = new DecisionError(DecisionErrorKind.RateLimited, RejectedMessage)
            {
                RetryAfter = lease.TryGetMetadata(MetadataName.RetryAfter, out TimeSpan retryAfter) ? retryAfter : null,
            };
            lease.Dispose();
            return new(Result<DecisionResponse, DecisionError>.Failure(error));
        }

        ValueTask<Result<DecisionResponse, DecisionError>> call;
        try
        {
            call = InnerClient.EvaluateAsync(request, cancellationToken);
        }
        catch
        {
            lease.Dispose();
            throw;
        }

        if (call.IsCompleted)
        {
            lease.Dispose();
            return call;
        }

        return ReleaseWhenDoneAsync(call, lease);
    }

    private static async ValueTask<Result<DecisionResponse, DecisionError>> ReleaseWhenDoneAsync(
        ValueTask<Result<DecisionResponse, DecisionError>> call, RateLimitLease lease)
    {
        using (lease)
        {
            return await call.ConfigureAwait(false);
        }
    }
}
```

```csharp
using ZeroAlloc.Results;

namespace Minos.Caching.Tests;

/// <summary>An inner client that answers from a script, counts its calls and offers the given metadata.</summary>
internal sealed class ScriptedClient(DecisionClientMetadata? metadata = null) : IDecisionClient
{
    private readonly Queue<Result<DecisionResponse, DecisionError>> _script = new();

    public int Calls { get; private set; }

    public ScriptedClient Then(Result<DecisionResponse, DecisionError> result)
    {
        _script.Enqueue(result);
        return this;
    }

    public ScriptedClient ThenAnswer() => Then(Result<DecisionResponse, DecisionError>.Success(Responses.Answer()));

    public ScriptedClient ThenFail(DecisionErrorKind kind)
        => Then(Result<DecisionResponse, DecisionError>.Failure(new DecisionError(kind, "x")));

    public ValueTask<Result<DecisionResponse, DecisionError>> EvaluateAsync(DecisionRequest request, CancellationToken cancellationToken = default)
    {
        Calls++;
        return new(_script.Count > 0 ? _script.Dequeue() : Result<DecisionResponse, DecisionError>.Success(Responses.Answer()));
    }

    public object? GetService(Type serviceType, object? serviceKey = null)
        => serviceKey is null && metadata is not null && serviceType == typeof(DecisionClientMetadata) ? metadata : null;

    public void Dispose()
    {
    }
}
```

```csharp
using System.ComponentModel;

namespace Minos.Caching;

/// <summary>
/// One cached answer: the fields a <see cref="DecisionResponse"/> is rebuilt from, without its definition, which the
/// cache key already covers.
/// </summary>
/// <remarks>
/// HybridCache keeps a sealed type marked <see cref="ImmutableObjectAttribute"/> in its in-process cache as the instance
/// itself, so an L1 hit deserializes nothing. The response built for the first definition instance is kept and returned
/// again for that same instance; an equal definition in another instance gets a response of its own, since the typed
/// calls check the definition's identity. An entry the serializer could not read is <see cref="Unreadable"/> and builds
/// nothing.
/// </remarks>
[ImmutableObject(true)]
internal sealed class CachedDecision
{
    /// <summary>The layout version the serializer writes and reads.</summary>
    public const int Version = 1;

    /// <summary>The entry for a stored value the serializer could not read: an unknown version, or corrupt bytes.</summary>
    public static readonly CachedDecision Unreadable = new([], [], null, null, null, null, null, null);

    private DecisionResponse? _response;

    public CachedDecision(
        AnswerSlot[] slots, double[] probabilities, string? model, int? inputTokens, int? outputTokens, double? cost, string? id, string? provider)
    {
        Slots = slots;
        Probabilities = probabilities;
        Model = model;
        InputTokens = inputTokens;
        OutputTokens = outputTokens;
        Cost = cost;
        Id = id;
        Provider = provider;
    }

    public AnswerSlot[] Slots { get; }

    public double[] Probabilities { get; }

    public string? Model { get; }

    public int? InputTokens { get; }

    public int? OutputTokens { get; }

    public double? Cost { get; }

    public string? Id { get; }

    public string? Provider { get; }

    /// <summary>The entry for a response that was just stored: it keeps <paramref name="cached"/> for its definition.</summary>
    /// <param name="cached">A response made with <see cref="DecisionResponse.AsCached"/>.</param>
    /// <returns>The entry.</returns>
    public static CachedDecision From(DecisionResponse cached)
        => new(cached.Slots, cached.Probabilities, cached.Model, cached.InputTokens, cached.OutputTokens, cached.Cost, cached.Id, cached.Provider)
        {
            _response = cached,
        };

    /// <summary>The cached response for <paramref name="definition"/>, or <see langword="null"/> when this entry does not fit it.</summary>
    /// <param name="definition">The request's definition.</param>
    /// <param name="firstBuild"><see langword="true"/> when this call built the entry's first response, so a read from L2 can be promoted to L1.</param>
    /// <returns>The response, or <see langword="null"/>.</returns>
    public DecisionResponse? ResponseFor(QuestionSetDefinition definition, out bool firstBuild)
    {
        var kept = Volatile.Read(ref _response);
        if (kept is not null && ReferenceEquals(kept.Definition, definition))
        {
            firstBuild = false;
            return kept;
        }

        var built = Fits(definition)
            ? new DecisionResponse(definition, Slots, Probabilities, Model, InputTokens, OutputTokens, Cost, Id, Provider, isCached: true)
            : null;
        firstBuild = kept is null && built is not null && Interlocked.CompareExchange(ref _response, built, null) is null;
        return built;
    }

    // Whether the slots and probabilities have the shape the definition's questions give them. The key covers the
    // definition, so a mismatch means a corrupt entry or a hash collision: either way, a miss.
    private bool Fits(QuestionSetDefinition definition)
    {
        var questions = definition.QuestionArray;
        if (ReferenceEquals(this, Unreadable) || Slots.Length != questions.Length || Probabilities.Length != definition.ProbabilityCount)
        {
            return false;
        }

        for (var i = 0; i < questions.Length; i++)
        {
            var slot = Slots[i];
            if (questions[i].Kind == QuestionKind.Noul)
            {
                continue;
            }

            if (slot.Offset != definition.Offsets[i] || (uint)slot.ValueIndex >= (uint)questions[i].OptionArray.Length)
            {
                return false;
            }
        }

        return true;
    }
}
```

```csharp
using System.Text.Json;
using Microsoft.Extensions.Caching.Hybrid;

namespace Minos.Caching;

/// <summary>
/// The distributed-cache form of a <see cref="CachedDecision"/>: compact JSON with a version field. A slot is
/// <c>[valueIndex, value, confidence, offset]</c>. No reflection, so it is trim- and AOT-safe.
/// </summary>
/// <remarks>
/// Reading never throws. An unknown version or bytes it cannot read give <see cref="CachedDecision.Unreadable"/>, which the
/// stage treats as a miss and overwrites on the next success, so a format change in a later version cannot break callers
/// sharing one distributed cache.
/// </remarks>
internal sealed class CachedDecisionSerializer : IHybridCacheSerializer<CachedDecision>

    public void Serialize(CachedDecision value, IBufferWriter<byte> target)
    {
        using var writer = new Utf8JsonWriter(target);
        writer.WriteStartObject();
        writer.WriteNumber("v"u8, CachedDecision.Version);
        WriteString(writer, "model"u8, value.Model);
        WriteNumber(writer, "input_tokens"u8, value.InputTokens);
        WriteNumber(writer, "output_tokens"u8, value.OutputTokens);
        if (value.Cost is { } cost)
        {
            writer.WriteNumber("cost"u8, cost);
        }

        WriteString(writer, "id"u8, value.Id);
        WriteString(writer, "provider"u8, value.Provider);
        writer.WriteStartArray("slots"u8);
        foreach (var slot in value.Slots)
        {
            writer.WriteStartArray();
            writer.WriteNumberValue(slot.ValueIndex);
            writer.WriteNumberValue(slot.Value);
            writer.WriteNumberValue(slot.Confidence);
            writer.WriteNumberValue(slot.Offset);
            writer.WriteEndArray();
        }

        writer.WriteEndArray();
        writer.WriteStartArray("probabilities"u8);
        foreach (var probability in value.Probabilities)
        {
            writer.WriteNumberValue(probability);
        }

        writer.WriteEndArray();
        writer.WriteEndObject();
    }

    public CachedDecision Deserialize(ReadOnlySequence<byte> source)
    {
        try
        {
            return Read(source) ?? CachedDecision.Unreadable;
        }
        catch (JsonException)
        {
            return CachedDecision.Unreadable;
        }
        catch (InvalidOperationException)
        {
            // A token of the wrong type, such as a string where a number belongs.
            return CachedDecision.Unreadable;
        }
        catch (FormatException)
        {
            return CachedDecision.Unreadable;
        }
    }

    private static CachedDecision? Read(ReadOnlySequence<byte> source)
    {
        var reader = new Utf8JsonReader(source);
        if (!reader.Read() || reader.TokenType != JsonTokenType.StartObject)
        {
            return null;
        }

        int? version = null;
        string? model = null, id = null, provider = null;
        int? inputTokens = null, outputTokens = null;
        double? cost = null;
        List<AnswerSlot>? slots = null;
        List<double>? probabilities = null;
        while (reader.Read() && reader.TokenType == JsonTokenType.PropertyName)
        {
            if (reader.ValueTextEquals("v"u8)) { reader.Read(); version = reader.GetInt32(); }
            else if (reader.ValueTextEquals("model"u8)) { reader.Read(); model = reader.GetString(); }
            else if (reader.ValueTextEquals("input_tokens"u8)) { reader.Read(); inputTokens = reader.GetInt32(); }
            else if (reader.ValueTextEquals("output_tokens"u8)) { reader.Read(); outputTokens = reader.GetInt32(); }
            else if (reader.ValueTextEquals("cost"u8)) { reader.Read(); cost = reader.GetDouble(); }
            else if (reader.ValueTextEquals("id"u8)) { reader.Read(); id = reader.GetString(); }
            else if (reader.ValueTextEquals("provider"u8)) { reader.Read(); provider = reader.GetString(); }
            else if (reader.ValueTextEquals("slots"u8)) { slots = ReadSlots(ref reader); }
            else if (reader.ValueTextEquals("probabilities"u8)) { probabilities = ReadNumbers(ref reader); }
            else
            {
                reader.Read();
                reader.Skip();
            }

            if (slots is null && reader.TokenType == JsonTokenType.None)
            {
                return null;
            }
        }

        if (version != CachedDecision.Version || slots is null || probabilities is null)
        {
            return null;
        }

        return new CachedDecision([.. slots], [.. probabilities], model, inputTokens, outputTokens, cost, id, provider);
    }

    // [[valueIndex, value, confidence, offset], ...]; null when the shape is wrong.
    private static List<AnswerSlot>? ReadSlots(ref Utf8JsonReader reader)
    {
        if (!reader.Read() || reader.TokenType != JsonTokenType.StartArray)
        {
            return null;
        }

        var slots = new List<AnswerSlot>();
        while (reader.Read() && reader.TokenType == JsonTokenType.StartArray)
        {
            reader.Read();
            var valueIndex = reader.GetInt32();
            reader.Read();
            var value = reader.GetDouble();
            reader.Read();
            var confidence = reader.GetDouble();
            reader.Read();
            var offset = reader.GetInt32();
            if (!reader.Read() || reader.TokenType != JsonTokenType.EndArray)
            {
                return null;
            }

            slots.Add(new AnswerSlot(valueIndex, value, confidence, offset));
        }

        return reader.TokenType == JsonTokenType.EndArray ? slots : null;
    }

    private static List<double>? ReadNumbers(ref Utf8JsonReader reader)
    {
        if (!reader.Read() || reader.TokenType != JsonTokenType.StartArray)
        {
            return null;
        }

        var numbers = new List<double>();
        while (reader.Read() && reader.TokenType == JsonTokenType.Number)
        {
            numbers.Add(reader.GetDouble());
        }

        return reader.TokenType == JsonTokenType.EndArray ? numbers : null;
    }

    private static void WriteString(Utf8JsonWriter writer, ReadOnlySpan<byte> name, string? value)
    {
        if (value is not null)
        {
            writer.WriteString(name, value);
        }
    }

    private static void WriteNumber(Utf8JsonWriter writer, ReadOnlySpan<byte> name, int? value)
    {
        if (value is { } number)
        {
            writer.WriteNumber(name, number);
        }
    }
```

```csharp
using Microsoft.Extensions.Caching.Hybrid;
using ZeroAlloc.Results;

namespace Minos.Caching;

/// <summary>A stage that answers a repeated request from a <see cref="HybridCache"/>, and stores each successful answer.</summary>
/// <remarks>
/// <para>
/// The key is a SHA-256 digest over the definition, the state, the images and the model, and the provider and endpoint of
/// the inner client's <see cref="DecisionClientMetadata"/>, so clients for different providers never share an answer. The
/// retry attempt is not part of it.
/// </para>
/// <para>
/// A hit returns the stored response, with <see cref="DecisionResponse.IsCached"/> set and the model, usage and cost of the
/// call that first produced it. An in-process hit returns the stored instance. Only a success is stored: an error or a
/// refusal passes through unchanged. Concurrent identical misses each call the provider; there is no stampede protection,
/// since HybridCache's would cache failures too.
/// </para>
/// <para>
/// The cache must have the decision serializer: <c>services.AddHybridCache().AddDecisionSerializer()</c>. Disposing the
/// stage disposes the inner client, never the cache.
/// </para>
/// </remarks>
public sealed class CachingDecisionClient : DelegatingDecisionClient
{
    private const string UnknownProvider = "unknown";

    // A read that writes nothing: the factory never runs, a miss returns null, and neither layer is written.
    private static readonly HybridCacheEntryOptions Lookup = new()
    {
        Flags = HybridCacheEntryFlags.DisableUnderlyingData
            | HybridCacheEntryFlags.DisableLocalCacheWrite
            | HybridCacheEntryFlags.DisableDistributedCacheWrite,
    };

    private readonly HybridCache _cache;
    private readonly string _provider;
    private readonly string? _endpoint;
    private readonly string _keyPrefix;
    private readonly HybridCacheEntryOptions _store;
    private readonly HybridCacheEntryOptions _promote;

    /// <summary>Initializes a new instance of the <see cref="CachingDecisionClient"/> class.</summary>
    /// <param name="innerClient">The client whose answers are cached.</param>
    /// <param name="cache">The cache, with the decision serializer registered.</param>
    /// <param name="options">The expiry and key prefix; <see langword="null"/> for the defaults.</param>
    /// <exception cref="ArgumentNullException"><paramref name="innerClient"/> or <paramref name="cache"/> is <see langword="null"/>.</exception>
    public CachingDecisionClient(IDecisionClient innerClient, HybridCache cache, DecisionCacheOptions? options = null)
        : base(innerClient)
    {
        ArgumentNullException.ThrowIfNull(cache);
        options ??= new DecisionCacheOptions();
        _cache = cache;
        var metadata = innerClient.GetService<DecisionClientMetadata>();
        _provider = metadata?.ProviderName ?? UnknownProvider;
        _endpoint = metadata?.Endpoint?.AbsoluteUri;
        _keyPrefix = options.KeyPrefix;
        _store = new HybridCacheEntryOptions { Expiration = options.Expiration, LocalCacheExpiration = options.LocalCacheExpiration };
        _promote = new HybridCacheEntryOptions
        {
            Expiration = options.Expiration,
            LocalCacheExpiration = options.LocalCacheExpiration,
            Flags = HybridCacheEntryFlags.DisableDistributedCacheWrite,
        };
    }

    /// <inheritdoc />
    public override ValueTask<Result<DecisionResponse, DecisionError>> EvaluateAsync(DecisionRequest request, CancellationToken cancellationToken = default)
    {
        ArgumentNullException.ThrowIfNull(request);
        var key = DecisionCacheKey.Create(request, _provider, _endpoint, _keyPrefix);
        var lookup = _cache.GetOrCreateAsync<object?, CachedDecision?>(
            key, null, static (_, _) => default, Lookup, null, cancellationToken);
        return lookup.IsCompletedSuccessfully
            ? Answer(lookup.Result, request, key, cancellationToken)
            : AwaitLookupAsync(lookup, request, key, cancellationToken);
    }

    private async ValueTask<Result<DecisionResponse, DecisionError>> AwaitLookupAsync(
        ValueTask<CachedDecision?> lookup, DecisionRequest request, string key, CancellationToken cancellationToken)
        => await Answer(await lookup.ConfigureAwait(false), request, key, cancellationToken).ConfigureAwait(false);

    private ValueTask<Result<DecisionResponse, DecisionError>> Answer(
        CachedDecision? entry, DecisionRequest request, string key, CancellationToken cancellationToken)
    {
        if (entry?.ResponseFor(request.Definition, out var firstBuild) is not { } hit)
        {
            return MissAsync(request, key, cancellationToken);
        }

        return firstBuild ? PromoteAsync(entry, hit, key) : new(Result<DecisionResponse, DecisionError>.Success(hit));
    }

    // A response rebuilt from the distributed cache is kept in the in-process one, so the next hit reuses it.
    private async ValueTask<Result<DecisionResponse, DecisionError>> PromoteAsync(CachedDecision entry, DecisionResponse hit, string key)
    {
        await _cache.SetAsync(key, entry, _promote, null, CancellationToken.None).ConfigureAwait(false);
        return Result<DecisionResponse, DecisionError>.Success(hit);
    }

    // The answer is paid for once it arrives, so it is stored even when the caller cancels afterwards.
    private async ValueTask<Result<DecisionResponse, DecisionError>> MissAsync(DecisionRequest request, string key, CancellationToken cancellationToken)
    {
        var result = await InnerClient.EvaluateAsync(request, cancellationToken).ConfigureAwait(false);
        if (result.IsSuccess)
        {
            await _cache.SetAsync(key, CachedDecision.From(result.Value.AsCached()), _store, null, CancellationToken.None).ConfigureAwait(false);
        }

        return result;
    }
}
```

**The stage's behaviour:**

```csharp
public override ValueTask<Result<DecisionResponse, DecisionError>> EvaluateAsync(DecisionRequest request, CancellationToken cancellationToken = default)
{
    ArgumentNullException.ThrowIfNull(request);
    var key = DecisionCacheKey.Create(request, _provider, _endpoint, _keyPrefix);
    if (_memory.TryGetValue(key, out var stored) && stored is CachedDecision entry
        && entry.ResponseFor(request.Definition, out _) is { } hit)
    {
        return new(Result<DecisionResponse, DecisionError>.Success(hit));
    }

    return _distributed is null ? MissAsync(request, key, cancellationToken) : ReadDistributedAsync(request, key, cancellationToken);
}
```

The shape of this code is binding: an in-process hit runs synchronously and builds no state machine. The rest:

- **`ReadDistributedAsync`** awaits `_distributed.GetAsync(key, cancellationToken)`.
  - If the caller's token is cancelled, the `OperationCanceledException` propagates.
  - Any other exception is logged as event 1007, when there is a logger, and treated as a miss.
  - If bytes come back, it reads them with `CachedDecisionFormat.Read`, then calls `ResponseFor`. If the entry fits, it stores the entry in process with the local options and returns the hit.
  - Anything else, including null bytes and an unreadable entry, goes to `MissAsync`.
- **`MissAsync`** awaits the inner client and returns its result unchanged. On a success it first:
  - builds `CachedDecision.From(result.Value.AsCached())`;
  - stores the entry in process with `_memory.Set(key, entry, _localOptions)`;

```markdown
## Caching decisions

`Minos.NET.Caching` adds `UseHybridCache()`, a stage that answers a repeated decision from a
[HybridCache](https://learn.microsoft.com/aspnet/core/performance/caching/hybrid): in process first, then from Redis
or any other `IDistributedCache` the app registers.

<!-- snippet: Pipeline_Caching -->
<!-- endSnippet -->

- **Register the serializer.** `AddDecisionSerializer()` stores answers as compact JSON with no reflection, so the
  cache stays trim- and AOT-safe. `Build` throws when the cache comes from the services and the serializer is missing.
- **A repeat is the same definition, state, images and model, to the same provider and endpoint.** Two clients for
  different providers never share an answer, even in one Redis instance. The retry attempt is not part of the key.
- **Only successes are stored.** An error or a refusal passes through, and the next call asks the provider again.
- **A hit is marked.** `DecisionResponse.IsCached` is `true`, the span and the duration and token metrics carry
  `minos.cache.hit`, and log event 1001's `Cached` field is `True`. The response keeps the model, usage and cost of the
  call that produced it, so filter on `minos.cache.hit` when you count spend.
- **Concurrent misses are not merged.** Two identical calls that both miss each ask the provider. HybridCache's
  stampede protection would cache failures as well, so the stage does not use it.
- **`DecisionCacheOptions`** sets `Expiration`, for the distributed cache, `LocalCacheExpiration`, for the in-process
  one, and `KeyPrefix`, `minos:` by default, to keep apps that share a cache apart.

## Limiting the call rate

`Minos.NET.RateLimiting` adds `UseRateLimiting(limiter)`, a stage that takes one permit from a
[`RateLimiter`](https://learn.microsoft.com/dotnet/api/system.threading.ratelimiting.ratelimiter) before each call
is sent.

<!-- snippet: Pipeline_RateLimiting -->
<!-- endSnippet -->

- **You own the limiter.** Any `RateLimiter` works: a token bucket, a fixed or sliding window, or a concurrency limiter.
  Share one across clients to limit an account, not a client. The stage never disposes it.
- **A call waits as the limiter says.** With a queue, a call waits for its permit; cancelling it while it waits throws
  `OperationCanceledException`. A concurrency limiter counts calls in flight, because the permit is held until the call
  completes.
- **A rejected call is not sent.** It returns a `RateLimited` error whose `StatusCode` is null, which tells it apart from
  a server's 429, and whose `RetryAfter` is the limiter's, when it gives one.

### Stage order

The first `Use` is the outermost stage. A client's standard pipeline runs inside every stage you add, so its retries
take no extra permits. When you build the pipeline yourself, use this order:

<!-- snippet: Pipeline_StageOrder -->
<!-- endSnippet -->

1. telemetry, so the span covers the whole call;
2. caching, so a hit takes no permit;
3. retries, outside the limiter, so a local rejection is retried after its `RetryAfter`;
4. rate limiting, so every attempt takes a permit;
5. the transport.
```
