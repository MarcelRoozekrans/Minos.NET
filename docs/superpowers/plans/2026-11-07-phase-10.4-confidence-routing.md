# Confidence Routing Guide and Proposal Draft Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An "Escalation" docs category (a concept page plus five recipes) and a dotnet/extensions proposal draft, for Phase 10.4 (#119).

**Architecture:** Docs only. Six pages in `docs/escalation/` teach routing between deciders and link to the reference in `docs/pipeline.md`. Compiled snippets and report-figure tests live in `tests/Minos.NET.Docs.Tests`, in the style of `RunningLocallyPageTests`. The proposal draft is `docs/plans/2026-11-06-dotnet-extensions-decision-proposal-draft.md`, which the site excludes.

**Tech Stack:** Markdown (Docusaurus), MarkdownSnippets (`dotnet mdsnippets`), xUnit, C# 14 on net10.0.

**Spec:** `docs/superpowers/specs/2026-11-06-phase-10.4-confidence-routing-design.md`

## Global Constraints

- No change under `src/` and none to `samples/Minos.NET.Samples.TicketTriage`.
- Every page has front matter `id`, `title`, `sidebar_position` (integer), `description`, and ends with a `## Next` section that links; a value with `: ` or ` #` is quoted.
- Every C# block is a `<!-- snippet: Name -->` region generated by `dotnet mdsnippets` from a `#region Name` in the Docs.Tests project. No snippet calls a real provider.
- Every figure quoted from a report is tied by a test to `docs/reports/triage/banking77/triage-report.json` (or the calibration `report.json`); the pages say whether a count is tickets (400) or questions (1,200).
- No workload names, domains, home-directory paths, keys or e-mail addresses in `docs/escalation/` or the draft. The pages and the draft are not allowed to say Daedalus or Thalos.
- Commit messages are `docs: <subject>`, or `test: <subject>`, with no scope, no Claude trailer and no nested parentheses in the body.
- Run `MSBUILDDISABLENODEREUSE=1` before `dotnet` commands (#145).
- Sidebar: the Escalation category is at position 18. Patterns (category), `samples`, `performance` and `conformance` move from 18, 19, 20, 21 to 19, 20, 21, 22. The index page is position 1 in its folder, then `thresholds` 2, `time-budget` 3, `fallback` 4, `composing-and-privacy` 5, `chat-model-target` 6.
- Page ids: `escalation`, `thresholds`, `time-budget`, `fallback`, `composing-and-privacy`, `chat-model-target`. Titles: Escalation, Sizing thresholds, The time budget, Falling back to another provider, Composing the stages and keeping data private, A chat model as the target.

## Review Focus

1. A default the page states that the code does not have (the 0.6 default threshold, `PrimaryName` "primary", `ShouldFallBack` defaulting to `FallbackOptions.IsProviderFailure`): each is pinned by a test against the real type.
2. A quoted figure that drifts when the report is rebuilt: the figure tests read the JSON.
3. A page that says escalation helps without saying when it does not: the index and `time-budget.md` carry the first run, where 0 of 106 escalated for time.
4. A private detail in the draft or a page: the denylist test covers both.
5. A link or anchor that breaks when pages move: the existing link and anchor tests cover every new page.
