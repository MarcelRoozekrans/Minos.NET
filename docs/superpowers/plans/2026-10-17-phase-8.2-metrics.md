# Phase 8.2 Metrics and Reports Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run a `DecisionDataset` through any `IDecisionClient`, save the per-item results as a versioned JSONL file, and compute a calibration report from that file as versioned JSON and as Markdown.

**Architecture:**
- **Results:** `DatasetRunner` sends one request per item, with configurable parallelism, and turns each response or error into an `ItemResult`.
- **Results file:** `EvaluationResults` saves to and loads from JSONL, with line-numbered problems.
- **Report:** `CalibrationReport.Create` joins the results with the dataset's expected answers and computes per-kind metrics on the gated number. `ToJson` and `ToMarkdown` render it.
- **Packing:** everything lives in `src/Minos.NET.Evaluation`, which stays non-packable.

**Tech Stack:** .NET 10, C#, System.Text.Json (`Utf8JsonReader`/`Utf8JsonWriter` or `JsonDocument`, no reflection), xUnit, ZeroAlloc.TestHelpers (`TextSnapshot.VerifyText`).

**Spec:** `docs/superpowers/specs/2026-10-17-phase-8.2-metrics-design.md`. Read its "Decisions" and its "Settled after the builder check (my calls)" sections.

## Global Constraints

- **Namespace and packing:** `Minos.Evaluation`; the project stays `IsPackable` false. No change to `src/Minos.NET` or any other package.
- **Scoring:**
  - **Noul:** the answer is `Probability >= 0.5`, and its confidence is `Math.Max(p, 1 - p)`.
  - **Choice:** the answer is the option key at `ChosenIndex` in the item's own definition, and its confidence is `Confidence`.
  - **Score:** the answer is the level `ChosenIndex`, and its confidence is `Confidence`.
  - **Correct:** Noul and Score by equality; Choice by an ordinal key comparison.
- **Scored and answered:**
  - A question is *scored* when the item's `Expected` has its key.
  - It is *answered* when it is scored and its item's request succeeded.
  - Accuracy, ECE, bins and base rate use answered questions. Sweep coverage uses scored questions.
- **Equal-mass bins:** sort answered questions by confidence ascending, then by item order. Make `min(10, n)` bins; when n does not divide, the first `n % 10` bins get one extra.
- **ECE:** the count-weighted mean of `|accuracy − mean confidence|`.
  - Equal-mass ECE is the headline figure.
  - Equal-width ECE uses bin index `Math.Min((int)(c * 10), 9)`.
- **Base rate:**
  - Noul: `max(trueRate, falseRate)` over the expected answers of answered questions.
  - Choice and Score: the share of the most common expected answer.
- **Sweep:** thresholds `0.00`, `0.01`, …, `0.99`, 100 points, each computed as `i / 100.0`.
  - Coverage is answered questions with confidence ≥ t, divided by scored questions.
  - Accuracy is computed among those covered, and is null when none are covered.
  - The sweep is given per kind and overall.
- **Latency:** nearest-rank, where the rank is `ceil(q * n)`, over successful requests that are not cached.
- **Cost per item:**
  - the reported `Usage.Cost` when it is ≥ 0;
  - otherwise both token counts times a matching price, when the response's model is non-null;
  - otherwise unknown.

  Cached items are left out of cost and counted separately. Cost per 1,000 decisions is the mean known cost times 1,000, or null when there is none.
- **Price match:** a model equals the entry's `Model`, or starts with the entry's `Model + "-"`. Use an ordinal comparison.
- **Errors:**
  - A `DecisionError` is saved with its kind name, from `DecisionErrorKind.ToString()`, its `StatusCode` and its `Message`.
  - An `OperationCanceledException` while the caller's token is not cancelled is saved with kind `Cancelled`.
  - The caller's own cancellation throws.
  - A run never stops early.
- **File kinds:** the results file is `"kind":"minos-run","version":1` on its header line. The report JSON is `"kind":"minos-report","version":1`.
- **Formatting:** invariant culture everywhere. The Markdown rounds to 4 decimals and the JSON keeps full precision. The Markdown's sweep rows are 0.00, 0.30, 0.50, 0.60, 0.70, 0.80, 0.85, 0.90, 0.95 and 0.99.
- **Commits:**
  - `feat:` with no scope for `src/Minos.NET.Evaluation`, which is unreleased;
  - `test(tests):` and `docs(docs):` elsewhere;
  - no nested parentheses in bodies;
  - every message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - always use `export MSBUILDDISABLENODEREUSE=1`.

## Review Focus

1. **A provider returns an answer whose key is missing, or an extra key.** The missing scored question counts as unanswered for that item, and an extra key is ignored. Neither throws. Pinned in Task 1.
2. **A Choice response with a `ChosenIndex` out of range** for the item's options. It is saved as an `InvalidResponse` error on that item, not thrown. Pinned in Task 1.
3. **`MaxParallelism` larger than the item count, or 0 or negative.** The first runs; 0 or negative throws `ArgumentOutOfRangeException` before any request. Pinned in Task 1.
4. **A results file saved on one machine and loaded on another with a different culture.** Numbers and dates round-trip exactly, in invariant culture with ISO 8601 UTC. Pinned in Task 2 under `de-DE`.
5. **A report over results where every item failed, or the dataset is empty.** It renders JSON and Markdown with null metrics and no exceptions or NaN text. Pinned in Task 4.
