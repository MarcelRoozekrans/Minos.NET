# Providers Docs and Samples Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Providers page that holds every provider fact, led by one capability matrix, and a provider-switch sample that runs one Choice question against TypeSafe, OpenRouter or a local `/v1/systemone` server, chosen by configuration only.

**Architecture:**
- **The shared sample host learns providers first.** `Minos.NET.Samples.Shared` gains `SampleArguments` (mode plus `--provider <name>`), `SampleProviders` (the `Minos:Providers:*` sections and `Minos:Active`), a recordings path per provider, `recordings/<provider>.json`, and a replay that fails at once, naming the record command for that provider, when the file is missing. The three existing samples keep their `recordings.json` and their behaviour.
- **Then the sample.** `samples/Minos.NET.Samples.ProviderSwitch` routes eight authored tickets through one Choice question, sent as a `DecisionRequest` so the report can name the model that answered. Its logic sits in `ProviderSwitchApp.RunAsync`, so a test can read its exit codes. It is tested on canned answers until its recordings exist.
- **Then CI:** the samples step replays every file in a sample's `recordings/` folder with `--provider`, and the billed Live smoke run and the free Local systemone run record the files and upload them as artifacts.
- **Then the docs.** The provider, capability and image sections of `client-and-errors.md` move, unchanged apart from the introductions, to a new `providers.md` at sidebar position 6. The five-row defaults table and the 12-row differences table merge into one matrix at the top of the page. New sections cover switching providers, running a local server and adding OpenAI, with compiled snippets.
- **After the merge, gated on the maintainer:** one billed Live smoke run and one Local systemone run record the three files, which land with the side-by-side table, the per-provider snapshots and the complete-phase changes.

**Tech Stack:** .NET 10, C#, Microsoft.Extensions.Hosting and Configuration, xUnit 2, ZeroAlloc.TestHelpers' `TextSnapshot`, MarkdownSnippets (`dotnet mdsnippets`), Docusaurus, GitHub Actions, ollajev 0.4.0.

## Rulings while planning

Each one settles a detail the spec leaves open. Every task follows them.

1. **What needs recordings waits for them.** The spec puts the recordings in the complete-phase PR, after a billed run. So the phase PR carries everything that can be tested without them, and the complete-phase PR (Task 8) adds, with the files, everything that reads them:
   - the three per-provider replay snapshots;
   - `EveryProviderSample_HasARecordingPerProvider`;
   - the side-by-side table on the Providers page and its test;
   - the recorded models and dates on the samples page and in the sample's README.

   In the phase PR the report is snapshotted on canned answers instead, and the CI per-provider loop runs nothing for the sample, because its `recordings/` folder has no files (`shopt -s nullglob`). No test is skipped: each one exists only once it can pass. Task 2 files a tracking issue for the gap, and Task 8's PR closes it.
2. **A missing recordings file fails at once.** In replay, `AddSampleDecisionClient` checks the file before it registers anything and throws `FileNotFoundException` naming the record command. That command names the provider when there is one: `dotnet run --project samples/<sample> -- --provider <name> --record`. The existing samples always have their file, so they are unaffected. The sample exits with code 1 in this case, and with 2 for a bad argument or provider, as the spec asks.
3. **Provider names.** A section's key is the provider's name: `TypeSafe`, `OpenRouter`, `Local`. `--provider` and `Minos:Active` match it without regard to case. The recordings file is the name in lower case, and the `provider` field inside a recordings file is the section name.
4. **The model in the report comes from the response.** A typed call returns only the answers, so the sample sends a `DecisionRequest` built from a `QuestionSetDefinition` and reads `DecisionResponse.Model`. When the models of one run differ, the report lists each, sorted.
5. **`--provider` is parsed by the sample, not by the host.** The host's command-line provider would read `--record --provider local` as `record=--provider`. `ProviderSwitchApp` builds its host without `Args` and adds the `--provider` value to configuration itself, after the environment, so it wins over `Minos__Active`.
6. **The merged matrix.** It has 15 rows: the five capability rows first, as plain values a test parses, then ten difference rows. The four rows of the old differences table that repeated a capability lose their duplicate parts: the wire names keep their own row, image transport becomes "Images on the wire", and the MIN201 to MIN203 and MIN206 notes and the model-listing details move into the paragraph under the matrix. `### The defaults` and `## Provider differences` keep their headings, so every anchor still resolves, and point at the matrix.
7. **Heading levels on the new page.** The moved `### The presets`, `### Custom servers`, `### OpenAI` and `### Provider differences` become `##`, and their `####` children become `###`. `## Capabilities` and `## Images` keep their levels. Slugs, and so anchors, do not change. The sentence "A Providers page is planned. Until it exists, the tables on this page are the reference." is deleted: the page now exists.
8. **Commit types.** No package changes, so nothing is a `feat`: sample code is `docs(samples)`, workflows are `ci(ci)` and pages are `docs(docs)`. The PR title is `docs: the Providers page and a provider-switch sample, Phase 6.7`.
9. **Snippet region names.** The moved snippets keep their `ClientAndErrors_*` region names, so their source files do not change. New regions are `Providers_ActiveProvider` and `Providers_AddOpenAI`.

namespace Minos.Samples;

/// <summary>The command line of a sample that runs against several providers: its mode, and the provider to use.</summary>
public sealed record SampleArguments(SampleMode Mode, string? Provider)
{
    /// <summary>
    /// Parses at most one of <c>--replay</c>, <c>--live</c> or <c>--record</c>, and at most one <c>--provider &lt;name&gt;</c>,
    /// in any order. No mode means <see cref="SampleMode.Replay"/>; no provider means the one configuration names.
    /// </summary>
    /// <exception cref="ArgumentException">An argument is unknown, repeated, or <c>--provider</c> has no name after it.</exception>
    public static SampleArguments Parse(IReadOnlyList<string> args)
    {
        ArgumentNullException.ThrowIfNull(args);
        SampleMode? mode = null;
        string? provider = null;
        for (var i = 0; i < args.Count; i++)
        {
            switch (args[i])
            {
                case "--replay" or "--live" or "--record":
                    if (mode is not null)
                    {
                        throw new ArgumentException("Pass at most one of --replay, --live or --record.", nameof(args));
                    }

                    mode = SampleModes.Parse([args[i]]);
                    break;
                case "--provider":
                    if (provider is not null)
                    {
                        throw new ArgumentException("Pass --provider at most once.", nameof(args));
                    }

                    if (i + 1 >= args.Count || args[i + 1].StartsWith("--", StringComparison.Ordinal))
                    {
                        throw new ArgumentException("--provider needs the name of a provider, such as --provider local.", nameof(args));
                    }

                    i++;
                    provider = args[i];
                    break;
                default:
                    throw new ArgumentException(
                        "Unknown argument " + args[i] + ". Use --replay, --live, --record or --provider <name>.", nameof(args));
            }
        }

        return new SampleArguments(mode ?? SampleMode.Replay, provider);
    }
}

using Microsoft.Extensions.Configuration;

namespace Minos.Samples;

/// <summary>
/// The configuration of a sample that runs against several providers: one section per provider under
/// <c>Minos:Providers</c>, and <c>Minos:Active</c> naming the one to use.
/// </summary>
public static class SampleProviders
{
    /// <summary>The section that holds one section per provider.</summary>
    public const string ProvidersKey = "Minos:Providers";

    /// <summary>The setting that names the provider to use.</summary>
    public const string ActiveKey = "Minos:Active";

    /// <summary>The names of the provider sections, in the order configuration sorts its keys.</summary>
    public static IReadOnlyList<string> Names(IConfiguration configuration)
    {
        ArgumentNullException.ThrowIfNull(configuration);
        return [.. configuration.GetSection(ProvidersKey).GetChildren().Select(section => section.Key)];
    }

    /// <summary>The provider section that <c>Minos:Active</c> names, matched without regard to case.</summary>
    /// <exception cref="InvalidOperationException">
    /// No provider is active, or the active one has no section. The message names the configured providers.
    /// </exception>
    public static IConfigurationSection Active(IConfiguration configuration)
    {
        ArgumentNullException.ThrowIfNull(configuration);
        var names = Names(configuration);
        var configured = names.Count == 0 ? "none" : string.Join(", ", names);
        var active = configuration[ActiveKey];
        if (string.IsNullOrWhiteSpace(active))
        {
            throw new InvalidOperationException(
                "No provider is active. Set Minos:Active, or pass --provider, to one of the configured providers: " + configured + ".");
        }

        var name = names.FirstOrDefault(n => string.Equals(n, active, StringComparison.OrdinalIgnoreCase))
            ?? throw new InvalidOperationException("Unknown provider " + active + ". The configured providers are: " + configured + ".");
        return configuration.GetSection(ProvidersKey).GetSection(name);
    }

using System.Globalization;

namespace Minos.Samples.Tests;

/// <summary>
/// Stands in for a provider: answers each ticket with its canned team and confidence, found by the ticket's text in the
/// request's state, and keeps the hash of every request body.
/// </summary>
internal sealed class CannedTickets(string model) : HttpMessageHandler
{
    private readonly List<string> _hashes = [];

    /// <summary>The team and confidence of each ticket, by its id.</summary>
    public static IReadOnlyDictionary<string, (string Team, double Confidence)> Answers { get; } =
        new Dictionary<string, (string Team, double Confidence)>(StringComparer.Ordinal)
        {
            ["s01"] = ("billing", 0.97),
            ["s02"] = ("technical", 0.95),
            ["s03"] = ("account", 0.99),
            ["s04"] = ("sales", 0.93),
            ["s05"] = ("technical", 0.88),
            ["s06"] = ("account", 0.91),
            ["s07"] = ("sales", 0.62),
            ["s08"] = ("billing", 0.84),
        };

    public IReadOnlyList<string> Hashes => _hashes;

    public int Requests => _hashes.Count;

    /// <summary>A System One response that chooses <paramref name="team"/> with <paramref name="confidence"/>.</summary>
    public static string Body(string model, string team, double confidence)
        => string.Create(
            CultureInfo.InvariantCulture,
            $$$"""{"model":"{{{model}}}","answers":{"team":{"type":"choice","choice":"{{{team}}}","probabilities":{{{Probabilities(team)}}},"confidence":{{{confidence}}}}},"usage":{"input_tokens":1,"output_tokens":1}}""");

    protected override async Task<HttpResponseMessage> SendAsync(HttpRequestMessage request, CancellationToken cancellationToken)
    {
        var body = await request.Content!.ReadAsByteArrayAsync(cancellationToken);
        _hashes.Add(RequestHash.Of(body));
        using var json = JsonDocument.Parse(body);
        var state = json.RootElement.GetProperty("state").GetString();
        var id = Tickets.All.First(t => string.Equals(t.Text, state, StringComparison.Ordinal)).Id;
        var (team, confidence) = Answers[id];
        return new HttpResponseMessage(HttpStatusCode.OK)
        {
            Content = new StringContent(Body(model, team, confidence), Encoding.UTF8, "application/json"),
        };
    }

    private static string Probabilities(string team)
        => "{" + string.Join(
            ",",
            new[] { "billing", "technical", "account", "sales" }.Select(
                key => "\"" + key + "\":" + (string.Equals(key, team, StringComparison.Ordinal) ? "1" : "0"))) + "}";
}

using System.Globalization;
using System.Text;

namespace Minos.Samples.ProviderSwitch;

/// <summary>One ticket and the team the model chose for it.</summary>
public sealed record RoutedTicket(string Id, string Text, string Team, double Confidence);

/// <summary>The routed tickets, the provider that was asked, and the model, or models, that answered.</summary>
public sealed record ProviderSwitchReport(string Provider, string Model, IReadOnlyList<RoutedTicket> Tickets)
{
    public string Render()
    {
        var text = new StringBuilder();
        foreach (var t in Tickets)
        {
            text.Append(CultureInfo.InvariantCulture, $"{t.Id}  {t.Team,-10} {t.Confidence:0.00}").Append('\n');
        }

        text.Append(CultureInfo.InvariantCulture, $"Answered by {Provider} with {Model}\n");
        return text.ToString();
    }
}

/// <summary>Routes every ticket with one request each, through whichever provider the client was configured for.</summary>
public static class ProviderSwitchSample
{
    public static async Task<ProviderSwitchReport> RunAsync(IDecisionClient client, string provider, CancellationToken cancellationToken)
    {
        ArgumentNullException.ThrowIfNull(client);
        ArgumentException.ThrowIfNullOrEmpty(provider);
        var options = TicketQuestions.Definition.Questions[0].Options;
        var routed = new List<RoutedTicket>();
        var models = new SortedSet<string>(StringComparer.Ordinal);
        foreach (var (id, text) in Tickets.All)
        {
            // A DecisionRequest rather than a typed call, so the response's model can be read as well as the answer.
            var result = await client.EvaluateAsync(new DecisionRequest(TicketQuestions.Definition, text), cancellationToken).ConfigureAwait(false);
            if (result.IsFailure)
            {
                throw new InvalidOperationException(id + ": " + result.Error.Kind + ": " + result.Error.Message);
            }

            var answer = result.Value.Answers[0];
            routed.Add(new RoutedTicket(id, text, options[answer.ChosenIndex].Key, answer.Confidence));
            models.Add(result.Value.Model ?? "an unnamed model");
        }

        return new ProviderSwitchReport(provider, string.Join(", ", models), routed);
    }
}

using Microsoft.Extensions.Configuration;
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Hosting;

namespace Minos.Samples.ProviderSwitch;

/// <summary>The sample's program, apart from the console, so a test can run it and read its exit code.</summary>
public static class ProviderSwitchApp
{
    public const string SampleName = "Minos.NET.Samples.ProviderSwitch";

    public const string Usage =
        "Usage: dotnet run --project samples/Minos.NET.Samples.ProviderSwitch [-- [--replay | --live | --record] [--provider <name>]]";

    /// <summary>
    /// Runs the sample against the provider that <c>Minos:Active</c> or <c>--provider</c> names. Returns 0; 1 when replay
    /// has no recordings for that provider; 2 for a bad argument, or a provider that is unknown or not set.
    /// </summary>
    public static async Task<int> RunAsync(
        IReadOnlyList<string> args, string contentRoot, TextWriter output, TextWriter error, CancellationToken cancellationToken)
    {
        ArgumentNullException.ThrowIfNull(output);
        ArgumentNullException.ThrowIfNull(error);

        SampleArguments arguments;
        try
        {
            arguments = SampleArguments.Parse(args);
        }
        catch (ArgumentException e)
        {
            await error.WriteLineAsync(e.Message).ConfigureAwait(false);
            await error.WriteLineAsync(Usage).ConfigureAwait(false);
            return 2;
        }

        // No Args: the host's command-line provider would read "--record --provider local" as record=--provider. The
        // --provider value is added last, after the environment, so it wins over Minos__Active.
        var builder = Host.CreateApplicationBuilder(new HostApplicationBuilderSettings { ContentRootPath = contentRoot });
        if (arguments.Provider is { } chosen)
        {
            builder.Configuration.AddInMemoryCollection([new KeyValuePair<string, string?>(SampleProviders.ActiveKey, chosen)]);
        }

        IConfigurationSection active;
        try
        {
            active = SampleProviders.Active(builder.Configuration);
        }
        catch (InvalidOperationException e)
        {
            builder.Configuration.Dispose();
            await error.WriteLineAsync(e.Message).ConfigureAwait(false);
            return 2;
        }

        // Replay and record use the recordings in the repository checkout; live needs none, so it runs from anywhere.
        var provider = active.Key;
        var recordingsPath = SampleHost.ProviderRecordingsPath(arguments.Mode, SampleName, provider);
        var session = new RecordingSession();
        try
        {
            builder.Services.AddSampleDecisionClient(active, arguments.Mode, recordingsPath, SampleName, session, provider);
        }
        catch (FileNotFoundException e)
        {
            builder.Configuration.Dispose();
            await error.WriteLineAsync(e.Message).ConfigureAwait(false);
            return 1;
        }

        using var host = builder.Build();
        var client = host.Services.GetRequiredService<IDecisionClient>();
        var report = await ProviderSwitchSample.RunAsync(client, provider, cancellationToken).ConfigureAwait(false);
        await output.WriteAsync(report.Render()).ConfigureAwait(false);

        if (arguments.Mode == SampleMode.Record && recordingsPath is not null)
        {
            Directory.CreateDirectory(Path.GetDirectoryName(recordingsPath)!);
            session.ToFile(provider, DateOnly.FromDateTime(DateTime.UtcNow)).Save(recordingsPath);
            await output.WriteLineAsync("Recorded " + session.Count + " responses to " + recordingsPath).ConfigureAwait(false);
        }

        return 0;
    }
}

# Provider-switch sample

This sample routes eight support tickets to a team, billing, technical, account or sales, with one Choice question per
ticket. It runs against TypeSafe, OpenRouter or a decision server on your own machine, and only the configuration
changes between them. It shows three things:

- **One section per provider.** `appsettings.json` holds a section for each provider under `Minos:Providers`, and
  `Minos:Active` names the one to use. The program binds the active section with `AddSystemOneClient`, and no other
  code knows which provider answers.
- **The same request, different answers.** The report prints each ticket's team and confidence, then the provider and
  the model that answered, so two runs can be compared line by line.
- **One recording per provider.** TypeSafe and OpenRouter receive byte-identical requests, because both ask
  `jev-latest`, so each provider's answers are kept in a file of their own.

The eight tickets are written for the sample.

## Run it

```
dotnet run --project samples/Minos.NET.Samples.ProviderSwitch
```

By default the sample replays the provider that `Minos:Active` names, `TypeSafe`, from `recordings/typesafe.json`. It
needs no network and no key. Pick another provider with `--provider`, or with the environment variable
`Minos__Active`:

```

```

has no recordings file exits with code 1 and prints the command that records it.

- TypeSafe needs `TYPESAFE_API_KEY`, and OpenRouter needs `OPENROUTER_API_KEY`. Each live run makes eight billed

  [Providers page](https://marcelroozekrans.github.io/Minos.NET/providers#running-a-local-server) has the commands
  that start it.

    private static IDecisionClient Client(HttpClient http, string column)
        => string.Equals(column, "OpenAI", StringComparison.Ordinal)
            ? new OpenAIDecisionClient(http, new OpenAIDecisionClientOptions { ApiKey = "key" })
            : new SystemOneClient(http, new SystemOneClientOptions

                ApiKey = "key",
                BaseAddress = new Uri("http://localhost:8080/"),
                Model = "my-model",
            });

    // The lines under a heading, up to the next heading of the same or a higher level outside a code block.
    private static List<string> SectionLines(string heading)
    {
        var lines = File.ReadAllLines(Path.Combine(PublishedPages.Root, "docs", Page));
        var start = Array.FindIndex(lines, line => string.Equals(line.TrimEnd(), heading, StringComparison.Ordinal));
        Assert.True(start >= 0, $"{Page} has a heading '{heading}'.");

        var level = heading.IndexOf(' ', StringComparison.Ordinal);
        var section = new List<string>();
        var fenced = false;
        foreach (var line in lines[(start + 1)..])
        {
            if (line.StartsWith("```", StringComparison.Ordinal))

                fenced = !fenced;
            }

            if (!fenced && Level().Match(line) is { Success: true } match && match.Groups["hashes"].Length <= level)

                break;
            }

            section.Add(line);
        }

        return section;

        return string.Equals(cell, "yes", StringComparison.Ordinal);

    [GeneratedRegex(@"^(?<hashes>#{1,6})\s", RegexOptions.None, matchTimeoutMilliseconds: 1000)]
    private static partial Regex Level();

### Work from a clone for replay and record

Replay and record read and write the recordings in the sample's own source folder: `recordings.json`, or for the
provider-switch sample one file per provider in `recordings/`. A sample finds that folder by walking up from the running

writes into the source folder on purpose, so that the next replay shows the new recording with no rebuild. `--live`

## The recordings

A recording is a file of real answers. The three single-provider samples hold real OpenRouter answers from the model
`typesafe/jev-1.13-20260917`, all recorded on 2026-10-02. Each file holds the provider, the model, the date, and the
response bodies, each filed under a hash of the request that earned it. The hash is the SHA-256 of the exact request
body. A recording never holds a header or a key.

The provider-switch sample keeps one file per provider in `recordings/`: `typesafe.json`, `openrouter.json` and
`local.json`. TypeSafe and OpenRouter receive byte-identical requests, so one file could not hold both. The billed Live
smoke workflow records the first two and the Local systemone workflow records `local.json`. Each uploads the files as an
artifact, and they reach the repository through a pull request.

Replay works by matching: the sample sends its request as usual, and a replacing handler hashes the body and returns the
recorded answer for that hash, without touching the network. This is the same idea as the canned handler on the
[testing page](testing-your-code.md#way-two-a-real-systemoneclient-over-a-canned-http-reply), kept in a file.

It follows that a recording is only good for the request that made it. Change a sample's questions or its data, or
change the request format of the client in the core library, and the request body changes, its hash changes, and the
recording has no answer for it. Replay then fails with an error that names the sample and gives the command to record
it again. Record again with `--record`. A client change moves the requests of every sample, so it means recording all
of them.

A fresh recording is a fresh set of answers, and a borderline answer can land on the other side of a threshold. Read
the new report before you keep it.

## How CI keeps the samples correct

A sample that is not run goes stale, so the CI workflow checks them in three ways.

- **They are built with everything else.** The samples are part of the solution, so the build compiles them with
  warnings treated as errors.
- **Their tests run.** The sample tests check each policy and route with made-up answers, compare each sample's report
  with a checked-in snapshot, and check that every recording holds no key and no header and that every sample has
  recordings.
- **Each sample runs, for real, in replay.** After the tests, a CI step runs every folder under `samples/` that holds a
  `recordings.json`, through the sample's real entry point: argument parsing, configuration and host setup included. It
  also runs the provider-switch sample once for each file in its `recordings/` folder, with `--provider` set to the
  file's name. A run passes only when the sample exits with code 0 and prints something. A new sample is picked up by
  adding its recordings. The step runs with empty `OPENROUTER_API_KEY` and `TYPESAFE_API_KEY`, so a sample that goes
  live by mistake fails at start-up and does not call the API.

So when a change to the library moves a request, CI fails with the message that names the sample and the command to
record it again, so a stale sample is caught by CI and not by a reader.
