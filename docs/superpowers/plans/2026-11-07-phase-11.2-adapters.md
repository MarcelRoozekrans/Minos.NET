# Decision Adapters Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The package `Minos.NET.Extensions.AI.Decisions`, unpacked, with a Minos client over an upstream client and the reverse, for Phase 11.2.

**Architecture:** A new project outside the default build, referencing the upstream assembly built by Phase 11.1's script. A mapper converts questions, state and answers both ways; two small client classes wrap the other side; extension methods are the entry points. Tests use a fake client on each side.

**Tech Stack:** C# 14 on net10.0, ZeroAlloc.Results, xUnit, the Minos conformance project, `Microsoft.CodeAnalysis.PublicApiAnalyzers`.

**Spec:** `docs/superpowers/specs/2026-11-07-phase-11.2-adapters-design.md`

**Builds on:** Phase 11.1 — `tools/upstream/build-decisions.sh` writing `artifacts/upstream/abstractions.path`, `tools/upstream/decisions-pin.json`, and `docs/extensions-ai-decisions/mapping.md`.

## Global Constraints

- `IsPackable` is false and a test fails if it is not. The project is built only in the `Decisions` configuration and by the `upstream-decisions` job; the default `dotnet build Minos.NET.slnx -c Release` and `dotnet test` must pass with no upstream clone.
- The upstream types are referenced by the path in `abstractions.path`, `Private` false. A missing file fails the build with a message naming `build-decisions.sh`.
- Public API is marked with the upstream experimental marker and recorded in `PublicAPI.Unshipped.txt`. Zero IL2 and IL3 warnings. No state in any exception message or log.
- Commit messages are `feat: <subject>` or `test: <subject>`, no scope in this package, no Claude trailer, no nested parentheses in the body. Run `MSBUILDDISABLENODEREUSE=1` before `dotnet` commands.
- Names fixed here: `UpstreamDecisionClient`, `MinosDecisionClient`, `MinosDecisionException` (carries the `DecisionError`), `DecisionMapper`, `DecisionClientAdapterExtensions.AsUpstreamDecisionClient` and `AsMinosDecisionClient`.

## Review Focus

1. A conversion that silently loses information: each row the mapping marks as a loss has a test and an `Unsupported` result.
2. The default build needing the clone.
3. State leaking into an error message.
