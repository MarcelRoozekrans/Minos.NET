Notable rulings:
- **Stopped runs:** a `DatasetRunException` keeps the finished items. In-flight requests cancelled by the run's own stop
  are left out, and the docs say their cost is not recorded.
- **Keyless endpoints:** the conformance `bad-key` probe is skipped when no credential was sent. This is fixed in
  `Minos.NET.Conformance`, not worked around in the tool.
- **The command name:** the root is a plain `Command` named `minos`, so the usage line names the installed command.
- **Package validation:** the 1.0.1 baseline is skipped for the two new ids, and the SDK turns validation off for tools.
- **Output folder:** reserved before the first request, so an unwritable folder fails before anything is paid for. The
  default folder is claimed atomically with a `.minos-run` marker, so two runs in the same second never share one.
- **Filed:** #230, keeping the finished results when a run is cancelled; it needs a decision on the runner's
  cancellation contract.
