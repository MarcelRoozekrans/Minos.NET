## Code quality

- **Security:**
  - No state reaches a log, tag, metric or exception message. A sentinel test covers logs, span tags and metric tags.
  - The cache and record readers treat malformed path data as a miss or a problem and never throw. Tests cover every
    branch, including negative usage, unknown reasons and certainties out of range.
- **Error handling:**
  - A target that throws propagates.
  - A deadline cancellation is a `TargetFailed` route.
  - The caller's cancellation throws an `OperationCanceledException` carrying the caller's token.
  - Recording failures never reach the caller.
- **Dead code:** `MatchingPath` was removed in the fix wave, because the `Path` setter already guarantees the match.
- **Info, I5:** an in-memory cache entry holds its path, and the path keeps the original merged response alive through
  the telemetry holder. That costs one object per entry. Accepted.
