## Commands

```bash
# Python 3.12 via actions/setup-python
pip install --extra-index-url https://download.pytorch.org/whl/cpu ollajev==0.4.0
ollajev pull Mapika/decider-2b-GGUF:Q4_K_M
OLLAJEV_DEVICE=cpu nohup ollajev serve Mapika/decider-2b-GGUF:Q4_K_M --port 8000 --no-browser > serve.log 2>&1 &
# ready when this succeeds; it took about 8 s, including a 5.9 s model load
for i in $(seq 1 60); do curl -sf http://127.0.0.1:8000/v1/models && break; sleep 5; done
```

## Resources

- **Server memory:** about 3.0 GB RSS for the ollajev process, on a 16 GB runner.
- **Install:** about 8 minutes, most of it building the `llama-cpp-python` wheel. The CPU torch index did not shorten it. Task 9 caches pip's wheel cache and the Hugging Face cache.
- **Model download:** about 20 s.

## Findings for the code

- ollajev's `GET /v1/models` returns `{"models":[{"name":…,"limits":…}]}`, which is not TypeSafe's model-list shape. A `Custom` client pointed at ollajev cannot read its model list, so `Custom` should default `ModelListing` to off. Task 9 makes that change.
- The response has no `id` and reports `output_tokens` as 0. The client already handles both.

## Decision

Task 9 adds a non-required `local-systemone` CI job with these commands, plus caches, and a `LocalSystemOneTests` run against the `Custom` preset with no key.
