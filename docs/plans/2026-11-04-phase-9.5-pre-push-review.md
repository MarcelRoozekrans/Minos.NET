**W1, Warning, `docs/running-locally.md:340`, the environment-variable switch fails at startup.** Step 6 says "Set
`Minos:Active` to `Local`, in the file or with the environment variable `Minos__Active`. No code changes." The app's
first configuration, which the reader has at that point, also holds `"Shadow": "Local"`. Overriding only
`Minos__Active=Local` gives Active and Shadow the same section, and `AddRecordedDecisions` throws
`InvalidOperationException` at startup: `RunningLocallyTests.AShadowNamingTheActiveSection_FailsNamingIt` pins exactly
that throw. The page's own instruction leads into it. Line 359 adds to the confusion: "Remove the shadow candidate, or
keep recording with no shadow" offers two options that are the same thing in this app, removing `Minos:Shadow`.
Fix: say that the switch sets `Minos:Active` to `Local` and removes `Minos:Shadow`, in the file, or with
`Minos__Active=Local` and an empty `Minos__Shadow`, which the app treats as unset because it checks
`IsNullOrWhiteSpace`. Then make line 359 one instruction: keep recording with no shadow, so outcomes keep arriving.
Quick fix.

**I2, Info, `docs/running-locally.md:291`, the threshold sweep is in the JSON only.** "The report already holds each
side's reliability bins and threshold sweep" is true of `shadow-report.json`, which has `sweep` per side and kind.
`shadow-report.md` has the reliability tables but no sweep, so a reader who opens the Markdown looks for a sweep that
is not there. Fix: "`shadow-report.json` holds each side's threshold sweep, and both files hold its reliability bins".
Quick fix.

**I3, Info, `docs/running-locally.md:43`, the Recording version is not named.** "A Minos.NET.Recording version that has

packages share one release-please version, so #313, a `feat`, ships in 1.9.0. Fix: name "Minos.NET.Recording 1.9.0 or
later" once #313's release PR shows that number, during the rebase onto `main`. Quick fix.

**I4, Info, `docs/running-locally.md:368`, outcomes and the erasure key.** "An outcome is stored with the record, under

Fix: "An outcome is attached to the record by its decision id, and erased with it." Quick fix.

**I5, Info, `docs/running-locally.md:389`, the zero-data-retention link.** "[Privacy: zero data retention] covers the
hosted setting" links to a section that is OpenRouter's `ProviderPreferences` only. Fix: "covers OpenRouter's

**I6, Info, `docs/running-locally.md:14-16`, a stacked sentence.** "cost 0.0293118 per 1,000 decisions, in the currency
