## Code quality

- **Primary path.** `RecordCore` begins the shadow, queues the record, then starts the candidate. `ShadowRunner.Start` and `RunAsync` catch everything, so recording never fails the call. The candidate never gets the caller's token, and the flow is suppressed, with the case where the caller already suppressed it handled. The allocation gate measures 1264 B against a bound of 1408 B, and the 1024 B gate of the unshadowed stage is unchanged.
- **Stage, runner, registry, sink.** On every path the running slot is released exactly once, and the shadow ends with `EndShadow`, `AbandonShadow` or `CancelShadow`. Queue order makes an erasure either drop the shadow write or erase the written record; it never resurrects one. `GiveUp` counts a lost shadow write as `shadows{dropped}`. `_shadowStop` is disposed only after the cancellation callbacks have run.
- **Public API.**
  - Both `PublicAPI.Unshipped.txt` files match the surface, and every new member has XML docs and `[Covers]`.
  - The `UseRecording` change keeps compatibility. The shipped `(builder, DecisionRecorder?)` signature keeps its binary shape. ApiCompat reports nothing. A scratch compile confirmed that `UseRecording(null)` and `UseRecording(recorder: null)` still bind to the recorder overload, not the shadow one.
- **Privacy.**
  - Logs carry exception type names only. Metric tags are fixed values. Exception messages hold no value.
  - The candidate's error message is dropped at `ShadowRunner.EvaluateAsync`.
  - The report holds keys, labels, model names and counts, never an id, an erasure key or the state. Problem lines are fixed text.
  - Sentinel tests cover the recorder (`NeverRecordedTests`, the `shadow` case), the report (`ShadowReportTests`) and the tool (`ShadowReport_OutputHoldsNoSentinel`).
- **Security.** Outputs are owner-only on Unix, with `FileShare.None`.
- **Debug code, suppressions.** There is no `Console.Write`, `#pragma`, `NoWarn` or `SuppressMessage` under `src/`.
- **Error handling.** Exit codes 0, 1, 2 and 130 are tested, and partial files are deleted on 1 and 130.
- **Tests.** Every bullet of the spec's test list has a test: `ShadowModeTests` and `ShadowWriteTests` in Recording, `ShadowReportTests` and `ShadowEndToEndTests` in Evaluation, `ShadowReportTests` and `CancellationTests` in the tool, and the docs snippets.
