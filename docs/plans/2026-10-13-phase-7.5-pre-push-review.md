| 6 | The README, the getting-started guide and the site for a published 1.0. |
| Final review | Fixes from the whole-branch review. |

The branch departs from the plan in four places, each recorded in the ledger when it happened:

1. **The packaging settings moved to `Directory.Build.targets`.** In `Directory.Build.props` they could not see a project's own `IsPackable=false`. The first form also made deterministic paths apply to the test projects, which broke `ProtocolBoundaryTests` on GitHub. CI found that, and run 38388378824 confirmed the fix.
2. **Deterministic builds also cover the generator, analyzers and code fixes,** because their DLLs ship inside `Minos.NET`.
3. **The pack-test helper bounds the stream reads, not only the process,** which the plan's helper code did not do.
4. **`RELEASING.md` says the Trusted Publishing policy must be allowed to create new packages.** All six ids are new, and a policy limited to existing packages would fail the one real push.
